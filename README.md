# Zeno AI Docs

Next.js + Nextra로 만든 AI 학습 문서 사이트.

강의나 책을 사는 대신 AI로 학습 자료를 직접 만들어,<br>
최소 비용으로 공부하는 것이 목표입니다.

이미 구독 중인 AI 서비스가 있으면 **Agent**로,<br>
없으면 필요할 때만 **API**로 만들 수 있습니다.

🔗 **https://zeno.it.kr**

<br>

### 방법 1 · API 파이프라인

과목 하나를 5단계로 쪼개서 단계마다 잘하는 모델에 맡깁니다.

| 단계 | 모델 | 하는 일 |
|:--:|:--|:--|
| 1 | Grok | 대상 독자·목표·범위 정의 |
| 2 | Perplexity | 웹 검색으로 자료 조사, 목차 설계 |
| 3 | Claude | 편별 MDX 본문 작성 |
| 4 | Gemini | 사실 확인, 계산 검산, 퀴즈 정답 검증 |
| 5 | GPT | 검수 반영과 내용 보강 |

`실행/작업지시.md`에 과목을 적고 단계별 bat을 실행합니다.
호출 비용은 `costs/`에 자동으로 쌓이고 `비용보고서.bat`으로 집계합니다.

<br>

### 방법 2 · Agent

Claude Code나 Codex Agent로 정리된 md를 보고 단계별 작업을 진행합니다.
구독 요금 안에서 처리되니 API 비용이 들지 않습니다.

두 방법은 산출물 경로가 같아서 섞어서 쓸 수 있습니다.
호출량이 많은 본문 작성은 Agent로, 검색이 필요한 조사는 API를 활용하는 것도 괜찮은 방법입니다.

<br>

### 구조

```
content/    사이트에 올라가는 MDX. 폴더 구조가 곧 메뉴 구조
prompts/    단계별 AI 지시문 + MDX 문법 규칙 (로컬 전용, 저장소 미포함)
scripts/    파이프라인 실행기, MDX 검사기, 홈 데이터 생성기
실행/       작업지시서와 단계별 bat
```

### 앞으로의 개선점
- **API 비용 절감**: 단계별로 Ollama(로컬 모델), Kimi, DeepSeek 같은 저렴한 모델을 붙여 보고, 품질이 유지되는 단계부터 교체
- **검수 강화**: 퀴즈 정답·계산·코드 실행 결과를 자동으로 검증하는 단계 보강
