</Callout>

## 왜 "가짜(pseudo)" 클래스인가

**의사 클래스**(pseudo-class, 슈도 클래스)라는 이름부터 뜯어봅시다. **의사**(pseudo)는 그리스어에서 온 접두어로 "가짜의, ~인 척하는"이라는 뜻입니다. 즉 의사 클래스는 **HTML 마크업에 실제로 존재하지 않는 클래스인 척하는 선택자**입니다.

왜 이런 게 필요할까요. 04편의 클래스 선택자(`.버튼`)는 HTML에 `class="버튼"`이라고 **직접 적어야만** 동작합니다. 그런데 "마우스를 올렸을 때", "포커스를 받았을 때", "체크된 상태일 때", "목록의 첫 번째일 때" 같은 조건은 HTML에 미리 적어 둘 수 없습니다. 마우스를 올리는 순간에 자바스크립트로 클래스를 추가했다가 떼는 식으로 흉내 낼 수는 있지만, 번거롭고 자바스크립트가 없으면 아예 동작하지 않습니다.

의사 클래스는 이런 **동적인 상태**나 **위치 기반 조건**을 브라우저가 대신 계산해서, 마치 그 순간에만 클래스가 붙은 것처럼 선택하게 해 줍니다. 문법은 콜론(`:`) 하나에 이름을 붙입니다: `선택자:의사클래스이름`.

> **쉽게 말하면:** 의사 클래스는 "지금 이 순간 이런 상태인 요소"를 브라우저가 실시간으로 찾아 주는 라벨입니다. 내가 마크업에 써 붙일 필요가 없습니다.

## 1. 상태 기반 의사 클래스 — 지금 어떤 상태인가

### `:hover` — 마우스가 올라와 있다

```css
button:hover {
  background-color: #2563eb;
}
```

`button:hover`는 "지금 마우스 커서가 그 위에 있는 버튼(`button`) 요소"만 고릅니다. 사용자가 마우스를 치우면 조건이 즉시 거짓이 되어 스타일도 즉시 사라집니다. 자바스크립트로 `mouseenter`/`mouseleave` 이벤트를 듣고 클래스를 붙였다 뗐다 하는 코드를 CSS 한 줄로 대체하는 셈입니다.

<Callout type="warning">
  **자주 틀리는 점:** 터치스크린 기기에는 마우스가 없어, `:hover`가 "터치 직후 계속 눌린 것처럼" 어색하게 유지되는 경우가 있습니다. 모바일까지 고려하는 실무 CSS는 `:hover`만으로 중요한 기능(예: 메뉴 열기)을 구현하지 않고 클릭으로도 동작하게 이중으로 설계합니다.
</Callout>

### `:focus`와 접근성

```css
input:focus {
  outline: 2px solid #2563eb;
}
```

**포커스**(focus, 초점)는 키보드의 Tab 키나 스크린 리더 탐색으로 "지금 입력을 받을 준비가 된 요소"에 옮겨지는 표시입니다. `:focus`는 그 순간의 요소를 고릅니다.

이 의사 클래스는 접근성(accessibility, 웹 접근성)과 직결됩니다. 마우스를 쓰지 않는 사용자는 `:hover`를 절대 경험하지 못하고, 오직 `:focus`로만 "지금 어디에 있는지"를 파악합니다. 그래서 `outline: none;`으로 포커스 표시를 지워 버리는 것은 디자인상 깔끔해 보여도, 키보드 사용자에게는 지금 커서가 화면 어디에 있는지 알 방법을 빼앗는 것과 같습니다. 지우려면 반드시 다른 시각적 표시(테두리 색, 그림자 등)로 대체해야 합니다.

### `:active` — 누르고 있는 순간

```css
button:active {
  transform: scale(0.98);
}
```

`:active`는 마우스 버튼을 누른 순간부터 뗄 때까지, 아주 짧은 구간만 참이 됩니다. 버튼을 "눌렀다"는 즉각적인 피드백을 주는 데 씁니다.

### `:checked`와 `:disabled` — 폼 요소의 상태

```css
input:checked + label {
  font-weight: bold;
}

button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

`:checked`는 체크박스나 라디오 버튼이 선택된 상태를, `:disabled`는 `disabled` 속성이 붙어 비활성화된 폼 요소를 고릅니다. 앞의 예시는 05편의 인접 형제 결합자(`+`)와 `:checked`를 결합해 "체크된 입력 바로 다음의 라벨을 굵게" 만드는 실전 패턴입니다.

`:disabled` 상태의 버튼은 스크린 리더가 "사용할 수 없음"으로 안내하고 Tab 이동에서도 건너뜁니다. 이때 `cursor: not-allowed`처럼 시각적으로도 "지금은 안 됨"을 보여주면, 화면을 보는 사용자와 스크린 리더 사용자 모두에게 일관된 정보를 전달하게 됩니다.

### 상태 기반 의사 클래스 정리

| 의사 클래스 | 참이 되는 순간 | 마우스 없이도 발생하는가 |
|-------------|----------------|--------------------------|
| `:hover` | 마우스 커서가 위에 있는 동안 | 아니오 |
| `:focus` | 요소가 입력을 받을 상태인 동안 | 예 — 키보드 Tab으로도 발생 |
| `:active` | 누르는 순간부터 떼기 전까지 | 아니오(터치는 가능) |
| `:checked` | 체크박스·라디오가 선택된 동안 | 예 |
| `:disabled` | `disabled` 속성이 있는 동안 | 예 |

## 2. 구조적 의사 클래스 — 형제들 사이의 위치

### `:first-child`와 `:last-child`

**구조적 의사 클래스**(structural pseudo-class)는 마우스나 키보드와 무관하게, 마크업 트리 안에서의 **위치**만으로 요소를 고릅니다.

```css
li:first-child {
  border-top: none;
}

li:last-child {
  border-bottom: none;
}
```

`:first-child`는 "부모의 자식들 중 첫 번째인 요소"를 고릅니다. 주의할 점은 이것이 "`li` 중에서 첫 번째"가 아니라 "**부모의 모든 자식 중** 첫 번째인데, 그게 마침 `li`인 경우"라는 것입니다.

```html
<ul>
  <p>안내 문구</p>
  <li>항목 1</li>
  <li>항목 2</li>
</ul>
```

이 마크업에서 `li:first-child`는 아무것도 고르지 못합니다. 부모(`ul`)의 첫 번째 자식은 `p`이지 `li`가 아니기 때문입니다. "`li` 요소들 중에서 첫 번째"를 고르고 싶다면 `:first-of-type`을 씁니다.

### `:nth-child()` — 순서를 공식으로 지정

```css
li:nth-child(2n) {
  background-color: #f3f4f6;
}
```

`:nth-child()`는 괄호 안에 순서를 나타내는 표현식을 받습니다. `2n`은 2, 4, 6, 8…번째(짝수 번째)를 뜻하고, `2n+1`은 홀수 번째, 숫자 하나만 쓰면(`li:nth-child(3)`) 정확히 그 번째 하나만 고릅니다. 표 행을 한 줄씩 다른 색으로 칠하는 "지브라 스트라이프"(zebra stripe) 효과가 이 의사 클래스의 대표적인 용도입니다.

> **쉽게 말하면:** `:nth-child(공식)`은 "부모 안에서 몇 번째 자식인지"를 수학 공식에 넣어 참·거짓을 계산하는 것입니다. `n`에 0, 1, 2, 3…을 차례로 넣어 나오는 번호들이 선택됩니다.

### `:not()` — 부정 선택자

```css
li:not(:last-child) {
  border-bottom: 1px solid #e5e7eb;
}
```

**부정 선택자**(negation pseudo-class) `:not()`은 괄호 안 조건에 **맞지 않는** 요소를 고릅니다. 위 예시는 "마지막 항목이 아닌 모든 `li`"에 아래쪽 테두리를 그려, 목록 항목 사이에만 구분선이 생기고 마지막 항목 아래에는 불필요한 선이 남지 않게 하는 흔한 패턴입니다.

### 구조적 의사 클래스 정리

| 의사 클래스 | 의미 |
|-------------|------|
| `:first-child` | 부모의 자식들 중 첫 번째 |
| `:last-child` | 부모의 자식들 중 마지막 |
| `:nth-child(공식)` | 공식으로 계산된 순번에 해당 |
| `:not(선택자)` | 괄호 안 조건에 맞지 않는 요소 |

## 4. 여기서 멈추는 이유 — Level 4로 넘어가는 경계

**의사 클래스 선택자 명세**(Selectors)는 버전이 올라가면서 계속 새 의사 클래스를 추가해 왔습니다. `:is()`, `:where()`, `:has()`, `:focus-visible`은 CSS Selectors Level 4에서 정의된 비교적 최근 기능으로, 이 기본기 과목이 아니라 자매 과목인 **모던 CSS**(Modern CSS)에서 다룹니다. 특히 `:has()`는 05편 끝에서 언급한 "앞쪽 요소를 뒤쪽 조건으로 고르는" 오랜 한계를 깨는 의사 클래스라 별도로 깊게 다룰 가치가 있습니다. 지금 단계에서는 이런 이름이 있다는 것만 기억해 두고, 실제 사용법은 `/web/css/modern_css` 과목에서 배우게 됩니다.

## 핵심 정리

- 의사 클래스는 마크업에 실제로 없는 클래스를 콜론(`:`)으로 흉내 내, 동적 상태나 구조적 위치로 요소를 고른다.
- `:hover`·`:focus`·`:active`·`:checked`·`:disabled`는 상태 기반이며, 특히 `:focus`는 키보드·스크린 리더 사용자의 접근성과 직결된다.
- `:first-child`·`:last-child`·`:nth-child()`는 구조적 위치 기반이며, `:first-child`는 "그 태그 중 첫 번째"가 아니라 "부모의 모든 자식 중 첫 번째"임을 주의한다.
- `:not()`은 조건에 맞지 않는 요소를 고르는 부정 선택자다.
- `:is()`·`:where()`·`:has()`·`:focus-visible`은 Modern CSS 과목에서 다룬다.
