  **이번 문서의 목표:** 이 문서를 다 읽으면 `::before`가 실제로 새 HTML 태그를 만드는 것이 아니라는 사실을 근거로 설명하고, `content` 속성과 함께 장식 요소나 아이콘을 마크업 수정 없이 삽입할 수 있게 됩니다.
</Callout>

## 콜론 하나 vs 콜론 둘 — 이름부터 구분

06편의 **의사 클래스**(pseudo-class)는 콜론 하나(`:hover`)였습니다. 이번에 배울 **의사 요소**(pseudo-element)는 콜론 둘(`::before`)을 씁니다. 둘 다 "의사"(pseudo, 가짜의)라는 접두어를 쓰지만 가리키는 대상이 다릅니다.

- 의사 **클래스**는 "이미 있는 요소"를 어떤 **상태**나 **위치** 조건으로 골라냅니다. 새로운 요소를 만들지 않습니다.
- 의사 **요소**는 마크업에 **존재하지 않는 요소를 렌더링 결과에만 새로 만들어 냅니다.** DOM(Document Object Model, 문서 객체 모델 — 브라우저가 HTML을 메모리에 트리 구조로 표현한 것)에는 이 요소가 추가되지 않습니다. 화면에는 보이지만 자바스크립트의 `document.querySelector`로는 잡히지 않습니다.

<Callout type="warning">
  **자주 틀리는 점:** CSS 사양은 원래 의사 요소도 콜론 하나(`:before`)로 쓰도록 허용했던 시절이 있어, 오래된 코드나 예제에 `:before`가 남아 있기도 합니다. 지금은 의사 클래스와 명확히 구분하기 위해 **콜론 둘(`::before`)이 표준 표기**입니다. 최신 브라우저는 하위 호환을 위해 콜론 하나도 여전히 받아 주지만, 새로 쓰는 코드는 콜론 둘로 통일합니다.
</Callout>

## 1. `::before`와 `::after` — 없던 요소를 끼워 넣기

### 정의와 필수 조건

`::before`는 요소의 **실제 내용이 시작되기 직전**에, `::after`는 **내용이 끝난 직후**에 새 상자를 하나 만들어 넣습니다. 단, 이 둘은 `content` 속성을 지정해야만 실제로 나타납니다. `content`가 없으면 브라우저는 아예 상자를 만들지 않습니다.

```css
.필수::after {
  content: " *";
  color: red;
}
```

```html
<label class="필수">이메일</label>
```

이 규칙은 `label` 요소의 텍스트("이메일") 뒤에 빨간 별표를 하나 더 붙입니다. 그런데 이 별표는 HTML 어디에도 적혀 있지 않습니다. 브라우저가 렌더링(rendering, 화면에 그리는 과정)하는 순간에만 만들어 낸 가짜 요소입니다.

### 브라우저가 실제로 하는 일

브라우저 개발자 도구(DevTools)로 위 `label`을 검사(Inspect)해 보면, **DOM 트리**에는 `<label class="필수">이메일</label>`만 있고 별표는 보이지 않습니다. 하지만 Styles 패널이나 Elements 패널에서 그 요소를 펼치면 `::after`라는 항목이 별도로 표시되어, "이 요소는 실제 DOM에는 없지만 렌더링에는 참여한다"는 것을 확인할 수 있습니다. 접근성 트리(accessibility tree)나 스크린 리더도 `content` 값을 상황에 따라 읽어 줄 수 있어, 순전히 장식용으로 쓴 텍스트가 스크린 리더에 불필요하게 낭독되지 않는지는 항상 확인이 필요합니다.

### content 속성에 넣을 수 있는 값

```css
.인용::before {
  content: "\201C"; /* 여는 큰따옴표 문자 */
}

.아이콘::before {
  content: "→";
}

.배지::after {
  content: attr(data-배지수);
}
```

`content`에는 문자열뿐 아니라 `attr()` 함수로 **그 요소의 HTML 속성값을 그대로 가져와** 표시할 수도 있습니다. 예를 들어 `<span data-배지수="3">`이 있다면 `attr(data-배지수)`는 "3"이라는 문자열을 그 자리에 그려 줍니다.

### 실전 활용 — 장식 요소와 클리어픽스

`::before`/`::after`는 아이콘을 이미지 태그 없이 붙이거나, 툴팁의 작은 삼각형 화살표를 그리거나, 리스트 항목 앞에 커스텀 불릿을 넣는 등 **순수하게 장식적인 요소**를 마크업 없이 추가하는 데 자주 쓰입니다. 19편에서 다룰 클리어픽스(clearfix) 기법도 `::after`로 보이지 않는 빈 상자를 만들어 float 문제를 해결하는 응용입니다.

## 2. `::first-line`과 `::first-letter` — 렌더링 결과의 일부만

### `::first-letter` — 첫 글자만

```css
p::first-letter {
  font-size: 2em;
  font-weight: bold;
}
```

`::first-letter`는 요소 텍스트의 **첫 번째 글자 하나**만 골라냅니다. 신문 기사나 잡지에서 문단 첫 글자를 크게 키우는 "드롭 캡"(drop cap) 효과가 대표적인 용도입니다.

### `::first-line` — 렌더링된 첫 줄만

```css
p::first-line {
  font-weight: bold;
}
```

`::first-line`은 문단의 **첫 번째 줄**만 고릅니다. 여기서 중요한 함정이 있습니다. "몇 번째 줄"인지는 HTML 코드가 아니라 **화면에 실제로 그려진 결과**로 정해집니다. 브라우저 창의 너비를 줄이면 줄바꿈 위치가 바뀌고, 그에 따라 `::first-line`이 적용되는 글자 수도 달라집니다.

> **쉽게 말하면:** `::first-letter`는 "글자 수"로, `::first-line`은 "화면에 실제로 그려진 줄"로 범위를 정합니다. 둘 다 HTML에 미리 표시해 둘 수 없는 범위라서 의사 요소가 필요합니다.

<Callout type="warning">
  **자주 틀리는 점:** `::first-line`을 "HTML 코드에서 줄바꿈된 곳까지"로 착각하기 쉽습니다. 실제로는 HTML 소스의 줄바꿈과 무관하며, 오직 브라우저 창 너비에 따라 텍스트가 실제로 접히는(wrap) 지점까지만 적용됩니다. 반응형으로 화면 크기가 바뀌면 대상 글자 수도 함께 바뀝니다.
</Callout>

## 4. 의사 클래스와 의사 요소 표기 구분 정리

| 구분 | 콜론 개수 | 대상 | 예시 |
|------|-----------|------|------|
| 의사 클래스 | `:` 하나 | 이미 있는 요소의 상태·위치 | `:hover`, `:nth-child()` |
| 의사 요소 | `::` 둘 | 렌더링에만 존재하는 새 부분 | `::before`, `::first-line` |

<Callout type="warning">
  **자주 틀리는 점:** 콜론 개수를 하나로 통일해서 외우면 `:hover`까지 `::hover`로 잘못 쓰는 실수를 하기 쉽습니다. "상태·위치를 고르면 콜론 하나, 없던 부분을 새로 만들면 콜론 둘"이라는 대상 기준으로 구분하는 편이 안전합니다.
</Callout>

## 핵심 정리

- 의사 요소(`::`)는 의사 클래스(`:`)와 달리 DOM에 없는 새로운 상자를 렌더링 결과에만 만들어 낸다.
- `::before`/`::after`는 `content` 속성이 있어야 나타나며, 문자열이나 `attr()`로 속성값을 표시할 수 있다.
- `::first-letter`는 첫 글자 하나, `::first-line`은 화면에 실제로 그려진 첫 줄을 대상으로 하며 둘 다 화면 크기에 따라 범위가 달라질 수 있다.
- 순수 장식용 콘텐츠는 스크린 리더에 불필요하게 낭독되지 않는지 확인이 필요하다.
