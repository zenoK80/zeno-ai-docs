## 왜 색 표기법이 하나가 아닌가

브라우저에게 "이 글자를 빨간색으로 칠해라"라고 지시하는 방법은 한 가지가 아닙니다. `red`라고 이름을 말할 수도 있고, 빛의 삼원색을 숫자로 섞어 말할 수도 있고, 색상환의 각도로 말할 수도 있습니다. 표기법이 여러 개인 이유는 **사람이 색을 떠올리는 방식과, 코드로 색을 조작하는 방식이 다르기 때문**입니다. 디자이너에게 받은 값은 보통 16진수이고, 자바스크립트로 밝기를 서서히 바꾸는 애니메이션을 만들 때는 각도와 퍼센트로 된 표기법이 계산하기 편합니다. 이 편에서는 이 표기법들이 결국 **같은 색을 가리키는 다른 언어**라는 점을 확인합니다.

## 1. 색 표기법 네 가지

### 키워드 — 이름으로 부르기

CSS는 `red`, `blue`, `steelblue`, `transparent`처럼 미리 정의된 색 이름을 100개 넘게 제공합니다. 가장 읽기 쉽지만, 미세한 색조 조정은 불가능합니다.

```css
.badge { background-color: tomato; }
```

### 16진수(hex) — 빛의 삼원색을 두 자리씩

**16진수**(hexadecimal, 헥스) 표기법은 `#`으로 시작해 빨강(Red)·초록(Green)·파랑(Blue) 세 가지 빛의 세기를 각각 00부터 FF(십진수로 0부터 255)까지의 16진수 두 자리로 나열합니다. 이 세 색을 섞어 원하는 색을 만드는 방식을 **RGB 색 모델**이라 부릅니다.

```css
.box {
  color: #ff0000;    /* 빨강 최대, 초록 0, 파랑 0 → 순수 빨강 */
  color: #ff6b6b;    /* 세 값을 섞어 만든 산호색 계열 */
  color: #333;       /* 세 자리 축약 표기 — #333333과 동일 */
}
```

투명도(alpha, 알파)까지 포함하려면 두 자리를 더 붙여 `#ff0000cc`처럼 씁니다(뒤 두 자리 `cc`는 십진수 204, 약 80퍼센트 불투명도).

### rgb() — 숫자로 섞는 비율

`rgb()` 함수는 16진수와 원리는 같지만, 각 채널을 0부터 255 사이의 십진수(또는 0퍼센트부터 100퍼센트)로 직접 씁니다. 네 번째 값으로 알파(투명도, 0은 완전 투명·1은 완전 불투명)를 함께 쓸 수 있습니다.

```css
.overlay {
  background-color: rgb(255 0 0);       /* 순수 빨강, #ff0000과 동일한 색 */
  background-color: rgb(0 0 0 / 50%);   /* 검정, 50% 투명도 */
}
```

### hsl() — 색상환으로 말하기

**hsl()** 함수는 색상(Hue, 색조)·채도(Saturation)·명도(Lightness)라는 세 값으로 색을 표현합니다. RGB가 "빛을 얼마나 섞을까"라면, HSL은 "색상환에서 어느 각도의 색을, 얼마나 선명하게, 얼마나 밝게"를 말하는 방식이라 사람의 직관에 더 가깝습니다.

- **Hue(색조)**: 0도에서 360도까지의 각도. 0도가 빨강, 120도가 초록, 240도가 파랑입니다.
- **Saturation(채도)**: 0퍼센트(완전한 회색)부터 100퍼센트(가장 선명한 색)까지.
- **Lightness(명도)**: 0퍼센트(검정)부터 50퍼센트(가장 선명한 원색)를 거쳐 100퍼센트(흰색)까지.

```css
.brand {
  background-color: hsl(210deg 80% 50%); /* 파란 계열, 채도 80%, 중간 명도 */
}
.brand-hover {
  background-color: hsl(210deg 80% 40%); /* 색조·채도는 그대로 두고 명도만 낮춰 hover 색을 만듦 */
}
```

같은 색을 유지한 채 밝기만 조절하고 싶을 때(hover 시 살짝 어둡게 등) `hsl()`은 명도 숫자 하나만 바꾸면 되지만, `rgb()`나 16진수는 세 채널을 모두 다시 계산해야 합니다. 이것이 실무에서 `hsl()`을 선호하는 대표적인 이유입니다.

| 표기법 | 구성 | 강점 |
|--------|------|------|
| 키워드 | 이름(`red` 등) | 가장 읽기 쉬움, 세밀한 조정 불가 |
| 16진수 | RGB 각 2자리 16진수 | 디자인 툴에서 그대로 복사해 오기 좋음 |
| `rgb()` | R·G·B 0–255(또는 %) + 알파 | 코드로 채널별 값을 직접 다룰 때 |
| `hsl()` | 색조(각도)·채도(%)·명도(%) + 알파 | 색조를 유지한 채 밝기·채도만 조절할 때 |

<Callout type="warning">
  **자주 틀리는 점:** 최근 브라우저는 더 넓은 색 영역을 표현하는 `oklch()` 같은 새 색 함수도 지원하기 시작했지만, 이는 비교적 최근에 Baseline에 들어온 기능이라 이 과목에서는 다루지 않습니다. `css/modern_css`에서 `color-mix()`와 함께 다룹니다. 여기서는 위 네 가지 전통적 표기법만으로 충분히 실무를 소화할 수 있다는 점을 기억해 두세요.
</Callout>

## 2. currentColor — 글자색을 다른 속성이 그대로 물려받기

**currentColor**는 "그 요소에 최종적으로 계산된 `color` 값"을 가리키는 특수 키워드입니다. `color`가 아닌 다른 속성(테두리, 그림자, 배경 등)에서 "지금 이 요소의 글자색과 똑같은 색을 써라"라고 지시할 때 씁니다.

```css
.icon-button {
  color: steelblue;
  border: 2px solid currentColor; /* 테두리 색이 글자색을 그대로 따라감 */
}
```

`color`가 상속(inheritance, 10편 참조)되는 속성이라는 사실과 겹쳐서 보면 강력해집니다. 부모의 `color`만 바꾸면, `currentColor`를 쓰는 자식의 테두리·그림자 색까지 한 번에 따라 바뀝니다. SVG 아이콘의 `fill="currentColor"`도 같은 원리로, 아이콘 색을 텍스트 색과 항상 맞추고 싶을 때 널리 쓰이는 관행입니다.

## 3. background 속성군 — 배경을 이루는 조각들

`background`는 사실 한 속성이 아니라 **여러 하위 속성을 한 줄로 합친 축약형**(shorthand)입니다. 각 조각의 역할을 따로 알아야 축약형을 읽고 쓸 수 있습니다.

| 하위 속성 | 역할 |
|-----------|------|
| `background-color` | 배경 이미지 아래(또는 이미지가 없을 때) 채워지는 단색 |
| `background-image` | 배경으로 쓸 이미지 또는 그라디언트 |
| `background-position` | 배경 이미지가 박스 안 어디에서 시작할지 |
| `background-size` | 배경 이미지를 얼마나 늘리거나 줄일지 |
| `background-repeat` | 이미지가 박스보다 작을 때 반복할지 여부와 방향 |

```css
.hero {
  background-color: #1e293b;                 /* 이미지 로드 전·실패 시 대비색 */
  background-image: url('/hero.jpg');
  background-position: center;                /* 이미지 중앙을 박스 중앙에 맞춤 */
  background-size: cover;                     /* 박스를 빈틈없이 채우도록 확대·축소 */
  background-repeat: no-repeat;               /* 반복하지 않음 */
}
```

`background-size`의 `cover`와 `contain`은 특히 자주 헷갈립니다.

| 값 | 동작 | 결과 |
|-----|------|------|
| `cover` | 이미지의 가로세로 비율을 유지하며 박스를 **완전히 채울 때까지** 확대 | 이미지 일부가 박스 밖으로 잘려 나갈 수 있음 |
| `contain` | 이미지의 가로세로 비율을 유지하며 박스 안에 **완전히 들어갈 때까지만** 확대 | 박스에 여백(빈 공간)이 남을 수 있음 |

## 4. 그라디언트 — 색과 색 사이를 서서히 잇는 배경 이미지

**그라디언트**(gradient, 그러데이션)는 하나의 배경 이미지처럼 취급되는 값으로, `background-image`에 씁니다. 별도의 이미지 파일 없이 색이 서서히 바뀌는 배경을 만들 수 있습니다.

### 선형 그라디언트 — 직선 방향으로

```css
.banner {
  background-image: linear-gradient(to right, #6366f1, #ec4899);
}
```

`to right`는 "왼쪽에서 오른쪽으로" 색이 변한다는 방향 지정입니다. 각도(`45deg` 등)로도 방향을 줄 수 있고, 색 정지점(color stop)을 세 개 이상 나열해 여러 색을 순서대로 지날 수도 있습니다.

```css
.rainbow-ish {
  background-image: linear-gradient(90deg, #ef4444 0%, #eab308 50%, #22c55e 100%);
}
```

### 원형 그라디언트 — 중심에서 바깥으로

```css
.spotlight {
  background-image: radial-gradient(circle, #fef08a 0%, #1e293b 70%);
}
```

`radial-gradient()`는 지정한 중심점에서 시작해 원(또는 타원) 모양으로 바깥까지 색이 퍼져 나갑니다.

## 핵심 정리

- 색은 키워드·16진수·`rgb()`·`hsl()` 네 가지 방식으로 표기할 수 있으며, 모두 같은 색 공간(RGB 또는 그것을 각도·퍼센트로 바꿔 표현한 HSL)을 가리키는 다른 언어일 뿐이다. `hsl()`은 색조를 유지한 채 명도만 조절하기 편해 hover 색 등에 자주 쓰인다.
- `currentColor`는 요소의 계산된 `color` 값을 다른 속성에서 그대로 재사용하는 키워드로, 부모의 `color`가 바뀌면 이를 참조하는 자식 속성도 함께 바뀐다.
- `background`는 색·이미지·위치·크기·반복이라는 하위 속성을 합친 축약형이다. `background-size: cover`는 박스를 빈틈없이 채우며 이미지를 자를 수 있고, `contain`은 이미지를 통째로 넣되 여백이 남을 수 있다.
- 그라디언트는 색이 아니라 배경 이미지 값이며, `linear-gradient()`는 직선 방향으로, `radial-gradient()`는 중심에서 바깥으로 색이 퍼진다.
