## 왜 필요한가

20편에서 컨테이너 속성을, 21편에서 아이템 속성을 따로 배웠지만, 실무 화면은 이 속성들을 **여러 개 동시에 조합**해야 완성됩니다. 예를 들어 네비게이션 바 하나에도 `display: flex`, `justify-content`, `align-items`, 그리고 특정 메뉴 항목의 `margin-left: auto`까지 한꺼번에 얽혀 있습니다. 속성을 개별적으로 아는 것과, 그 속성들을 조합해 실제 화면을 짜는 것 사이에는 거리가 있습니다.

> **쉽게 말하면:** 이번 편은 "단어(개별 속성)"에서 "문장(실전 조합)"으로 넘어가는 연습입니다.

## 패턴 1 — 네비게이션 바

네비게이션 바는 로고·메뉴·부가 버튼이 가로 한 줄에 늘어서면서, 서로 다른 그룹은 좌우로 벌어져야 하는 전형적인 요구입니다.

```css
.navbar {
  display: flex;
  align-items: center;         /* 로고·메뉴 텍스트 높이가 달라도 세로 중앙 정렬 */
  justify-content: space-between; /* 왼쪽 그룹과 오른쪽 그룹을 양 끝으로 */
  padding: 0 24px;
}
.navbar .menu {
  display: flex;   /* 메뉴 항목들도 flex 컨테이너로 만들어 가로 나열 */
  gap: 16px;        /* 항목 사이 간격 — flex 컨테이너 안에서도 gap 사용 가능 */
}
```

여기서 중요한 관찰은 **flex 컨테이너를 중첩**했다는 점입니다. `.navbar` 자체도 flex 컨테이너이고, 그 자식인 `.menu`도 다시 flex 컨테이너입니다. Flexbox는 이렇게 자유롭게 중첩할 수 있으며, 각 레벨은 자신의 직계 자식만 영향을 미칩니다(20편에서 확인한 것처럼).

로그인 상태에 따라 오른쪽에 버튼 하나만 추가로 붙이고 싶다면, 21편에서 배운 `margin-left: auto`를 그 버튼에 주는 방법도 있습니다. `justify-content: space-between`과 `margin-left: auto`는 둘 다 "그룹을 벌린다"는 목적에서 비슷해 보이지만, `space-between`은 컨테이너 전체의 정렬 규칙이고 `margin-left: auto`는 특정 아이템 하나에 붙는 개별 규칙이라는 차이가 있습니다. 아이템이 셋 이상이고 그중 일부만 오른쪽으로 몰아야 한다면 `margin-left: auto`가 더 정밀합니다.

## 패턴 2 — 미디어 객체(이미지 + 텍스트)

**미디어 객체**(media object)는 아바타나 썸네일 같은 고정 크기 이미지 옆에 가변 길이 텍스트가 붙는 구성입니다. 댓글 목록, 알림 목록, 프로필 카드에서 반복적으로 나타납니다.

```css
.media {
  display: flex;
  gap: 12px;
  align-items: flex-start; /* 이미지와 텍스트 첫 줄을 위쪽 기준으로 정렬 */
}
.media__image {
  flex: 0 0 48px;  /* 절대 늘어나지도 줄어들지도 않는 고정 크기(21편 참조) */
  width: 48px;
  height: 48px;
  border-radius: 50%;
}
.media__body {
  flex: 1 1 0;      /* 남는 공간을 전부 차지하며, 텍스트가 길면 줄바꿈된다 */
}
```

여기서 이미지에 `flex: 0 0 48px`을 준 이유가 핵심입니다. `flex-grow: 0`으로 늘어나지 않게, `flex-shrink: 0`으로 줄어들지 않게 고정해, 옆의 텍스트가 아무리 길어져도 이미지 크기가 흔들리지 않도록 못 박은 것입니다. 반대로 `.media__body`에는 `flex: 1 1 0`을 주어 나머지 공간을 전부 흡수하게 했습니다. 이 조합이 없으면(즉 이미지에 `flex-shrink`가 기본값 `1`로 남아 있으면) 텍스트가 아주 길어졌을 때 이미지까지 함께 찌그러드는 문제가 생깁니다.

## 패턴 3 — 카드 정렬과 콘텐츠 길이 함정

카드 여러 장을 가로로 나열할 때 자주 겪는 문제가 있습니다. 카드마다 제목 줄 수가 달라, 버튼이 카드마다 다른 높이에 놓이는 것입니다.

```css
.card-list {
  display: flex;
  gap: 16px;
}
.card {
  display: flex;
  flex-direction: column; /* 카드 내부를 세로로 쌓는 별도의 flex 컨테이너 */
  flex: 1 1 0;             /* 카드들이 가로 폭을 균등하게 나눠 가짐 */
}
.card__button {
  margin-top: auto; /* 세로 방향 flex 컨테이너 안에서는 margin-top: auto가 아래로 밀어낸다 */
}
```

`.card`를 `flex-direction: column`인 flex 컨테이너로 만들고, 버튼에 `margin-top: auto`를 주면 제목이 한 줄이든 세 줄이든 상관없이 버튼이 항상 카드 맨 아래에 붙습니다. 자동 마진은 21편에서 가로 방향으로만 봤지만, `flex-direction: column`일 때는 세로 방향 남는 공간을 흡수하는 방식으로 똑같이 동작합니다. **자동 마진이 흡수하는 것은 항상 "메인 축 방향"의 남는 공간**이라는 원리를 기억하면 방향이 바뀌어도 헷갈리지 않습니다.

## 접근성 관점

세 패턴 모두 시각적 배치를 바꾸는 것이지 문서의 논리 구조를 바꾸는 것이 아닙니다. 네비게이션 바를 짤 때는 `<nav>` 요소로 감싸고 메뉴는 `<ul>`/`<li>` 목록으로 마크업해 스크린 리더가 "탐색 랜드마크"와 "항목 개수"를 안내할 수 있게 하는 것이 Flexbox 스타일링보다 우선입니다(이 마크업 규칙 자체는 `html/html_fundamentals` 과목 참조). 미디어 객체 패턴에서는 아바타 이미지에 의미 있는 정보가 없다면 `alt=""`로 처리해 스크린 리더가 불필요하게 읽지 않도록 하는 것이 좋습니다. 카드 목록에서 자동 마진으로 버튼 위치를 맞추는 것은 순수하게 시각적인 조정이므로 접근성 트리나 읽는 순서에는 영향을 주지 않습니다.

## 자주 틀리는 점

- **미디어 객체에서 이미지에 `flex-shrink: 0`을 빠뜨려, 텍스트가 길어지면 이미지까지 찌그러드는 것.** 고정 크기를 유지해야 하는 아이템에는 반드시 `flex-shrink: 0`(또는 `flex: 0 0 크기`)을 명시해야 합니다.
- **`flex-direction: column`에서 자동 마진이 세로 방향으로 작동한다는 것을 모르고, 가로 방향에서만 쓰인다고 오해하는 것.** 자동 마진은 항상 메인 축 방향의 남는 공간을 흡수하므로, 축 방향이 바뀌면 자동 마진이 미는 방향도 바뀝니다.
- **컨테이너를 중첩할 때, 바깥 컨테이너의 정렬 속성이 안쪽 컨테이너의 자식에게까지 영향을 준다고 착각하는 것.** `justify-content`·`align-items`는 항상 직계 자식에게만 적용되므로, 안쪽 flex 컨테이너는 자신만의 정렬 속성을 별도로 지정해야 합니다.

## 핵심 정리

- 네비게이션 바는 `justify-content: space-between`(그룹 전체 정렬) 또는 `margin-left: auto`(개별 아이템 정렬)로 좌우를 벌린다.
- 미디어 객체는 고정 크기 요소에 `flex-shrink: 0`을, 가변 크기 요소에 `flex: 1 1 0`을 주어 콘텐츠 길이 변화에도 레이아웃이 무너지지 않게 한다.
- 카드처럼 세로로 쌓는 레이아웃에서는 `flex-direction: column` 컨테이너 안의 `margin-top: auto`로 버튼 같은 요소를 항상 맨 아래에 고정할 수 있다.
- 자동 마진이 흡수하는 방향은 항상 메인 축 방향이며, 축 방향이 바뀌면 미는 방향도 함께 바뀐다.
