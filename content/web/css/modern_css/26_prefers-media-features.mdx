<Callout type="info">
  **이번 문서의 목표:** 이 문서를 다 읽으면 `prefers-reduced-motion`·`prefers-color-scheme`·`prefers-contrast`·`prefers-reduced-data` 네 가지 사용자 선호 미디어 기능을 구분해 설명하고, 이를 활용해 "물어보지 않아도 사용자의 환경 설정을 존중하는" CSS를 작성할 수 있게 됩니다.
</Callout>

## 왜 필요한가

지금까지 다룬 미디어 쿼리(media query, CSS Fundamentals 범위)는 대부분 화면 폭 같은 **기기의 물리적 특성**을 물었습니다. 그런데 사용자의 운영체제나 브라우저에는 화면 크기와 무관한 또 다른 설정이 있습니다. "애니메이션을 줄여줘", "어두운 화면을 써줘", "글자와 배경 대비를 더 세게 해줘", "데이터를 아껴줘" 같은 **개인 선호 설정**입니다.

이런 설정은 대개 접근성 설정(설정 앱의 손쉬운 사용·접근성 메뉴)에서 켭니다. 전정 기능(vestibular system, 몸의 균형을 담당하는 내이 감각 기관) 장애가 있는 사용자는 화면이 크게 움직이는 애니메이션에 어지러움이나 메스꺼움을 느낄 수 있습니다. 저시력 사용자는 기본 대비로는 글자를 읽기 어려울 수 있습니다. 이런 설정을 웹사이트가 무시하고 화려한 애니메이션과 낮은 대비의 디자인을 강행하면, 그 사용자에게는 사이트가 아예 쓸 수 없는 상태가 됩니다.

> **쉽게 말하면:** `prefers-*`(선호-무엇)로 시작하는 미디어 기능들은 "운영체제 설정에서 사용자가 무엇을 원한다고 미리 답했는지"를 CSS가 물어보는 창구입니다. 사용자에게 다시 묻지 않고도 그 답을 존중할 수 있습니다.

## 1. prefers-reduced-motion — 움직임을 줄여 달라는 요청

### 정의

`prefers-reduced-motion`(모션 줄임 선호)은 사용자가 운영체제에서 "동작 줄이기"류 설정을 켰는지 알려줍니다.

| 값 | 의미 |
|---|---|
| `no-preference` | 특별히 설정하지 않음(기본값) |
| `reduce` | 움직임을 최소화해 달라는 설정을 켬 |

```css
.hero-banner {
  animation: slide-in 0.6s ease-out;
}

@media (prefers-reduced-motion: reduce) {
  .hero-banner {
    animation: none;
  }
}
```

애니메이션을 완전히 없애기보다, **의미 전달에 필요한 최소한의 상태 변화**(예: 페이드인 정도)만 남기고 회전·확대·자동 재생 캐러셀 같은 큰 움직임만 제거하는 것이 더 나은 경우가 많습니다.

<Callout type="warning">
  **자주 틀리는 점:** `prefers-reduced-motion: reduce`를 "애니메이션을 아예 쓰면 안 된다"로 오해하기 쉽습니다. 실제로는 "불필요하게 큰 움직임을 줄여 달라"는 요청입니다. 로딩 스피너처럼 정보 전달에 꼭 필요한 최소한의 움직임까지 없앨 필요는 없습니다.
</Callout>

## 2. prefers-color-scheme — 밝은 화면과 어두운 화면

### 정의

`prefers-color-scheme`(색 배색 선호)은 사용자가 운영체제 수준에서 라이트 모드와 다크 모드 중 무엇을 쓰는지 알려줍니다.

| 값 | 의미 |
|---|---|
| `light` | 밝은 배색을 선호 |
| `dark` | 어두운 배색을 선호 |

```css
body {
  background: white;
  color: black;
}

@media (prefers-color-scheme: dark) {
  body {
    background: black;
    color: white;
  }
}
```

이 미디어 기능은 17편에서 다룬 `color-scheme` 속성·`light-dark()` 함수와 짝을 이룹니다. `color-scheme: light dark`를 선언해 두면 브라우저 기본 UI(스크롤바, 폼 컨트롤 테두리 등)도 함께 전환되고, `light-dark()`로 값 두 개를 한 번에 지정할 수 있습니다. `prefers-color-scheme`는 "지금 사용자 환경이 어느 쪽인가"를 **판별**하는 미디어 쿼리이고, `light-dark()`는 그 판별 결과에 따라 **값을 고르는** 함수라는 역할 차이가 있습니다. 자세한 설계 패턴은 17편을 참조하세요.

## 3. prefers-contrast — 대비를 더 세게 또는 약하게

### 정의

`prefers-contrast`(대비 선호)는 사용자가 시스템에서 고대비 모드 같은 설정을 켰는지 알려줍니다.

| 값 | 의미 |
|---|---|
| `no-preference` | 기본값 |
| `more` | 더 강한 대비를 원함 |
| `less` | 더 약한(부드러운) 대비를 원함 |
| `custom` | 시스템이 커스텀 색상표를 강제하는 등 표준 대비 단계로 분류되지 않는 상태 |

```css
.button {
  border: 1px solid #999;
}

@media (prefers-contrast: more) {
  .button {
    border: 2px solid black;
  }
}
```

저시력 사용자나 눈부심에 민감한 사용자를 위한 설정입니다. `more`일 때 테두리를 굵게 하거나 글자와 배경의 명도 차이를 키우고, `less`일 때는 과도하게 쨍한 배색을 눈에 편하게 낮춰주는 식으로 응답합니다.

## 4. prefers-reduced-data — 데이터를 아껴 달라는 요청

### 정의

`prefers-reduced-data`(데이터 절약 선호)는 사용자가 브라우저나 네트워크 설정에서 데이터 절약 모드를 켰는지 알려줍니다.

| 값 | 의미 |
|---|---|
| `no-preference` | 기본값 |
| `reduce` | 데이터 사용을 줄여 달라는 설정을 켬 |

```css
.hero-video {
  background-image: url('hero-poster.jpg');
}

@media (prefers-reduced-data: reduce) {
  .hero-video {
    background-image: none; /* 배경 동영상 대신 단색이나 저용량 이미지로 대체 */
  }
}
```

모바일 데이터 요금이 부담스러운 사용자나 네트워크가 느린 환경의 사용자를 위한 설정입니다. 배경 동영상, 고해상도 배경 이미지, 자동 재생 미디어처럼 용량이 큰 리소스를 CSS 단계에서부터 아예 불러오지 않게 만들 수 있습니다.

## 네 가지 비교

| 미디어 기능 | 무엇을 묻는가 | 대표 대응 |
|---|---|---|
| `prefers-reduced-motion` | 움직임을 줄여야 하는가 | 애니메이션 제거·축소 |
| `prefers-color-scheme` | 밝은가 어두운가 | 배색 전환(17편의 `light-dark()`와 연동) |
| `prefers-contrast` | 대비를 세게 또는 약하게 | 테두리·명도 차이 조정 |
| `prefers-reduced-data` | 데이터를 아껴야 하는가 | 무거운 배경 리소스 생략 |

네 기능 모두 2026년 9월 기준 **널리 사용 가능**(Baseline: Widely available)한 접근성 기본기입니다. 오래전에 안정화되어 폴백 걱정 없이 바로 써도 됩니다.

<Callout type="warning">
  **자주 틀리는 점:** `prefers-*` 미디어 쿼리는 자바스크립트로 감지하려면 `window.matchMedia('(prefers-reduced-motion: reduce)')`처럼 별도 API가 필요합니다. CSS의 `@media` 블록과 자바스크립트의 `matchMedia`는 같은 조건을 읽지만 서로 다른 코드로, 애니메이션을 CSS `transition`/`animation`이 아니라 자바스크립트로 직접 구현했다면 CSS `@media` 블록만으로는 그 자바스크립트 애니메이션을 막을 수 없습니다.
</Callout>

## 핵심 정리

- `prefers-*` 미디어 기능은 사용자가 운영체제·브라우저에 미리 설정해 둔 접근성 선호를 CSS가 읽는 창구다.
- `prefers-reduced-motion: reduce`는 움직임을 완전히 없애라는 뜻이 아니라 불필요하게 큰 움직임을 줄이라는 요청이다.
- `prefers-color-scheme`은 라이트/다크를 판별하고, 17편의 `light-dark()`·`color-scheme`과 짝을 이뤄 다크모드를 구현한다.
- `prefers-contrast`는 저시력·눈부심 민감 사용자를 위한 대비 조정, `prefers-reduced-data`는 데이터 절약을 위한 리소스 생략에 쓰인다.
- 네 기능 모두 널리 사용 가능한 기본기이므로 폴백 없이 바로 도입할 수 있다.
