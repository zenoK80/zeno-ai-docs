## 개념 정리

### HTML·CSS·JS는 왜 나뉘어 있는가

웹 페이지 하나는 세 가지 언어가 각자 다른 역할을 맡아 만듭니다.

| 언어 | 역할 |
|------|------|
| HTML | 구조와 의미(제목인지, 목록인지, 표인지) |
| CSS | 색·레이아웃·타이포 같은 모양 |
| JavaScript | 클릭·입력 같은 동작 |

모양이 없어도 구조와 의미만으로 콘텐츠를 전달할 수 있는지 확인하는 것이 목표입니다.

### HTML 요소란 무엇인가(예고)

HTML 문서는 **요소**(element)로 이루어집니다. 요소는 보통 여는 태그·내용·닫는 태그로 구성됩니다. 예를 들어 문단 요소는 `<p>내용</p>` 형태입니다. 태그의 정확한 문법(속성값 인용, 빈 요소 등)은 02편에서 다룹니다.
