## 개념 정리

### 원시 타입 7종

JavaScript의 값은 원시(primitive) 타입 7종과 객체(object) 타입으로 나뉩니다. `typeof` 연산자로 확인합니다.

| 값 예시 | typeof 결과 |
|---------|-------------|
| `'study'` | `string` |
| `42` | `number` |
| `true` | `boolean` |
| `undefined` | `undefined` |
| `null` | `object` (역사적 버그로 남은 예외) |
| `10n` | `bigint` |
| `Symbol('id')` | `symbol` |

`null`의 `typeof`가 `object`로 나오는 것은 JavaScript 초기 구현의 버그가 표준으로 굳어진 결과입니다. 값이 없음을 표현할 때 `null`인지 `undefined`인지는 나중에 저장 로직(08편)에서 구분해 씁니다.

### process.argv

Node.js는 터미널에서 받은 명령행 인자를 `process.argv` 배열로 제공합니다.

```text
node src/index.js add "할일 내용" --tag study
```

| 인덱스 | 값 | 설명 |
|--------|-----|------|
| `0` | node 실행 파일 경로 | 보통 사용하지 않음 |
| `1` | 실행 중인 스크립트 경로 | 보통 사용하지 않음 |
| `2` | `add` | 실제 명령 |
| `3` | `할일 내용` | 첫 번째 인자 |
| `4` | `--tag` | 플래그 이름 |
| `5` | `study` | 플래그 값 |

앞의 두 항목은 항상 실행 정보라서 `process.argv.slice(2)`로 잘라내고 실제 인자만 다룹니다.

### 값은 모두 문자열이다

`process.argv`의 모든 원소는 **문자열**입니다. `--due 2026-09-20`을 받아도 값은 숫자가 아니라 문자열 `'2026-09-20'`입니다. 숫자로 써야 할 때는 `Number()`나 `parseInt()`로 직접 변환해야 합니다. 이 편에서는 값을 그대로 문자열로 저장하고, 실제 날짜 계산은 12편(Date·Intl)에서 다룹니다.

### 타입 변환 방법 비교

| 방법 | 예시 | 결과 | 특이사항 |
|------|------|------|----------|
| `Number(값)` | `Number('42')` | `42` | 변환 실패 시 `NaN` |
| `parseInt(값, 10)` | `parseInt('42px', 10)` | `42` | 앞부분 숫자만 읽고 나머지 무시 |
| `String(값)` | `String(42)` | `'42'` | 숫자를 문자열로 되돌릴 때 사용 |

`typeof NaN`은 `'number'`입니다. `NaN`도 숫자 타입의 값이며, `Number.isNaN()`으로 확인해야 합니다.

## 실습

<Steps>

### 1. 인자 파서 파일 만들기

`src/cli/` 폴더를 만들고 `parseArgs.js` 파일을 추가합니다.

### 2. 코드 작성

```js
// src/cli/parseArgs.js
export function parseArgs(argv) {
  const [command, ...rest] = argv;
  const positional = [];
  const flags = {};

  for (let i = 0; i < rest.length; i += 1) {
    const token = rest[i];
    if (token.startsWith('--')) {
      const key = token.slice(2);
      const value = rest[i + 1];
      flags[key] = value;
      i += 1;
    } else {
      positional.push(token);
    }
  }

  return { command, positional, flags };
}
```

`--`로 시작하는 토큰은 플래그 이름으로, 그다음 토큰은 플래그 값으로 취급합니다. 그 외 토큰은 위치 인자(`positional`)로 모읍니다.

```js
// src/index.js
import { parseArgs } from './cli/parseArgs.js';

const argv = process.argv.slice(2);
const parsed = parseArgs(argv);

console.log('명령:', parsed.command, typeof parsed.command);
console.log('위치 인자:', parsed.positional);
console.log('플래그:', parsed.flags);
```

### 3. 실행

```text
node src/index.js add "할일 내용" --tag study --due 2026-09-20
```

### 4. 확인

</Steps>

- 아래처럼 출력되면 성공입니다.

```text
명령: add string
위치 인자: [ '할일 내용' ]
플래그: { tag: 'study', due: '2026-09-20' }
```

- `node src/index.js`를 인자 없이 실행하면 `명령: undefined undefined`가 출력됩니다. `typeof undefined`가 문자열 `"undefined"`임을 확인합니다.

## 직접 해보기

1. `--tag`와 `--due`의 순서를 바꿔 실행해도 같은 결과가 나오는지 확인합니다.
2. `node src/index.js list --page 2`를 실행해 `positional`이 빈 배열이고 `flags.page`가 문자열 `'2'`(숫자 아님)임을 확인합니다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| `positional`에 플래그 값까지 섞여 들어감 | 반복문에서 `i += 1`(값 건너뛰기)을 빠뜨림 | 플래그를 만난 다음 루프에서 인덱스를 한 칸 더 건너뛴다 |
| 숫자 비교가 항상 실패함 | `flags.due`가 문자열인데 숫자와 비교함 | 비교 전에 `Number()`로 변환하거나 문자열끼리 비교한다 |
| 따옴표 없는 여러 단어 인자가 쪼개짐 | `add 할일 내용`처럼 따옴표 없이 입력 | 공백이 있는 인자는 반드시 큰따옴표로 감싼다 |
