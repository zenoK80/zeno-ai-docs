## 문제를 푸는 기준

현재 원소만 보지 말고 이전까지 무엇을 기억해야 하는지 정합니다. 상태를 최소화하면 중첩 반복 없이 한 번의 순회로 끝낼 수 있습니다.

## 핵심 개념

| 개념 | 코딩테스트에서의 역할 |
|---|---|
| 인덱스 | 현재 위치와 이전·다음 위치의 관계를 나타냅니다. |
| 누적 상태 | 합, 최댓값, 개수처럼 순회 중 갱신할 값을 저장합니다. |
| 연속 구간 | 값이 바뀌는 지점에서 지금까지의 그룹을 확정합니다. |

## 대표 문제

### 연속 문자 압축

영문 소문자 문자열 text에서 같은 문자가 연속한 개수를 문자 뒤에 붙인 문자열을 반환하세요. 빈 문자열은 그대로 반환합니다.

**함수 시그니처:** `solution(text)`

### 제한사항

- text의 길이는 0 이상 200,000 이하입니다.
- 떨어져 있는 같은 문자는 다른 그룹입니다.

### 입출력 예

| 매개변수 | 반환값 |
|---|---|
| `aaabbc` | `a3b2c1` |
| `` | `` |

### 풀이 설계

1. 첫 문자를 현재 그룹으로 잡습니다.
2. 같은 문자가 이어지면 count를 늘립니다.
3. 문자가 바뀌면 이전 그룹을 확정하고 마지막 그룹도 반복 뒤 붙입니다.

### JavaScript 풀이

```js
function solution(text) {
  if (text.length === 0) return '';
  let result = '';
  let current = text[0];
  let count = 1;
  for (let i = 1; i < text.length; i += 1) {
    if (text[i] === current) count += 1;
    else {
      result += current + count;
      current = text[i];
      count = 1;
    }
  }
  return result + current + count;
}
```

### 복잡도

- 시간복잡도: `O(n)`
- 공간복잡도: `O(n)`
- 핵심 패턴: 값이 바뀌는 경계에서 이전 그룹 확정
- 경계 사례: 빈 문자열과 마지막 그룹을 별도 처리

## 자주 하는 실수

- 빈 문자열에서 첫 문자를 바로 읽는 실수
- 문자가 바뀔 때 count를 초기화하지 않는 실수
- 마지막 그룹을 누락하는 실수
- 원본 배열 변경 여부를 확인하지 않는 실수

## 핵심 정리

- 예시와 경계 사례를 손으로 추적한 뒤 구현합니다.
- 완성한 `solution` 함수가 입력을 불필요하게 바꾸지 않는지도 확인합니다.
