## 문제를 푸는 기준

같은 값을 반복해서 찾는다면 조회 구조를 먼저 만듭니다. 빈도와 추가 정보가 필요하면 Map, 존재 여부만 필요하면 Set이 자연스럽습니다.

## 핵심 개념

| 개념 | 코딩테스트에서의 역할 |
|---|---|
| Map | 키마다 개수나 부가 정보를 저장합니다. |
| Set | 값의 존재 여부와 중복 제거에 사용합니다. |
| 동률 규칙 | 최댓값이 같을 때 선택 기준을 명시합니다. |

## 대표 문제

### 가장 자주 등장한 코드

영문 소문자 코드 배열 codes에서 가장 많이 등장한 코드를 반환하세요. 빈도가 같으면 사전순으로 앞선 코드를 반환합니다.

**함수 시그니처:** `solution(codes)`

### 제한사항

- codes의 길이는 1 이상 200,000 이하입니다.
- 각 코드는 길이 1 이상 20 이하입니다.

### 입출력 예

| 매개변수 | 반환값 |
|---|---|
| `[b, a, b, c, a]` | `a` |
| `[z, z, a]` | `z` |

### 풀이 설계

1. Map으로 코드별 빈도를 셉니다.
2. 항목을 순회하며 더 큰 빈도를 선택합니다.
3. 빈도가 같으면 사전순을 비교합니다.

### JavaScript 풀이

```js
function solution(codes) {
  const counts = new Map();
  for (const code of codes) counts.set(code, (counts.get(code) ?? 0) + 1);
  let answer = '';
  let bestCount = -1;
  for (const [code, count] of counts) {
    if (count > bestCount || (count === bestCount && code.localeCompare(answer) < 0)) {
      answer = code;
      bestCount = count;
    }
  }
  return answer;
}
```

### 복잡도

- 시간복잡도: `O(n)`
- 공간복잡도: `O(n)`
- 핵심 패턴: Map 빈도표 뒤 최댓값과 동률 규칙 적용
- 경계 사례: 최고 빈도가 같으면 사전순 규칙 적용
