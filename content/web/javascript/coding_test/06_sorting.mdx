## 문제를 푸는 기준

정렬은 답 자체가 아니라 관계를 단순하게 만드는 전처리입니다. 이후에는 현재 후보와 다음 원소를 한 번씩 비교합니다.

## 핵심 개념

| 개념 | 코딩테스트에서의 역할 |
|---|---|
| 비교 함수 | 숫자 오름차순은 `(a, b) => a - b`를 사용합니다. |
| 복사 정렬 | 원본 보존이 필요하면 복사본을 정렬합니다. |
| 인접 관계 | 정렬 뒤 겹침과 차이를 이웃끼리 확인합니다. |

## 대표 문제

### 겹치는 예약 구간 합치기

구간 배열 intervals에서 겹치거나 맞닿은 구간을 모두 합쳐 시작 시각 오름차순으로 반환하세요.

**함수 시그니처:** `solution(intervals)`

### 제한사항

- intervals의 길이는 0 이상 100,000 이하입니다.
- 각 구간에서 시작은 종료 이하입니다.

### 입출력 예

| 매개변수 | 반환값 |
|---|---|
| `[[1,3],[2,5],[8,10]]` | `[[1,5],[8,10]]` |
| `[]` | `[]` |

### 풀이 설계

1. 구간 복사본을 시작 시각 기준으로 정렬합니다.
2. 결과의 마지막 구간과 현재 구간을 비교합니다.
3. 겹치면 종료를 늘리고 아니면 새 구간을 추가합니다.

### JavaScript 풀이

```js
function solution(intervals) {
  if (intervals.length === 0) return [];
  const sorted = intervals.map(([s, e]) => [s, e]).sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  const merged = [sorted[0]];
  for (let i = 1; i < sorted.length; i += 1) {
    const last = merged[merged.length - 1];
    const [start, end] = sorted[i];
    if (start <= last[1]) last[1] = Math.max(last[1], end);
    else merged.push([start, end]);
  }
  return merged;
}
```

### 복잡도

- 시간복잡도: `O(n log n)`
- 공간복잡도: `O(n)`
- 핵심 패턴: 정렬 뒤 마지막 확정 구간과 현재 구간 비교
- 경계 사례: 빈 배열과 끝점이 같은 구간 처리
