## 개념 정리

### Vite가 하는 일

Vite는 개발 서버와 빌드 도구입니다. `npm create vite`는 이런 설정이 이미 끝난 프로젝트 템플릿을 만들어 줍니다.

### 생성되는 폴더 구조

| 경로 | 역할 |
|------|------|
| `index.html` | 앱의 유일한 HTML 문서. `<div id="root">`에 React가 화면을 그린다 |
| `src/main.jsx` | 진입점. `App` 컴포넌트를 `#root`에 렌더링한다 |
| `src/App.jsx` | 최상위 컴포넌트. 이 과목 내내 여기서부터 화면을 구성한다 |
| `src/index.css` | 전역 스타일 |
| `package.json` | 의존 패키지 목록과 `dev`/`build`/`preview` 스크립트 |
| `vite.config.js` | Vite 설정(React 플러그인 등록) |

### package.json 스크립트

| 스크립트 | 역할 |
|------|------|
| `npm run dev` | 개발 서버 실행(HMR 지원, 로컬에서만 접근 가능) |
| `npm run build` | 배포용 정적 파일을 `dist/`에 생성 |
| `npm run preview` | `build` 결과물을 로컬에서 미리 확인 |

`npm create vite`를 실행한 시점에 더 새 버전이 설치되면 그 버전을 그대로 사용합니다.
