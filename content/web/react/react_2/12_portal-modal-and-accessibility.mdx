## 개념 정리

모달은 보통 화면 전체를 덮어야 합니다. 컴포넌트 트리 안 깊숙한 곳(예: `BookDetailPage` 안)에서 렌더링하면 부모 요소의 `overflow: hidden`이나 `z-index` 쌓임 맥락에 갇힐 수 있습니다. `createPortal(children, domNode)`은 컴포넌트 트리상의 위치는 그대로 두면서 실제 DOM은 다른 위치(보통 `document.body` 바로 아래)에 렌더링합니다. React 이벤트 버블링과 Context는 트리 위치를 기준으로 동작하므로, 포털로 옮겨도 부모의 이벤트 핸들러나 Context는 그대로 유지됩니다.

모달을 열었을 때 키보드로만 쓸 수 있어야 합니다. WAI-ARIA Dialog(Modal) 패턴이 요구하는 최소 조건은 다음과 같습니다.

| 요구 사항 | 구현 방법 |
|-----------|-----------|
| 모달임을 알림 | `role="dialog"`, `aria-modal="true"` |
| 제목과 연결 | `aria-labelledby`로 제목 요소 id 참조 |
| 포커스 트랩 | `Tab`/`Shift+Tab`이 모달 안 요소만 순환 |
| `Esc`로 닫기 | `keydown` 이벤트에서 `Escape` 감지 |
| 포커스 복귀 | 닫힐 때 모달을 연 트리거 요소로 포커스 이동 |
| 열릴 때 포커스 이동 | 모달이 열리면 내부 요소(보통 첫 버튼)로 포커스 이동 |

포커스 트랩이 없으면 `Tab`을 눌렀을 때 포커스가 모달 뒤 화면 요소로 빠져나가, 스크린 리더 사용자와 키보드 사용자가 모달 밖 요소를 조작하게 됩니다.

<Steps>

### 1. Modal 컴포넌트 작성

```jsx
// src/components/Modal.jsx
import { useEffect, useRef } from 'react';
import { createPortal } from 'react-dom';

function Modal({ titleId, title, onClose, children }) {
  const dialogRef = useRef(null);
  const triggerRef = useRef(document.activeElement);

  useEffect(() => {
    const dialogNode = dialogRef.current;
    const focusableSelector = 'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])';
    const focusableElements = dialogNode.querySelectorAll(focusableSelector);
    const firstElement = focusableElements[0];
    const lastElement = focusableElements[focusableElements.length - 1];

    firstElement?.focus();

    function handleKeyDown(e) {
      if (e.key === 'Escape') {
        onClose();
        return;
      }

      if (e.key !== 'Tab') {
        return;
      }

      // Shift+Tab이 첫 요소에서 마지막으로, Tab이 마지막에서 첫 요소로 순환하도록 막습니다.
      if (e.shiftKey && document.activeElement === firstElement) {
        e.preventDefault();
        lastElement.focus();
      } else if (!e.shiftKey && document.activeElement === lastElement) {
        e.preventDefault();
        firstElement.focus();
      }
    }

    dialogNode.addEventListener('keydown', handleKeyDown);

    return () => {
      dialogNode.removeEventListener('keydown', handleKeyDown);
      triggerRef.current?.focus();
    };
  }, [onClose]);

  return createPortal(
    <div className="modal-overlay" onClick={onClose}>
      <div
        ref={dialogRef}
        className="modal-dialog"
        role="dialog"
        aria-modal="true"
        aria-labelledby={titleId}
        onClick={(e) => e.stopPropagation()}
      >
        <h2 id={titleId}>{title}</h2>
        {children}
      </div>
    </div>,
    document.getElementById('modal-root')
  );
}

export default Modal;
```

`onClick={onClose}`를 오버레이에 달고, 다이얼로그 내부 클릭에는 `e.stopPropagation()`을 걸어 배경 클릭만 닫기로 처리합니다. 정리 함수(`return () => ...`)에서 `triggerRef.current?.focus()`를 호출해 모달을 닫을 때 원래 포커스 위치로 되돌립니다.

`index.html`의 `<body>` 안, `#root`와 형제 위치에 `<div id="modal-root"></div>`를 추가합니다.

```html
<!-- index.html (일부) -->
<body>
  <div id="root"></div>
  <div id="modal-root"></div>
</body>
```

### 2. 상세 페이지에서 모달 연결

```jsx
// src/pages/BookDetailPage.jsx (일부)
import { useState } from 'react';
import { Link, NavLink, Outlet, useLoaderData, useNavigate, useParams } from 'react-router';
import Modal from '../components/Modal.jsx';
// ...04편의 bookDetailLoader(STORAGE_KEY 포함), STATUS_LABEL 유지

function BookDetailPage() {
  const book = useLoaderData();
  const { bookId } = useParams();
  const navigate = useNavigate();
  const [isDeleteModalOpen, setDeleteModalOpen] = useState(false);

  function handleConfirmDelete() {
    const raw = localStorage.getItem(STORAGE_KEY);
    const books = raw ? JSON.parse(raw) : [];
    const remainingBooks = books.filter((item) => String(item.id) !== String(book.id));
    localStorage.setItem(STORAGE_KEY, JSON.stringify(remainingBooks));
    setDeleteModalOpen(false);
    navigate('/');
  }

  return (
    <div className="book-detail">
      <Link to="/">목록으로</Link>
      <h1 style={{ borderLeftColor: book.coverColor }}>{book.title}</h1>
      <p>{book.author}</p>

      <button type="button" onClick={() => setDeleteModalOpen(true)}>
        삭제
      </button>

      {isDeleteModalOpen && (
        <Modal
          titleId="delete-confirm-title"
          title="책을 삭제할까요"
          onClose={() => setDeleteModalOpen(false)}
        >
          <p>{book.title} 삭제 후에는 되돌릴 수 없습니다.</p>
          <button type="button" onClick={() => setDeleteModalOpen(false)}>
            취소
          </button>
          <button type="button" onClick={handleConfirmDelete}>
            삭제 확인
          </button>
        </Modal>
      )}

      <nav className="book-detail__nav">
        <NavLink to={`/books/${bookId}`} end>
          요약
        </NavLink>
        <NavLink to={`/books/${bookId}/memo`}>메모 전체 보기</NavLink>
      </nav>

      <Outlet context={book} />
    </div>
  );
}

export default BookDetailPage;
```

삭제 처리는 04편의 `bookDetailLoader`와 같은 `STORAGE_KEY`(`'bookshelf-books'`) 문자열을 그대로 사용해 직접 `localStorage`를 읽고 씁니다. `loader`가 아닌 이벤트 핸들러 안이므로 훅을 써도 되지만, 04편 로더와 같은 파일 안에 있는 상수를 그대로 재사용하는 편이 더 적은 수정으로 끝납니다. 저장 로직을 하나의 모듈로 다시 묶는 작업은 13편에서 `booksStorage.js`로 정리합니다.

### 4. 확인

- 상세 페이지에서 "삭제" 버튼을 클릭하면 모달이 뜨고, 포커스가 모달 안 첫 번째 버튼("취소")으로 이동합니다.
- `Tab`을 계속 누르면 "취소" → "삭제 확인" → 다시 "취소"로 순환하고 배경 요소로는 빠지지 않습니다.
- `Esc`를 누르면 모달이 닫히고, 포커스가 다시 "삭제" 버튼으로 돌아옵니다.
- 모달 바깥 어두운 영역을 클릭해도 닫힙니다. 모달 안을 클릭하면 닫히지 않습니다.
- 개발자 도구 Elements 패널에서 모달 DOM이 `#root`가 아니라 `#modal-root` 안에 있는 것을 확인합니다.

<details>
<summary>풀이 보기</summary>

```jsx
useEffect(() => {
  document.body.style.overflow = 'hidden';
  return () => {
    document.body.style.overflow = '';
  };
}, []);
```

이 effect를 기존 포커스 트랩 effect와 별도로 추가합니다. `useId()`는 React가 컴포넌트 인스턴스마다 고유한 문자열을 생성해 주므로, 같은 `Modal`을 여러 곳에서 써도 `id` 충돌이 생기지 않습니다.

</details>

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 모달이 화면에 안 보임 | `#modal-root`가 `index.html`에 없음 | `document.getElementById`가 `null`이 아닌지 확인 |
| `Tab`이 모달 밖으로 빠져나감 | 포커스 트랩 `keydown` 핸들러 누락 | 다이얼로그 요소에 `keydown` 리스너 연결 확인 |
| 모달을 닫아도 포커스가 body로 감 | 트리거 요소를 저장해 두지 않음 | 열릴 때 `document.activeElement`를 `ref`에 저장 |
| 배경 클릭 시 모달도 같이 닫힘(의도와 다름) | 다이얼로그 내부 클릭 이벤트가 오버레이까지 버블링 | 다이얼로그에 `stopPropagation` 추가 |
