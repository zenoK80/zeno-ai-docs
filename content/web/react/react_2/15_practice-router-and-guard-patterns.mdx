</Callout>

## 판단 기준

> **쉽게 말하면:** 라우터는 화면 전환 버튼 모음이 아니라, URL과 화면·데이터·권한의 대응표입니다.

- 공유·새로고침·뒤로 가기가 필요한 상태는 URL 후보다.
- 공통 껍데기는 부모 route의 layout과 `Outlet`으로 표현한다.
- 인증 가드는 사용자에게 무엇을 보여줄지 결정하지만, 서버 권한 검사를 대체하지 않는다.
- 코드 스플리팅은 사용자가 방문할 가능성이 낮고 덩치가 큰 route 경계부터 적용한다.
