## 문제를 푸는 기준

> **쉽게 말하면:** 성능 최적화는 렌더 횟수를 0으로 만드는 일이 아니라, 사용자가 기다리는 **비싼 작업**을 근거 있게 줄이는 일입니다.

먼저 React DevTools Profiler로 느린 상호작용과 비싼 컴포넌트를 찾습니다. 그다음 state 위치와 컴포넌트 경계를 고치고, 여전히 비용이 남을 때 `memo`, `useMemo`, `useCallback`을 검토합니다. 합성 패턴은 이름을 적용하는 것이 목적이 아니라 사용자가 조립할 수 있는 안전한 API를 만드는 수단입니다.
