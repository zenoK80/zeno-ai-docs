## 개념 (짧게)

지금까지의 재즈피아노 기초·중급 과정은 곡의 "본체"(코러스 하나를 처음부터 끝까지 도는 진행)를 반주하는 법 위주였습니다. 고급 과정의 솔로 피아노 어레인지(17~19편)와 트리오 실무 편에서는 곡을 "본체 앞뒤로 무엇을 붙일지"까지 설계해야 하므로, 그 설계를 표시하는 용어부터 정리합니다. 이 편은 표기 지도만 그리며, 실제로 인트로·엔딩을 "만드는 법"은 19편에서 다룹니다.

**편곡 구조의 기본 용어**

| 용어 | 뜻 | 위치 |
|---|---|---|
| 인트로(intro) | 멜로디가 나오기 전 도입부 | 곡 맨 앞 |
| 버스(verse) | 노래에서 절 부분(재즈 스탠다드에서는 도입 서술부를 가리키기도 함) | 코러스 앞(있는 곡만) |
| 코러스(chorus) | 곡의 진행 한 바퀴(AABA 32마디, 12마디 블루스 등) | 곡의 본체 |
| 아웃트로(outro) | 마지막 코러스 뒤에 붙는 마무리부 | 곡 맨 뒤 |
| 태그 엔딩(tag ending) | 마지막 몇 마디를 반복하며 마무리하는 기법 | 아웃트로 안에서 |
| 뱀프(vamp) | 짧은 구간(1–4마디)을 정해진 횟수 또는 신호가 있을 때까지 반복하는 것 | 인트로·아웃트로·간주 어디에나 |

**인트로 뱀프와 태그 엔딩의 관계**: 뱀프는 "반복 가능한 짧은 조각"을 가리키는 일반 용어이고, 태그 엔딩은 그 뱀프 개념을 곡의 맨 끝에 적용한 구체적인 기법입니다. 즉 모든 태그 엔딩은 뱀프의 일종이지만, 모든 뱀프가 태그 엔딩은 아닙니다(인트로 뱀프는 엔딩이 아닙니다). 재즈 연주에서 태그 엔딩은 보통 마지막 2~4마디(자주 마지막 ii-V-I)를 정해진 횟수(3회 등)만큼 반복하고 마지막에만 다르게 끝냅니다.

**편곡 스케치에서 마디 구간을 표시하는 관례**: 편곡자들은 전체 곡을 처음부터 끝까지 오선보로 다 그리지 않고, 구간 이름과 마디 수만 적은 스케치로 설계도를 그립니다. 아래는 자주 쓰이는 표시 관례입니다.

| 표시 | 뜻 |
|---|---|
| Intro (4) | 인트로 4마디 |
| A / A / B / A | AABA 폼에서 각 8마디 섹션을 순서대로 표시 |
| Solo (1 chorus) | 솔로 구간을 코러스 1바퀴만큼 배정 |
| Vamp (x3, then cue) | 신호(cue)가 있을 때까지 3회 이상 반복 |
| Tag (last 4, x3) | 마지막 4마디를 3회 반복하는 태그 엔딩 |
| D.C. al Coda | 처음으로 돌아가 코다(마무리 구간) 표시까지 연주 |
| D.S. al Fine | 세뇨(segno) 표시로 돌아가 Fine까지 연주 |

**반복 기호와 편곡 용어의 관계**: D.C.(다카포), D.S.(달세뇨), Coda, Fine 같은 반복 기호는 이미 리드시트 폼 용어(재즈피아노_중급 02편)에서 다뤘습니다. 이 편에서 새로 추가되는 것은 그 반복 구간 앞뒤에 "무엇을 얹을지"(인트로·뱀프·태그)를 가리키는 편곡 어휘입니다. 즉 반복 기호가 "어디로 돌아갈지"를 정한다면, 편곡 구조 용어는 "그 반복 밖에 무엇을 새로 붙일지"를 정합니다.

**세션에서 구두로 주고받는 신호와 스케치 표시의 관계**: 실제 합주에서는 종이에 적힌 스케치 외에도 밴드 리더가 손짓이나 눈짓으로 "한 번 더", "여기서 끝" 같은 신호(cue)를 즉석에서 보내는 경우가 많습니다. 스케치의 "Vamp (x3, then cue)" 같은 표시는 바로 이런 상황을 미리 적어 둔 것으로, "최소 3회는 반복하되 정확한 반복 횟수는 그 자리에서 신호로 정한다"는 뜻입니다. 즉 편곡 스케치는 연주를 100% 고정하는 악보라기보다, 현장 판단의 여지를 남겨 두는 설계도에 가깝습니다.

| 스케치 표시 | 현장에서의 의미 |
|---|---|
| Vamp (x3, then cue) | 최소 3회 반복, 이후 리더 신호로 종료 시점 결정 |
| Solo (open) | 솔로이스트가 원하는 만큼 코러스를 자유롭게 가져감(끝날 때 신호) |
| Tag (last 4, x3) | 반복 횟수가 고정되어 신호 없이도 다 함께 정확히 끝남 |

이 구분은 21~22편(트리오 연주 실무: 컴핑 신호·트레이딩 포즈)에서 다시 다루며, 이 편에서는 스케치에 이런 "열린 구간" 표시가 있을 수 있다는 것만 읽어 둡니다.

## 건반과 악보로 보기

편곡 스케치 한 줄을 실제 마디 수로 풀어보는 예시입니다.

```text
스케치:     Intro (4) - A(8) - A(8) - B(8) - A(8) - Solo(1 chorus) - Tag(last 4, x3)

실제 마디:  1~4(인트로) 5~12(A) 13~20(A) 21~28(B) 29~36(A)
            37~68(솔로 1코러스, AABA=32마디) 69~72(태그 4마디, 3회 반복=12마디 연주)
```

이처럼 스케치 한 줄이 실제로는 수십 마디로 풀리기 때문에, 편곡자는 스케치 단계에서 전체 길이를 미리 계산해 둡니다. 태그 구간처럼 "몇 마디를 몇 번 반복"하는지가 스케치에 명시되어 있어야 연주자들이 현장에서 신호 없이도 같은 곳에서 끝낼 수 있습니다.

| 구간 | 스케치 표시 | 실제 길이 |
|---|---|---|
| 인트로 | Intro (4) | 4마디 |
| 태그 엔딩 | Tag (last 4, x3) | 4마디 × 3회 = 12마디 연주분 |

## 연습 과제

<Steps>

### 1. 용어 카드 만들기

인트로·버스·코러스·아웃트로·태그 엔딩·뱀프 여섯 단어를 카드 앞면에 적고, 뒷면에 위치(곡 앞/본체/곡 뒤)와 뜻을 적습니다. 카드를 섞어 5초 안에 위치를 답하는 연습을 5회 반복합니다.

### 2. 스케치 읽고 마디 수 계산하기

이 편의 예시 스케치("Intro (4) - A(8) - A(8) - B(8) - A(8) - Solo(1 chorus) - Tag(last 4, x3)")를 손으로 다시 옮겨 적으며 각 구간의 시작·끝 마디 번호를 계산합니다. 계산이 끝나면 이 편의 표와 대조해 맞았는지 확인합니다.

### 3. 직접 스케치 만들어보기

12마디 블루스 곡을 가정하고, 인트로 2마디+블루스 2코러스+태그 엔딩(마지막 4마디를 2회 반복)으로 이루어진 편곡 스케치를 스스로 적어봅니다. 전체 마디 수를 계산해봅니다.

### 4. 반복 기호와 구조 용어 함께 표시하기

같은 12마디 블루스 스케치에 D.C. al Coda 표시를 추가해, "처음부터 다시 연주하다가 코다 표시에서 아웃트로로 빠지는" 구조를 스케치로 그려봅니다.

### 5. 열린 구간과 고정 구간 구분하기

이 편의 예시 스케치에서 "Solo (1 chorus)"처럼 길이가 고정된 구간과 "Vamp (x3, then cue)"처럼 신호를 기다려야 하는 구간을 각각 표시해봅니다. 스스로 만든 12마디 블루스 스케치에도 열린 구간을 하나 추가해 표시해봅니다.

</Steps>

## 곡에 적용하기

간단한 32마디 AABA 스탠다드 한 곡을 예로 들어 편곡 스케치를 구조 용어로 표시합니다(코드 진행은 표기하지 않고 구조만 다룹니다).

| 구간 | 스케치 표시 | 마디 수 |
|---|---|---|
| 인트로 뱀프 | Intro Vamp (2, x2) | 4마디(2마디 × 2회) |
| A | A(8) | 8마디 |
| A | A(8) | 8마디 |
| B(브리지) | B(8) | 8마디 |
| A | A(8) | 8마디 |
| 솔로 | Solo (2 choruses) | 64마디(32마디 × 2회) |
| 태그 엔딩 | Tag (last 4, x3) | 12마디(4마디 × 3회) |

이 스케치만 보고도 연주자는 곡 전체 길이(약 104마디분 연주)와 각 구간에서 자신이 무엇을 해야 하는지(인트로에서 반복 대기, 솔로 구간 길이, 엔딩에서 몇 번 반복할지)를 미리 파악할 수 있습니다. 실제로 인트로 뱀프·태그 엔딩을 "작곡"하는 방법은 19편에서 다룹니다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| 뱀프와 태그 엔딩을 같은 말로 혼동 | 둘 다 "반복"이라는 공통점만 봄 | 뱀프는 일반 개념, 태그 엔딩은 곡 끝에서의 구체적 적용이라는 포함 관계로 구분한다 |
| 버스와 코러스를 헷갈림 | 대중음악의 verse-chorus 구조와 재즈 용어를 그대로 대응시킴 | 재즈에서 코러스는 "진행 한 바퀴"를 뜻하며 대중음악의 후렴과는 다른 개념임을 기억한다 |
| 스케치의 반복 횟수를 안 보고 넘어감 | "Tag (last 4, x3)"에서 x3을 놓치고 1회만 반복 | 스케치에 적힌 반복 횟수·구간 길이를 항상 함께 읽는다 |
| 스케치만 보고 전체 곡 길이를 계산 안 함 | 스케치 한 줄이 실제로 몇 마디인지 감이 없음 | 이 편의 계산 연습처럼 각 구간을 실제 마디 수로 풀어서 더해본다 |
| 인트로와 아웃트로가 항상 같은 재료라고 생각함 | 앞뒤로 대칭이어야 한다는 선입견 | 인트로와 아웃트로(태그 엔딩)는 서로 다른 재료로 만들 수 있으며 19편에서 실제로 다르게 설계하는 예시를 다룬다 |
| "Solo (open)"을 보고 몇 코러스인지 미리 정해져 있다고 생각함 | 모든 스케치 표시가 고정 길이라고 오해 | open은 솔로이스트가 자유롭게 길이를 정하고 신호로 마무리한다는 뜻임을 구분한다 |
| 편곡 스케치가 연주를 100% 고정한다고 오해 | 악보=고정이라는 클래식 관습을 그대로 적용 | 뱀프·솔로 구간처럼 현장 신호로 길이가 정해지는 열린 구간이 있을 수 있음을 기억한다 |
