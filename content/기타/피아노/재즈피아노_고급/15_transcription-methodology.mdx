## 개념 (짧게)

**트랜스크립션**(transcription)은 녹음된 연주를 듣고 그 음과 리듬을 악보나 코드 심벌로 옮겨 적는 작업입니다. 실제 연주자가 그 개념들을 **어떻게 실전에서 썼는지** 귀로 확인하고, 그 결과를 자기 것으로 흡수하는 절차입니다.

이 편에서는 저작권이 있는 실제 스탠다드 녹음이나 유명 솔로이스트의 솔로를 악보로 옮겨 싣지 않습니다. 다음 편(16편)에서 이 절차를 학습자가 직접 고른 짧은 녹음, 또는 이 교재가 제공하는 원리 설명용 자작 프레이즈에 적용합니다.

채보 절차는 네 단계로 나뉩니다.

| 단계 | 하는 일 | 이유 |
|------|---------|------|
| 1. 속도 늦춰 전체 듣기 | 원곡 속도로 한 번, 느린 속도(70–80퍼센트)로 한 번 전체를 듣는다 | 먼저 곡의 전체 흐름과 분위기를 파악해야 세부를 오해하지 않는다 |
| 2. 코드 진행 먼저 채보 | 베이스음과 화성 진행을 먼저 적는다 | 코드를 알면 멜로디 음이 어떤 코드톤·텐션인지 짐작하기 쉬워진다 |
| 3. 멜로디를 구간 반복으로 채보 | 2–4마디씩 끊어 반복 재생하며 음과 리듬을 적는다 | 짧은 구간을 반복해야 정확한 음정과 리듬을 확정할 수 있다 |
| 4. 12키로 옮겨 검증 | 채보한 프레이즈를 피아노로 다른 키에 옮겨 쳐 본다 | 정확히 들었다면 어떤 키로 옮겨도 같은 소리 관계가 유지된다 |

1·2단계는 전체 그림을 먼저 잡는 과정이고, 3단계에서 실제로 악보에 옮겨 적는 세부 작업이 이루어집니다. 4단계는 채보가 정확한지 스스로 검증하는 절차이며, 동시에 12편~14편에서 배운 12키 이동 훈련과도 자연스럽게 이어집니다.

## 건반과 악보로 보기

한 마디를 채보할 때 아래처럼 박마다 칸을 나눈 표를 준비하면 리듬과 음을 놓치지 않고 채워 넣을 수 있습니다.

```
마디 (            )  코드: (        )
┌──────┬──────┬──────┬──────┐
│ 1박  │ 2박  │ 3박  │ 4박  │
├──────┼──────┼──────┼──────┤
│      │      │      │      │
└──────┴──────┴──────┴──────┘
```

칸 안에는 먼저 리듬(몇 개의 음이 들어가는지, 8분음표인지 4분음표인지)만 표시하고, 그다음 두 번째 청취에서 음이름을 채워 넣습니다. 리듬과 음을 동시에 잡으려 하면 둘 다 놓치기 쉽습니다.

속도를 늦춰 듣는 도구는 방식에 따라 크게 두 종류로 나뉩니다.

| 도구 종류 | 방식 | 장점 |
|-----------|------|------|
| 재생 속도 조절 기능 | 음원 재생 프로그램·동영상 사이트의 배속 조절(0.5배·0.75배 등) | 음높이(피치)가 바뀌지 않으면서 속도만 늦출 수 있다 |
| 구간 반복(A-B 반복) 기능 | 특정 시작점과 끝점을 지정해 그 구간만 무한 반복 재생 | 짧은 프레이즈를 원하는 만큼 반복해서 확인할 수 있다 |

두 기능을 함께 지원하는 프로그램을 하나 골라 익혀 두면, 이후 어떤 녹음을 채보하더라도 같은 절차를 반복할 수 있습니다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 리듬과 음이름을 동시에 적으려다 둘 다 부정확하게 적는다 | 한 번에 모든 정보를 잡으려 한다 | 3번 과제처럼 리듬을 먼저 확정하고, 그다음 청취에서 음이름만 채운다 |
| 멜로디부터 채보하다가 코드가 안 맞아 처음부터 다시 시작한다 | 코드 진행을 확인하지 않고 멜로디부터 듣는다 | 2단계(코드 진행 먼저 채보)를 항상 멜로디 채보보다 먼저 끝낸다 |
| 짧은 구간을 반복 없이 통으로 여러 번 들어 시간만 쓴다 | 구간 반복 기능을 설정하지 않는다 | 1번 과제처럼 A-B 구간 반복을 미리 지정해 그 구간만 정확히 반복한다 |
