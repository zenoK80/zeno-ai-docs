## 개념 (짧게)

저작권이 있는 실제 솔로 녹음 대신, 이 교재가 원리 설명용으로 새로 만든 4마디 프레이즈를 "듣고 받아쓰기" 대상으로 씁니다. `<AbcScore>`는 재생 버튼을 제공하므로, **아래 악보를 눈으로 먼저 읽지 말고 재생 버튼만 눌러** 소리로 채보를 시작하는 것이 이 예시의 핵심입니다.

채보 과정은 세 부분으로 나뉩니다.

1. **채보**: 4마디 프레이즈를 듣고 리듬·음이름을 워크시트에 옮겨 적습니다.
2. **라벨링**: 채보한 결과에서 12편(비밥 스케일)·13편(인클로저)·14편(코드톤 갈아타기)에서 배운 패턴이 어디에 쓰였는지 표시합니다.
3. **이식**: 채보한 프레이즈의 리듬·음형(윤곽)을 그대로 유지하면서 다른 코드 진행에 옮겨 적습니다.

세 부분 모두 15편의 4단계 절차(전체 듣기 → 코드 먼저 → 멜로디 구간 반복 → 12키 검증)를 그대로 따르되, 이번에는 실제로 손을 움직여 끝까지 완성합니다.

## 건반과 악보로 보기

채보를 시작하기 전에, 마디마다 8분음표 8칸을 채울 빈 틀을 먼저 준비합니다. 코드 칸에는 15편 2단계(코드 먼저 채보)에서 짐작한 코드를 적고, 음 칸에는 3단계에서 확인한 음이름을 하나씩 적습니다.

```
1마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
2마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
3마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
4마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
```

점(・) 하나가 8분음표 한 칸입니다. 실제 프레이즈에는 4분음표나 그보다 긴 음도 섞여 있을 수 있으므로, 한 음이 두 칸 이상을 차지하면 옆 칸에 화살표나 줄을 그어 이어 붙였다고 표시합니다.

아래 표는 채보 중 헷갈리기 쉬운 반음 간격을 빠르게 확인하는 참고용입니다. 건반에서 흰건반 두 개가 검은건반 없이 붙어 있는 자리(E-F, B-C)만 기억하면 나머지는 셈으로 구합니다.

| 확인할 구간 | 반음 개수 | 건반 단서 |
|-------------|-----------|-----------|
| 같은 흰건반끼리(E→F, B→C) | 1개(반음) | 사이에 검은건반이 없다 |
| 흰건반 사이에 검은건반이 있는 경우(C→D 등) | 2개(온음) | 사이에 검은건반이 하나 있다 |
| 흰건반과 바로 옆 검은건반 | 1개(반음) | 인접한 건반이면 항상 반음 |

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 재생 버튼을 누르기 전에 악보부터 눈으로 읽는다 | 듣기 전에 시각 정보를 먼저 확인하려는 습관 | 1번 과제처럼 재생만 먼저 하고, 대조는 4번 과제에서만 한다 |
| 코드 진행을 짐작하지 않고 바로 멜로디 음이름부터 적으려 한다 | 15편의 절차 순서를 건너뛴다 | 2번 과제(코드 먼저)를 3번 과제(멜로디)보다 항상 먼저 끝낸다 |
| 이식할 때 원본과 똑같은 음이름을 그대로 옮겨 적어 새 코드와 안 맞는다 | 음이름을 옮기는 것과 코드톤을 재계산하는 것을 혼동한다 | 새 코드의 코드톤을 먼저 확인한 뒤, 원본과 같은 자리(근음·3도·5도·7도)에 맞춰 채운다 |
