<Callout type="info">
  **이번 편의 목표:** 4마디 분량의 프레이즈를 15편의 절차대로 직접 채보하고, 채보한 프레이즈 안에서 인클로저·비밥 스케일 패턴을 찾아 라벨을 붙인 뒤 같은 리듬·음형을 다른 진행에 옮겨 쓸 수 있습니다. **연습 시간 목안:** 하루 20~30분 × 5일
</Callout>

## 개념 (짧게)

이번 편은 15편에서 정리한 절차를 실제로 한 번 끝까지 밟아 보는 실습입니다. 저작권이 있는 실제 솔로 녹음 대신, 이 교재가 원리 설명용으로 새로 만든 4마디 프레이즈를 "듣고 받아쓰기" 대상으로 씁니다. `<AbcScore>`는 재생 버튼을 제공하므로, **아래 악보를 눈으로 먼저 읽지 말고 재생 버튼만 눌러** 소리로 채보를 시작하는 것이 이번 실습의 핵심입니다.

실습은 세 부분으로 진행합니다.

1. **채보**: 4마디 프레이즈를 듣고 리듬·음이름을 워크시트에 옮겨 적습니다.
2. **라벨링**: 채보한 결과에서 12편(비밥 스케일)·13편(인클로저)·14편(코드톤 갈아타기)에서 배운 패턴이 어디에 쓰였는지 표시합니다.
3. **이식**: 채보한 프레이즈의 리듬·음형(윤곽)을 그대로 유지하면서 다른 코드 진행에 옮겨 적습니다.

세 부분 모두 15편의 4단계 절차(전체 듣기 → 코드 먼저 → 멜로디 구간 반복 → 12키 검증)를 그대로 따르되, 이번에는 실제로 손을 움직여 끝까지 완성합니다.

## 건반과 악보로 보기

채보를 시작하기 전에, 마디마다 8분음표 8칸을 채울 빈 틀을 먼저 준비합니다. 코드 칸에는 15편 2단계(코드 먼저 채보)에서 짐작한 코드를 적고, 음 칸에는 3단계에서 확인한 음이름을 하나씩 적습니다.

```
1마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
2마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
3마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
4마디  코드:(     )  │ ・ ・ ・ ・ ・ ・ ・ ・ │
```

점(・) 하나가 8분음표 한 칸입니다. 실제 프레이즈에는 4분음표나 그보다 긴 음도 섞여 있을 수 있으므로, 한 음이 두 칸 이상을 차지하면 옆 칸에 화살표나 줄을 그어 이어 붙였다고 표시합니다.

아래 표는 채보 중 헷갈리기 쉬운 반음 간격을 빠르게 확인하는 참고용입니다. 건반에서 흰건반 두 개가 검은건반 없이 붙어 있는 자리(E-F, B-C)만 기억하면 나머지는 셈으로 구합니다.

| 확인할 구간 | 반음 개수 | 건반 단서 |
|-------------|-----------|-----------|
| 같은 흰건반끼리(E→F, B→C) | 1개(반음) | 사이에 검은건반이 없다 |
| 흰건반 사이에 검은건반이 있는 경우(C→D 등) | 2개(온음) | 사이에 검은건반이 하나 있다 |
| 흰건반과 바로 옆 검은건반 | 1개(반음) | 인접한 건반이면 항상 반음 |

## 연습 과제

<Steps>

### 1. 전체 듣기 (원곡 속도 + 느린 속도)

### 2. 코드 진행 먼저 채보하기

재생 버튼으로 다시 들으며 베이스음(왼손 파트)의 변화만 워크시트 코드 칸에 적습니다. 근음이 4도 위로 움직이는지, 2도 위로 움직이는지 구분해 진행의 모양을 먼저 짐작합니다.

### 3. 한 마디씩 끊어 멜로디 채보하기

한 마디씩 반복 재생하며 리듬을 먼저 표시하고, 그다음 음이름을 채워 넣습니다. 한 마디가 끝나면 다음 마디로 넘어가기 전에 반드시 건반으로 확인합니다.

### 4. 채보 결과와 대조하기

네 마디를 모두 채운 뒤 위 악보를 직접 눈으로 확인해 자신이 적은 음·리듬과 대조합니다. 다른 부분이 있으면 그 마디만 다시 반복 재생으로 확인합니다.

### 5. 패턴 라벨링

대조를 마친 악보에서 12편(비밥 스케일이 쓰인 자리), 13편(인클로저가 쓰인 자리), 14편(코드가 바뀌는 지점에서 코드톤으로 갈아탄 자리)을 찾아 표시합니다. 4마디 프레이즈 안에는 4마디(Cmaj7 마지막 마디)에 비밥 스케일의 반음 추가음(G와 A 사이 G#)이, 3마디 끝에서 4마디 시작으로 넘어가는 자리에 코드톤 갈아타기가 들어 있습니다.

</Steps>

## 곡에 적용하기

채보한 프레이즈 중 1마디(Dm7)의 리듬·윤곽(코드톤으로 올라갔다가 스텝으로 내려오는 모양)을 그대로 유지한 채, 다른 코드(Am7)에 옮겨 적은 예시입니다.

| 원본 | 이식 대상 | 유지하는 것 | 바꾸는 것 |
|------|-----------|-------------|-----------|
| Dm7 위 D-F-A-c-B-A-G-F | Am7 | 리듬(8분음표 8개)과 상행 후 하행이라는 윤곽 | 실제 음이름(각 코드의 코드톤으로 재계산) |

원본은 근음(D)에서 3도(F)·5도(A)·7도(C)까지 올라간 뒤 스텝으로 내려오는 모양이었습니다. Am7 버전도 근음(A)에서 3도(C)·5도(E)·7도(G)까지 올라간 뒤 스텝으로 내려오는 같은 윤곽을 유지합니다. 나머지 세 마디도 같은 방식으로 자신이 정한 진행에 옮겨 적어 봅니다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 재생 버튼을 누르기 전에 악보부터 눈으로 읽는다 | 듣기 전에 시각 정보를 먼저 확인하려는 습관 | 1번 과제처럼 재생만 먼저 하고, 대조는 4번 과제에서만 한다 |
| 코드 진행을 짐작하지 않고 바로 멜로디 음이름부터 적으려 한다 | 15편의 절차 순서를 건너뛴다 | 2번 과제(코드 먼저)를 3번 과제(멜로디)보다 항상 먼저 끝낸다 |
| 이식할 때 원본과 똑같은 음이름을 그대로 옮겨 적어 새 코드와 안 맞는다 | 음이름을 옮기는 것과 코드톤을 재계산하는 것을 혼동한다 | 새 코드의 코드톤을 먼저 확인한 뒤, 원본과 같은 자리(근음·3도·5도·7도)에 맞춰 채운다 |
| 패턴 라벨링 없이 채보만 끝내고 다음 편으로 넘어간다 | 라벨링을 채보의 마무리 확인 정도로 여긴다 | 5번 과제처럼 12–14편 개념이 어디 쓰였는지 반드시 표시한 뒤 마무리한다 |
