## 개념 (짧게)

재즈피아노 악보(리드시트)에는 오선 위 음표 대신 `Cmaj7`, `Dm7`, `G7` 같은 문자와 숫자 조합이 코드 이름으로 적혀 있습니다. 이 조합을 읽는 법을 모르면 다음 편부터 나오는 모든 코드 이야기가 암호로만 보입니다. 코드 심벌은 항상 같은 순서로 조립됩니다.

```
근음(Root) + 코드 성질(Quality) + 추가 확장(Extension/Tension)
예)  C        maj7
     G        7
     C        m7(b5)
```

**근음**은 A~G 알파벳 하나(필요하면 `#`이나 `b`가 붙음)입니다. 한국 음악 교육에서 쓰는 한글 음이름(다라마바사가나)과 짝지으면 다음과 같습니다.

| 알파벳 | C | D | E | F | G | A | B |
|--------|---|---|---|---|---|---|---|
| 한글 음이름 | 다 | 라 | 마 | 바 | 사 | 가 | 나 |
| 계이름(다장조 기준) | 도 | 레 | 미 | 파 | 솔 | 라 | 시 |

코드 심벌과 로마 숫자 표기는 항상 **알파벳**을 기준으로 씁니다("씨코드"라고 부르되 표기는 `C`). 한글 음이름은 조성 이름(다장조, 사장조 등)을 부를 때만 참고로 쓰이며, 이 과목의 악보·코드 표기에는 등장하지 않습니다.

**코드 성질**은 아래 표의 약어로 정해집니다. 이 과목 전체에서 코드 성질 표기는 이 표를 기준으로 통일합니다.

| 코드 성질 | 표기 약어 | 예시 | 읽는 법 |
|-----------|-----------|------|---------|
| 메이저 | (표기 없음) 또는 `maj` | `C` | 씨 |
| 메이저 7th | `maj7` | `Cmaj7` | 씨 메이저 세븐 |
| 마이너 | `m` | `Cm` | 씨 마이너 |
| 마이너 7th | `m7` | `Dm7` | 디 마이너 세븐 |
| 도미넌트 7th | `7` | `G7` | 지 세븐 |
| 마이너 7th flat5(하프디미니시드) | `m7(b5)` | `Cm7(b5)` | 씨 마이너 세븐 플랫 파이브 |
| 디미니시드 7th | `dim7` | `Cdim7` | 씨 디미니시드 세븐 |
| 서스펜디드 4 | `sus4` | `Csus4` | 씨 서스 포 |
| 식스 | `6` | `C6` | 씨 식스 |

코드에 색을 더하는 음을 **텐션**(tension)이라 하고, 괄호 안에 숫자로 표기합니다. 이 과목에서는 텐션 표기를 `9, 11, 13, b9, #11`처럼 씁니다. 예를 들어 `C7(#9)`는 "씨 세븐 샵 나인"이라고 읽습니다. 텐션이 실제로 무엇을 뜻하는지는 이후 편(중급 과정)에서 다루고, 지금은 **표기를 정확히 읽는 것**만 목표로 합니다.

### 실전 리드시트에서 만나는 표기 변형

실제 리드시트나 악보집마다 같은 코드를 조금씩 다르게 적기도 합니다. 처음 보는 표기에 당황하지 않도록 자주 보이는 변형을 정리합니다. 이 과목의 본문과 예제는 표의 왼쪽(이 과목 표준 표기)으로 통일합니다.

| 이 과목 표준 표기 | 같은 뜻의 다른 표기 | 코드 성질 |
|----------------------|------------------------|-----------|
| `Cm7` | `Cmin7`, `C-7` | 마이너 7th |
| `Cmaj7` | `CM7`, `Cma7` | 메이저 7th |
| `Cm7(b5)` | `Cø7`, `Cmin7(b5)` | 하프디미니시드 |
| `C7` | `Cdom7` (드묾) | 도미넌트 7th |

어떤 표기를 만나든 **알파벳 대소문자와 숫자 조합의 뜻**(마이너=소문자 m 또는 하이픈, 메이저 7th=대문자 M 또는 maj)만 기억하면 낯선 표기도 어렵지 않게 해독할 수 있습니다.

## 로마 숫자 화음 표기

코드 진행을 특정 조성에 묶이지 않고 설명할 때는 **로마 숫자**로 코드 자리를 나타냅니다. 대문자와 소문자로 코드 성질을 구분하는 것이 핵심 규칙입니다.

| 로마 숫자 표기 | 뜻하는 코드 성질 | 예시(다장조 기준) |
|----------------|-------------------|---------------------|
| 대문자(예: `I`, `IV`, `V`) | 메이저 계열 | `C`, `F`, `G` |
| 소문자(예: `ii`, `iii`, `vi`) | 마이너 계열 | `Dm`, `Em`, `Am` |
| 소문자 + `°`(예: `vii°`) | 디미니시드 | `Bdim` |

7th 코드까지 포함하면 다음과 같이 확장됩니다. 이 표는 08편(다이어토닉 7th 코드)에서 그대로 다시 사용합니다.

| 로마 숫자(7th) | 코드 성질 | 예시(다장조 기준) |
|-----------------|-----------|---------------------|
| `Imaj7` | 메이저 7th | `Cmaj7` |
| `ii7` | 마이너 7th | `Dm7` |
| `iii7` | 마이너 7th | `Em7` |
| `IVmaj7` | 메이저 7th | `Fmaj7` |
| `V7` | 도미넌트 7th | `G7` |
| `vi7` | 마이너 7th | `Am7` |
| `viiø7` | 하프디미니시드(m7b5) | `Bm7(b5)` |

`ø`(슬래시 오) 기호는 하프디미니시드 7th 코드를 로마 숫자에서 나타낼 때 쓰는 전용 기호이며, 코드 이름으로 쓸 때는 `m7(b5)`로 풀어 씁니다. 두 표기는 같은 코드를 가리키는 다른 방식입니다.

## 인터벌 이름 표기

**인터벌**(interval, 음정)은 두 음 사이의 거리이며, 몇 번째 음인지를 세는 **도수**와 정확한 크기를 나타내는 **성질**(장·단·완전)로 이름 붙입니다. 근음을 1도로 세는 것이 기준입니다.

| 도수 | 반음 수(장/완전) | 반음 수(단) | C 기준 예시 |
|------|--------------------|--------------|---------------|
| 2도 | 장2도 – 2 | 단2도 – 1 | `C`–`D`(장2도), `C`–`Db`(단2도) |
| 3도 | 장3도 – 4 | 단3도 – 3 | `C`–`E`(장3도), `C`–`Eb`(단3도) |
| 4도 | 완전4도 – 5 | – | `C`–`F`(완전4도) |
| 5도 | 완전5도 – 7 | – | `C`–`G`(완전5도) |
| 6도 | 장6도 – 9 | 단6도 – 8 | `C`–`A`(장6도), `C`–`Ab`(단6도) |
| 7도 | 장7도 – 11 | 단7도 – 10 | `C`–`B`(장7도), `C`–`Bb`(단7도) |

4도와 5도는 장·단이 아니라 **완전**(perfect)이라는 성질을 씁니다. 완전이라는 이름이 붙는 이유는 이 두 인터벌이 장조든 단조든 크기가 변하지 않고 항상 같기 때문입니다(장3도·단3도처럼 조에 따라 반음 수가 달라지는 것과 다릅니다). 반음 개수를 직접 세는 방법은 04편(온음·반음)에서 다룹니다. 지금은 표기 이름과 숫자만 정확히 읽을 수 있으면 충분합니다.

## 건반과 악보로 보기

01편의 건반 지도를 그대로 가져와, 코드 이름 `C`(다장조 코드)가 어떤 건반 조합을 부르는지 확인합니다.

```
      C#    D#          F#    G#    A#
   ┌────┬────┬────┬────┬────┬────┬────┬────┐
   │ C  │ D  │ E  │ F  │ G  │ A  │ B  │ C  │
   └────┴────┴────┴────┴────┴────┴────┴────┘
```

코드 이름 `C`는 지금 단계에서 `C`(근음) · `E`(3도 위) · `G`(5도 위) 세 건반을 함께 누르는 것을 가리킵니다. 왜 근음에서 3도와 5도를 쌓으면 코드가 되는지는 07편에서 자세히 다루고, 지금은 코드 심벌 하나가 "누를 건반 조합의 이름"이라는 사실만 확인합니다.

## 연습 과제

<Steps>

### 1. 코드 성질 약어 소리 내어 읽기

메트로놈을 BPM 50으로 맞추고, 클릭마다 코드 성질 표의 약어를 하나씩 소리 내어 읽습니다(`maj7`, `m7`, `7`, `m7(b5)`, `dim7`, `sus4`, `6` 순서). 8칸 채운 표를 왕복 3회 읽습니다.

### 2. 코드 심벌을 근음·성질로 분해해 말하기

`Cmaj7`, `Dm7`, `G7`, `Cm7(b5)`, `Fsus4`, `A7` 여섯 개 코드 심벌을 순서대로 보고 "근음은 무엇, 성질은 무엇"이라고 각각 말합니다. 막히지 않고 끝까지 말할 수 있을 때까지 반복합니다.

### 3. 로마 숫자 대문자·소문자 구분해 말하기

`I ii iii IV V vi vii°`를 메트로놈 BPM 60에 맞춰 한 클릭에 하나씩 읽으며, 대문자는 "메이저", 소문자는 "마이너", `vii°`는 "디미니시드"라고 성질까지 함께 말합니다. 왕복 4회 반복합니다.

### 4. 인터벌 도수 표에서 반음 수 암송하기

인터벌 표를 손가락으로 짚으며 "장2도는 반음 2개, 단3도는 반음 3개" 형식으로 2도부터 7도까지 순서대로 암송합니다. 표를 보지 않고 말할 수 있을 때까지 반복합니다.

</Steps>

## 곡에 적용하기

지금까지 배운 코드 심벌 표기를 이용해 다장조에서 가장 단순한 코드 진행 하나를 표기로 읽어봅니다. 보이싱(코드를 손으로 짚는 구체적 방법)은 09편부터 다루므로, 지금은 표기와 소리만 확인합니다.

| 마디 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|
| 코드 심벌 | `C` | `F` | `G` | `C` |
| 로마 숫자 | `I` | `IV` | `V` | `I` |

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| `m`(마이너)과 `maj`(메이저 7th)을 혼동한다 | 소문자 m과 maj의 철자가 비슷해 보인다 | maj는 항상 숫자 7과 붙어 다닌다는 점(`maj7`)을 기준으로 구분한다 |
| 로마 숫자 대문자·소문자를 구분하지 않고 읽는다 | 대소문자가 코드 성질을 나타낸다는 규칙을 모른다 | 대문자=메이저, 소문자=마이너, 소문자+°=디미니시드 규칙을 표로 다시 확인한다 |
| `ø`와 `°` 기호를 같은 뜻으로 쓴다 | 두 기호 모두 낯설어 구분 없이 쓴다 | `°`는 디미니시드 3화음, `ø`는 하프디미니시드 7th 코드 전용이라는 것을 구분해 외운다 |
| 인터벌 도수를 셀 때 근음을 빼고 센다 | 두 음 사이 간격을 음 개수로 착각한다 | 근음 자신을 1도로 포함해 세는 규칙을 매번 손가락으로 확인한다 |
| `Cmin7`, `C-7` 같은 낯선 표기를 아예 다른 코드로 착각한다 | 표기 변형이 있다는 것을 모른다 | 대소문자·기호의 뜻만 뜯어보면 결국 같은 코드라는 것을 표로 다시 확인한다 |
