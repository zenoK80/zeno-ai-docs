</Callout>

## 개념 (짧게)

09편에서는 가이드톤(3도·7도)을 근음 위로 쌓아 코드 진행을 짚었습니다. 그 방식은 오른손으로 코드 전체(또는 가이드톤 2음)를 짚는 데는 좋지만, 오른손이 계속 코드를 누르고 있으면 멜로디를 만들 손이 남지 않습니다. 이번 편에서는 그 가이드톤을 왼손 하나로 편하게 치도록 근음 바로 옆에 촘촘히 배치합니다. 이렇게 만든 왼손 2음 보이싱을 **셸 보이싱**이라고 부릅니다. 왼손이 코드 성질을 이미 표현하고 있으므로, 오른손은 코드를 누르는 부담 없이 멜로디에 집중할 수 있습니다.

셸 보이싱은 두 가지 모양이 있습니다.

- **근음+7도**: 근음 바로 아래에 7도 음을 놓습니다. 장7 코드는 근음보다 반음 낮은 음, 단7·딸림7 코드는 근음보다 온음 낮은 음입니다.
- **근음+3도**: 근음 바로 위에 3도 음을 놓습니다. 장3도 또는 단3도만큼 떨어진 가까운 음입니다.

두 모양 모두 손가락 두 개(보통 1번·5번)로 짚을 수 있는 좁은 간격입니다. 09편의 클로즈드 보이싱이 4음을 다 눌러 소리를 두껍게 만든다면, 셸 보이싱은 왼손 두 음만으로 같은 정보(코드 성질)를 더 가볍게 전달합니다.

C7(딸림7 코드)의 근음+7도 셸을 손으로 단계별로 찾으면 다음과 같습니다.

1. 근음 C에서 시작합니다.
2. C7의 7도는 단7도입니다. 단7도는 근음보다 온음 하나 낮은 음과 같은 자리이므로, 근음 바로 아래 온음을 찾습니다.
3. C보다 온음 낮은 음은 B♭입니다.
4. C7의 근음+7도 셸은 B♭(아래)-C(근음)입니다.

Cmaj7(장7 코드)이라면 3단계에서 반음만 낮추므로 B(아래)-C(근음)가 됩니다. 이 반음 차이가 장7과 딸림7을 구분하는 핵심이며, 같은 근음 C를 쓰는 두 코드를 귀로 구분하는 유일한 단서이기도 합니다.

| 코드 | 근음+7도 셸 | 근음+3도 셸 |
|---|---|---|
| Cmaj7 | B-C | C-E |
| C7 | B♭-C | C-E |
| Dm7 | C-D | D-F |
| Fmaj7 | E-F | F-A |
| G7 | F-G | G-B |

Cmaj7과 C7의 근음+3도 셸이 똑같은 것도 확인해 둡니다. 두 코드 모두 장3도를 쓰기 때문이며, 둘을 구분하는 정보는 7도 쪽 셸에만 들어 있습니다.

셸 보이싱의 두 형태(근음+7도, 근음+3도)를 코드마다 하나만 고집하지 않고 상황에 따라 골라 쓰는 이유는 11편에서 배울 ii-V-I 연결 때문입니다. 앞 코드와 가까운 모양을 고르면 손이 크게 움직이지 않고 부드럽게 이어지는데, 이 편에서는 우선 두 형태를 각각 따로 손에 익히는 데 집중합니다. 두 형태를 모두 정확히 짚을 수 있어야 다음 편에서 상황에 맞는 모양을 고를 수 있습니다.

09편에서 정리한 다이어토닉 7th 코드 7개를 셸 보이싱 두 형태로 모두 계산하면 다음과 같습니다.

| 코드 | 근음+7도 셸 | 근음+3도 셸 |
|---|---|---|
| Cmaj7 | B-C | C-E |
| Dm7 | C-D | D-F |
| Em7 | D-E | E-G |
| Fmaj7 | E-F | F-A |
| G7 | F-G | G-B |
| Am7 | G-A | A-C(위 옥타브) |
| Bm7(b5) | A-B | B-D(위 옥타브) |

Am7과 Bm7(b5)의 근음+3도 셸에서는 3도가 다음 옥타브로 넘어갑니다. 09편에서 본 것과 같은 이유로, 근음보다 낮은 자리에 3도를 놓을 수 없기 때문입니다. 이런 코드는 근음+7도 셸을 먼저 익히고, 근음+3도 셸은 옥타브가 넘어간다는 점을 인지한 채 나중에 연습합니다.

왼손 손가락은 셸의 간격에 따라 다르게 씁니다.

| 셸 모양 | 음 간격 | 왼손 손가락 |
|---|---|---|
| 근음+7도(아래) | 2도(온음 또는 반음) | 1번-2번 |
| 근음+3도(위) | 3도(장3도 또는 단3도) | 1번-3번 |

간격이 좁을수록 손가락 번호도 가까운 것을 씁니다. 간격이 넓어지는 근음+3도 셸에서 1번-3번을 쓰면 손 모양이 자연스럽게 유지됩니다.

## 연습 과제

<Steps>

### 1. 왼손 셸 모양 두 가지 익히기

메트로놈 BPM 70. Cmaj7, Dm7, Fmaj7, G7 네 코드를 근음+7도 셸로 각각 4번씩, 이어서 근음+3도 셸로 각각 4번씩 왼손만으로 반복합니다. 손가락은 1번(엄지)과 5번(새끼)을 기본으로 씁니다.

### 2. 오른손 스케일 멜로디만 따로 연습

오른손으로 C메이저 스케일 안에서 위 악보의 멜로디(C-D-E-G, E-D-C)를 왼손 없이 먼저 익힙니다. BPM 90에 맞춰 4번 반복합니다.

### 3. 양손 합치기

왼손 셸(근음+7도)을 코드마다 한 박자 먼저 눌러 소리를 확인한 뒤, 오른손 멜로디를 얹습니다. BPM 80으로 느리게 8마디 반복합니다.

### 4. 셸 모양 바꿔가며 연결

Cmaj7(근음+7도) → Fmaj7(근음+7도) → Cmaj7(근음+3도) → Fmaj7(근음+3도) 순서로 왼손만 4마디 반복합니다. 손이 코드마다 어느 방향으로 움직이는지 눈으로 확인합니다.

### 5. 다이어토닉 7th 코드 7개 전부 셸로 익히기

앞서 정리한 셸 보이싱 표 순서대로 Cmaj7부터 Bm7(b5)까지, 근음+7도 셸을 왼손만으로 메트로놈 BPM 75에 맞춰 온음표로 이어 칩니다. 익숙해지면 같은 순서를 근음+3도 셸로도 반복합니다.

### 6. 셸 위에 스케일 멜로디 자유롭게 얹기

Cmaj7 셸(근음+7도)을 왼손으로 유지한 채, 오른손으로 C메이저 스케일 음 중 아무 음이나 골라 4박 동안 자유롭게 눌러봅니다. 정해진 멜로디 없이 왼손 코드 위에서 오른손이 자유롭게 움직이는 감각을 먼저 익히는 연습입니다. 틀린 음은 없다고 생각하고, 코드 톤(근음·3도·5도)에 착지할 때 소리가 더 안정적으로 들리는지만 귀로 비교합니다.

</Steps>

| 3 | Cmaj7 | 근음+3도 (C-E) |
