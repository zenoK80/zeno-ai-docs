## 개념 (짧게)

### 컴핑이란 무엇인가

컴핑(comping, accompanying의 줄임말)은 멜로디나 즉흥을 연주하는 사람(자신 또는 다른 연주자) 뒤에서 코드로 리듬과 화성을 받쳐주는 반주 방식입니다. 컴핑의 목표는 세 가지입니다.

| 목표 | 설명 |
|---|---|
| 화성 지지 | 지금 어떤 코드인지 귀에 들려준다 |
| 리듬 추진 | 스윙감과 찰스턴 리듬으로 곡을 앞으로 밀어준다 |
| 공간 남기기 | 마디 전체를 꽉 채우지 않고 쉬는 구간을 남겨 멜로디·즉흥이 숨 쉴 자리를 준다 |

### 이번 편에서 하는 일

14편에서 F 12마디 블루스의 코드 배치(I-IV-V)를 배웠고, 13편에서 찰스턴 리듬을 배웠습니다. 이번 편은 이 둘을 합쳐 12마디 전체에 걸쳐 가이드톤 보이싱(왼손 근음 + 오른손 가이드톤)을 찰스턴 리듬으로 반주합니다. 새로운 개념은 없고, 배운 것을 12마디 길이로 이어 붙이는 것이 이번 편의 핵심입니다.

### 손을 최소한으로만 움직인다

12마디를 처음 이어 칠 때 가장 많이 겪는 어려움은 코드가 바뀔 때마다 손이 건반 위에서 크게 뛰는 것입니다. F7-Bb7-C7 세 코드의 근음과 가이드톤 위치를 살펴보면 실제로는 손이 아주 조금만 움직여도 됩니다.

| 전환 | 왼손 근음 이동 | 오른손 가이드톤 이동 |
|---|---|---|
| F7 → Bb7 | F → Bb(완전4도, 손 하나 폭 정도) | A, Eb → D, Ab(각 음이 반음–온음 정도만 이동) |
| Bb7 → F7 | Bb → F(완전4도 아래) | D, Ab → A, Eb |
| F7 → C7(또는 Bb7 → C7) | F 또는 Bb → C(가까운 거리) | 각 음이 반음–온음 정도만 이동 |

가이드톤끼리는 대부분 반음이나 온음 정도만 움직이므로, 손 모양을 크게 바꾸지 않고 손가락 위치만 살짝 옮긴다는 느낌으로 연주하면 이어 치기가 훨씬 매끄러워집니다.

## 연습 과제

<Steps>

### 1. 4마디씩 나눠 손 따로 연습

12마디를 1~4, 5~8, 9~12로 나눕니다. 각 구간을 왼손 근음만, 오른손 가이드톤만 따로 메트로놈 BPM 70에 맞춰 4회씩 연습합니다.

### 2. 4마디씩 양손 합치기

같은 구간을 양손 합쳐서 BPM 70으로 연습합니다. 코드가 바뀌는 지점(5마디 F7→Bb7, 9마디 Bb7→C7 등)에서 멈추지 않도록 특히 신경 씁니다.

### 3. 12마디 전체 이어 치기

세 구간을 끊지 않고 12마디 전체를 BPM 80으로 4회 반복 연주합니다.

### 4. 템포 올리기

BPM 80 → 90 → 100 순서로 12마디 전체를 각각 2회씩 반복합니다.

</Steps>

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| Bb7과 F7의 가이드톤을 헷갈린다 | F7(A, Eb)과 Bb7(D, Ab)의 음이 비슷한 손 모양이라 혼동 | 코드 전환 직전 마디에서 다음 코드 이름을 소리 내어 말한 뒤 연주 |
| 코드 전환 마디에서 리듬이 끊긴다 | 4마디 구간을 따로만 연습하고 이어 붙이는 연습을 안 함 | 3단계(12마디 전체 이어 치기)를 충분히 반복 |
| 왼손 근음이 자꾸 다른 옥타브로 이동한다 | 코드마다 근음 위치를 매번 눈으로 찾음 | 손 모양을 고정하고 다음 코드까지 손을 최소한으로만 움직이는 연습 |
| 템포를 올리자마자 리듬이 정박처럼 굳는다 | 빠른 템포에서 스윙 비율을 유지하지 못함 | 템포를 한 단계 낮춰 스윙 비율이 유지되는 최고 속도를 먼저 확인 |
