<Callout type="info">
  **이번 편의 목표:** 18편의 8마디 발라드 진행 앞에 인트로 2마디, 뒤에 확장 6마디를 더한 16마디 오리지널 발라드 한 곡을 인트로부터 마지막 마디까지 셸 보이싱과 찰스턴 리듬으로 끊기지 않게 반주합니다. **연습 시간 목안:** 하루 20~30분 × 5일
</Callout>

## 개념 (짧게)

이번 편도 새 이론이 없습니다. 18편에서 만든 8마디 진행(Cmaj7-Am7-Fmaj7-Em7-Dm7-G7-Cmaj7-Cmaj7)을 그대로 가운데에 두고, 앞에 인트로 2마디, 뒤에 확장 6마디를 붙여 16마디 한 곡을 완성하는 것이 목표입니다.

<Callout type="warning">
  이 진행은 저작권이 있는 실제 스탠다드 곡의 멜로디가 아닌, 이 과목만을 위해 만든 자작 발라드 진행입니다. 다이어토닉 코드와 ii-V-I 진행을 조합한 화성 구조이며, 실존하는 특정 곡을 그대로 옮긴 것이 아닙니다.
</Callout>

16마디는 다음 네 구간으로 나뉩니다.

| 구간(마디) | 역할 | 이번 편에서 하는 것 |
|---|---|---|
| 1–2 | 인트로(신규) | 다이어토닉 코드(Cmaj7, Fmaj7)만, 리듬 없이 온음표로 |
| 3–10 | 18편 진행 재현 | Cmaj7-Am7-Fmaj7-Em7-Dm7-G7-Cmaj7-Cmaj7, 셸+가이드톤+찰스턴 그대로 |
| 11–15 | 확장(신규) | Fmaj7-Em7-Dm7-G7-Cmaj7로 다시 한 번 서브도미넌트에서 토닉으로 이동 |
| 16 | 최종 마무리(신규) | Cmaj7, 리듬 없이 온음표로 정지 |

10마디는 18편에서 원래 곡이 끝나던 자리입니다. 이번 편에서는 그 자리를 완전한 끝이 아니라 잠깐 숨을 고르는 중간 지점으로 바꾸고, 11마디부터 같은 화성 재료(Fmaj7-Em7-Dm7-G7-Cmaj7)로 한 번 더 서브도미넌트에서 토닉으로 이동해 16마디째에 진짜 끝을 만듭니다.

> **쉽게 말하면:** 인트로는 곡이 시작되기 전 숨 고르는 구간이고, 10마디는 원래 끝이었던 자리에서 한 번 더 걸어가는 다리이며, 16마디는 곡이 끝났다는 정지 신호입니다.

## 건반과 악보로 보기

18편에서 정리한 셸 보이싱(왼손, 근음+7th)과 가이드톤(오른손, 3rd+7th) 표를 그대로 재사용합니다. 새 코드는 하나도 없습니다.

| 코드 | 왼손 셸(근음+7th) | 오른손 가이드톤(3rd+7th) |
|---|---|---|
| Cmaj7 | C+B | E+B |
| Am7 | A+G | C+G |
| Fmaj7 | F+E | A+E |
| Em7 | E+D | G+D |
| Dm7 | D+C | F+C |
| G7 | G+F | B+F |

왼손은 셸 보이싱(근음+7th)을 온음표로 한 마디 내내 유지하고, 오른손은 가이드톤(3rd+7th)을 찰스턴 리듬(1박 + 2박의 뒷박)으로 짚습니다. 인트로 2마디만 오른손도 리듬 없이 온음표로 채웁니다. 아래는 곡 맨 앞 4마디(인트로 2마디 + 18편 진행 시작 2마디)로 이 차이를 먼저 확인합니다.

인트로 두 마디(Cmaj7, Fmaj7)는 양손 모두 온음표로만 채워 리듬이 없고, 3마디부터 18편 진행이 시작되면서 오른손에 찰스턴 리듬(8분음표 3+5 단위로 나뉜 붙임음)이 등장하는 차이를 확인합니다.

건반 위 코드별 근음과 가이드톤 위치는 다음과 같습니다.

```
C  D  E  F  G  A  B
   #     #  #
```

## 연습 과제

<Steps>

### 1. 3~10마디 복습

18편에서 이미 연습한 8마디이므로 손 모양은 그대로입니다. 메트로놈 BPM 60으로 3~10마디만 먼저 4회 통과합니다.

### 2. 11~16마디 새로 익히기

같은 BPM 60에서 11~16마디(Fmaj7-Em7-Dm7-G7-Cmaj7-Cmaj7)만 따로 떼어 왼손 셸, 오른손 가이드톤 순서로 나눠 연습한 뒤 양손을 합칩니다. 4회 반복합니다.

### 3. 인트로 붙이기

1~2마디 인트로를 앞에 붙여 1~10마디를 이어 연주합니다. 인트로에서 찰스턴 리듬이 미리 나오지 않는지 확인합니다.

### 4. 전체 16마디 통연주

BPM 60으로 8회 통과한 뒤 BPM 66, BPM 70 순서로 올립니다. 각 템포에서 4회 이상 끊기지 않아야 다음 템포로 넘어갑니다.

### 5. 진행 표 보지 않고 연주

코드 진행 표를 가리고 16마디를 끝까지 반주합니다. 막히는 마디가 있으면 그 마디가 속한 구간(개념 부분의 표)으로 돌아가 다시 연습합니다.

</Steps>
