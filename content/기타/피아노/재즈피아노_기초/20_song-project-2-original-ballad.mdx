## 개념 (짧게)

이번 편도 새 이론이 없습니다. 18편에서 만든 8마디 진행(Cmaj7-Am7-Fmaj7-Em7-Dm7-G7-Cmaj7-Cmaj7)을 그대로 가운데에 두고, 앞에 인트로 2마디, 뒤에 확장 6마디를 붙여 16마디 한 곡을 완성하는 것이 목표입니다.

<Callout type="warning">
  이 진행은 저작권이 있는 실제 스탠다드 곡의 멜로디가 아닌, 이 과목만을 위해 만든 자작 발라드 진행입니다. 다이어토닉 코드와 ii-V-I 진행을 조합한 화성 구조이며, 실존하는 특정 곡을 그대로 옮긴 것이 아닙니다.
</Callout>

16마디는 다음 네 구간으로 나뉩니다.

| 구간(마디) | 역할 | 이번 편에서 하는 것 |
|---|---|---|
| 1–2 | 인트로(신규) | 다이어토닉 코드(Cmaj7, Fmaj7)만, 리듬 없이 온음표로 |
| 3–10 | 18편 진행 재현 | Cmaj7-Am7-Fmaj7-Em7-Dm7-G7-Cmaj7-Cmaj7, 셸+가이드톤+찰스턴 그대로 |
| 11–15 | 확장(신규) | Fmaj7-Em7-Dm7-G7-Cmaj7로 다시 한 번 서브도미넌트에서 토닉으로 이동 |
| 16 | 최종 마무리(신규) | Cmaj7, 리듬 없이 온음표로 정지 |

10마디는 18편에서 원래 곡이 끝나던 자리입니다.

## 건반과 악보로 보기

18편에서 정리한 셸 보이싱(왼손, 근음+7th)과 가이드톤(오른손, 3rd+7th) 표를 그대로 재사용합니다. 새 코드는 하나도 없습니다.

| 코드 | 왼손 셸(근음+7th) | 오른손 가이드톤(3rd+7th) |
|---|---|---|
| Cmaj7 | C+B | E+B |
| Am7 | A+G | C+G |
| Fmaj7 | F+E | A+E |
| Em7 | E+D | G+D |
| Dm7 | D+C | F+C |
| G7 | G+F | B+F |

왼손은 셸 보이싱(근음+7th)을 온음표로 한 마디 내내 유지하고, 오른손은 가이드톤(3rd+7th)을 찰스턴 리듬(1박 + 2박의 뒷박)으로 짚습니다. 인트로 2마디만 오른손도 리듬 없이 온음표로 채웁니다. 아래는 곡 맨 앞 4마디(인트로 2마디 + 18편 진행 시작 2마디)로 이 차이를 먼저 확인합니다.

인트로 두 마디(Cmaj7, Fmaj7)는 양손 모두 온음표로만 채워 리듬이 없고, 3마디부터 18편 진행이 시작되면서 오른손에 찰스턴 리듬(8분음표 3+5 단위로 나뉜 붙임음)이 등장하는 차이를 확인합니다.

건반 위 코드별 근음과 가이드톤 위치는 다음과 같습니다.

```
C  D  E  F  G  A  B
   #     #  #
```

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| 인트로 2마디에서 이미 찰스턴 리듬을 친다 | 인트로와 3마디부터 시작되는 본 진행을 구분하지 않음 | 인트로는 양손 모두 온음표로만, 3마디부터 찰스턴 시작 |
| 10마디에서 완전히 곡이 끝난 것처럼 손을 뗀다 | 온음표로 길게 두는 것을 종지로 착각 | 10마디는 잠깐 숨 고르는 지점일 뿐, 11마디부터 같은 진행이 다시 이어짐을 미리 확인 |
| 11–16마디에서 3–10마디와 다른 새 화성이 나올 것이라고 기대한다 | 확장 구간도 완전히 새로운 코드로 착각 | 11–16마디는 이미 배운 Fmaj7-Em7-Dm7-G7-Cmaj7을 그대로 재사용한다는 것을 먼저 확인 |
