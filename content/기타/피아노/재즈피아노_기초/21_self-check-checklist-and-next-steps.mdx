  **이번 편의 목표:** 지금까지 배운 여섯 영역(건반·스케일·코드·보이싱·리듬·블루스 반주)을 항목별 통과 기준으로 스스로 점검하고, 막히는 부분을 어느 편에서 다시 볼지 확인합니다. **연습 시간 목안:** 하루 30~40분 × 2일
</Callout>

## 개념 (짧게)

이 편은 새 개념을 배우지 않습니다. 01편부터 20편까지 쌓아온 것을 여섯 영역으로 나눠 스스로 확인하는 편입니다. 자가 점검은 몇 번 쳤는가가 아니라 정해진 통과 기준을 실제로 만족하는가로 판단합니다. 통과 기준을 만족하지 못하면 실력이 부족한 것이 아니라, 아직 그 영역의 반복 횟수가 부족한 것뿐입니다. 막히는 영역이 있으면 부담 없이 해당 편으로 돌아가 다시 연습합니다.

여섯 영역과 점검 방식은 다음과 같습니다.

| 영역 | 점검 방식 |
|---|---|
| 건반 | 음이름을 듣고 건반 위치를 짚기 |
| 스케일 | 조성을 듣고 스케일을 손으로 만들기 |
| 코드 | 코드 심벌을 보고 구성음을 말하기 |
| 보이싱 | 코드 심벌을 보고 왼손 모양을 즉시 짚기 |
| 리듬 | 메트로놈에 맞춰 리듬 패턴을 재현하기 |
| 블루스 반주 | 12마디 전체를 끊기지 않고 반주하기 |

> **쉽게 말하면:** 이번 편은 성적을 매기는 시험이 아니라 지도입니다. 어디가 튼튼하고 어디를 더 다져야 하는지 표시하는 역할만 합니다.

## 영역별 자가 점검표

아래 표에서 항목마다 통과 기준을 만족하는지 확인합니다. 통과하지 못한 항목은 마지막 열의 편으로 돌아갑니다.

| 영역 | 확인 항목 | 통과 기준 | 막히면 복습할 편 |
|---|---|---|---|
| 건반 | 무작위 음이름 12개를 듣고 건반에서 짚기 | 하나당 3초 이내, 12개 모두 정확 | 01 |
| 리듬 기호 | 온음표–8분음표가 섞인 4마디 리듬을 보고 손뼉으로 재현 | 메트로놈과 어긋나지 않게 4마디 끝까지 | 02 |
| 코드 심벌 | Cmaj7·Dm7·G7·Cm7(b5) 등 코드 심벌을 보고 구성음 말하기 | 5초 이내, 근음·3rd·7th까지 정확 | 03 |
| 메이저·마이너 스케일 | C·F·G 메이저 스케일과 A 자연단조를 오른손으로 상행·하행 | 손가락 번호를 바꾸지 않고 끊김 없이 | 04, 05 |
| 5도권 | 5도권에서 인접한 조 3개의 조표 개수 말하기 | 5초 이내 정확 | 06 |
| 다이어토닉 코드 | C메이저 다이어토닉 3화음·7th 코드 7개를 순서대로 치기 | I부터 vii까지 끊김 없이 | 07, 08 |
| 보이싱 | 코드 심벌을 보고 클로즈드 보이싱과 셸 보이싱(근음+3rd, 근음+7th)을 각각 짚기 | 3초 이내, 두 형태 모두 | 09, 10 |
| ii-V-I | C키 Dm7–G7–Cmaj7을 셸 보이싱으로 연결 | 손 이동 없이 부드럽게 3코드 연결 | 11 |
| 스윙·컴핑 리듬 | 스윙 8분음표와 찰스턴 리듬을 메트로놈 BPM 80에서 재현 | 클릭과 어긋나지 않게 4마디 반복 | 12, 13 |
| 블루스 반주 | F 12마디 블루스를 코드+리듬+베이스 패턴으로 끊김 없이 | 처음부터 끝까지 12마디 통과 | 14, 15, 16 |
| 즉흥 프레이즈 | 블루스 스케일로 2마디 프레이즈를 코드톤에 착지시켜 만들기 | 코드가 바뀌는 지점에서 어색하지 않게 | 17 |
| 종합 반주 | 16마디 발라드 진행을 인트로부터 끝까지 반주 | 20편 진행표대로 끊김 없이 | 18, 19, 20 |

## 연습 과제

<Steps>

### 1. 영역별로 하루 한두 개씩만 확인

한 번에 여섯 영역을 다 확인하려 하지 않습니다. 하루에 한두 영역만 골라 통과 기준과 비교합니다.

### 2. 통과하지 못한 항목은 바로 그 편으로 돌아가기

막힌 항목의 복습할 편 칸을 보고 해당 편의 연습 과제만 다시 진행합니다. 처음부터 전체를 다시 볼 필요는 없습니다.

### 3. 녹음해서 다시 듣기

가능하면 스마트폰으로 짧게 녹음합니다. 연주 중에는 못 느낀 리듬 밀림이나 멈칫거림이 녹음을 들으면 더 잘 들립니다.

### 4. 통과한 항목도 일주일 뒤 한 번 더 확인

한 번 통과했다고 완전히 끝난 것은 아닙니다. 일주일 뒤 같은 항목을 다시 확인해 유지되는지 봅니다.

</Steps>

## 다음 배울 것

체크리스트를 모두 통과했다면 재즈피아노_중급으로 넘어갈 준비가 된 것입니다. 이 과목에서는 다음과 같은 것을 다룹니다.

| 영역 | 재즈피아노_기초에서 한 것 | 재즈피아노_중급에서 새로 배우는 것 |
|---|---|---|
| 진행 | C키 ii-V-I 하나 | 여러 조성의 메이저·마이너 2-5-1 진행 |
| 왼손 보이싱 | 셸 보이싱(근음+3rd, 근음+7th) | 루트리스 보이싱(A/B form) |
| 코드 확장 | 다이어토닉 7th 코드까지 | 텐션(9·13, 알터드 텐션)을 얹은 보이싱 |
| 왼손 저음 | 근음–5음 베이스 패턴 | 코드톤과 경과음으로 만든 워킹 베이스 |
| 반주 대상 | 오리지널 블루스·발라드 진행 | 실제 재즈 스탠다드 5곡의 코드 진행 |

> **쉽게 말하면:** 지금까지 왼손으로 코드의 뼈대(근음·3rd·7th)만 짚었다면, 다음 과목에서는 그 뼈대에 색을 입히고(텐션), 저음을 걸어 다니게(워킹 베이스) 만듭니다.

## 자주 하는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| 통과 기준 없이 그냥 되는 것 같다고 넘어간다 | 표의 통과 기준을 확인하지 않음 | 항목마다 통과 기준 문장을 소리 내어 읽고 그대로 확인 |
| 막힌 항목을 대충 넘기고 다음 영역으로 간다 | 여섯 영역을 한 번에 끝내려는 조급함 | 하루 한두 영역만 확인하고 막힌 항목은 바로 복습 |
| 블루스 반주만 확인하고 앞 영역은 건너뛴다 | 뒤 영역이 더 어려우니 앞 영역은 저절로 됐다고 생각함 | 앞 영역(건반·스케일)도 표 순서대로 빠짐없이 확인 |
| 한 번 통과하면 다시 안 봐도 된다고 생각한다 | 통과를 최종 완성으로 착각 | 일주일 뒤 같은 항목을 한 번 더 확인 |
