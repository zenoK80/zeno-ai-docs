## 개념 (짧게)

지금까지는 진행, 보이싱, 텐션, 워킹 베이스, 컴핑, 솔로를 각각 따로 연습했습니다. 실제 곡에서는 이 요소들이 동시에 겹쳐서 나옵니다. 코드가 바뀌는 순간 왼손 베이스와 오른손 보이싱이 같이 움직여야 하고, 솔로로 넘어가는 지점도 미리 정해 둬야 합니다. 이번 편은 새 개념을 배우지 않고, 03~20편까지 익힌 것을 한 곡의 틀 안에서 이어 붙이는 데 집중합니다. 여러 악기 파트를 한 사람이 두 손으로 나눠 맡는 것과 같습니다.

"오리지널 진행"은 저작권이 있는 스탠다드 대신, 배운 화성 어휘(ii-V-I, 부속 도미넌트, 텐션)로 직접 만든 16마디 진행입니다. 코드 진행만 정해져 있고 멜로디는 없으므로, 오른손은 보이싱 또는 솔로 라인을 자유롭게 채웁니다.

이 곡의 형식은 AABA가 아니라 16마디를 처음부터 끝까지 한 번에 흘러가는 "스루(through) 형식"입니다. AABA는 8마디 단위가 반복·대비되면서 구조를 알아채기 쉽지만, 스루 형식은 반복 구간이 없어서 화성이 계속 앞으로 나아가는 느낌을 줍니다. 그래서 이 곡은 연주자가 스스로 구간을 나눠 외워야 하며, 위 표의 4마디 단위 구분이 그 역할을 합니다.

이 곡에서 쓰는 기법을 구간별로 정리하면 다음과 같습니다.

| 구간 | 사용 기법 | 이어지는 편 |
|------|-----------|-------------|
| 1–4마디 | ii-V-I 기본형 + 부속 도미넌트(V7/ii) | 03, 05, 06 |
| 5–8마디 | iii-V7/ii-ii-V 순환(부속 도미넌트 반복) | 03, 07 |
| 9–12마디 | IV-iv(마이너 서브도미넌트 차용)-I-V7/ii(#9) | 04, 08 |
| 13–16마디 | ii-V(b13)-I 종지 | 08, 06 |
| 솔로 8마디 | 9–16마디 진행 재사용 + 코드톤 중심 가이드톤 라인 | 13, 14 |

## 건반과 악보로 보기

2마디의 A7(b9)는 3마디 Dm7으로 가는 부속 도미넌트입니다. 부속 도미넌트에서 텐션을 얹을 때는 보통 5th 자리를 빼고 그 자리에 텐션을 넣습니다. 아래 악보는 A7(b9)의 B form(7th이 최저음)이 Dm7의 A form(3rd이 최저음)으로 부드럽게 이어지는 모습입니다.

A7(b9)의 오른손 구성음은 b7(G), b9(Bb), 3rd(C#)이며, 5th은 생략합니다. 건반에서 이 세 음의 위치는 다음과 같습니다.

```
      C#      F#  G#  A#
C  D  E  F  G  A  B
```

| 사용 음 | 코드 내 역할 |
|---------|--------------|
| C# | 3rd |
| G | b7(근음에서 볼 때 딸림7도) |
| Bb | b9(텐션) |

Dm7으로 넘어갈 때 C#은 반음 아래 C로, Bb는 A로 내려가며 정리됩니다. 왼손은 A에서 D로 4도 아래로 움직여 진행의 방향을 잡아 줍니다.

이 두 코드처럼, 이 곡 전체는 왼손이 근음만 온음표로 짚고 오른손이 근음을 뺀 보이싱을 담당하는 역할 분담을 그대로 따릅니다. 오른손이 매번 근음까지 같이 누르면 저음이 두꺼워져서 왼손의 움직임이 잘 들리지 않습니다. 역할을 나누면 왼손의 4도·5도 진행이 선명하게 들리고, 오른손은 손을 적게 움직이고도 코드가 바뀌는 것을 표현할 수 있습니다.

| 손 | 담당 | 이유 |
|-----|------|------|
| 왼손 | 근음(온음표) | 진행의 뼈대를 저음에서 분명히 들려줌 |
| 오른손 | 3rd·5th·7th·텐션(근음 제외) | 코드 성질과 색을 담당, 손 이동을 최소화 |

## 연습 과제

<Steps>

### 1. 왼손 베이스만 16마디

악보 없이 표만 보고 왼손 5번 손가락으로 각 마디의 근음을 짚습니다. BPM 70, 4회 반복합니다.

### 2. 오른손 보이싱만 16마디

왼손 없이 오른손으로만 16마디의 보이싱을 짚습니다. 1-2-3-5 손가락을 기본으로 쓰고, 5음 구성일 때만 4번을 추가합니다. BPM 70입니다.

### 3. 양손 합치기(4마디씩)

1~4마디, 5~8마디, 9~12마디, 13~16마디를 각각 따로 양손으로 합칩니다. 한 구간이 편해지면 다음 구간으로 넘어갑니다. BPM 80입니다.

### 4. 8마디 솔로 오른손 단독 연습

각 마디 첫박에 코드톤(주로 근음이나 3rd)에 정확히 도착하는지 확인하며 천천히 연주합니다. BPM 70입니다.

### 5. 전체 24마디 연결

16마디 반주 뒤에 바로 8마디 솔로를 이어 붙여 끊지 않고 연주합니다. BPM 100, 스윙 리듬으로 4회 반복합니다.

### 6. 12키 이동 연습

같은 진행을 F키로 옮겨 한 번 더 연주합니다(모든 코드를 완전4도 위로 이동). 조성이 바뀌어도 손 모양의 논리는 그대로라는 것을 확인합니다. 예를 들어 1마디 Cmaj7-A7(b9)-Dm7-G7은 F키에서 Fmaj7-D7(b9)-Gm7-C7이 되며, 손가락 순서와 A/B form이 교차하는 방식은 조성과 무관하게 동일합니다.

</Steps>

9마디에서 10마디로 넘어갈 때(Fmaj7에서 Fm7)는 근음이 그대로 F여서 왼손은 움직이지 않고, 오른손 3rd만 A에서 Ab로 반음 내려갑니다. 이 반음 하나가 코드의 성질을 메이저에서 마이너로 완전히 바꾸므로, 이 지점은 특히 천천히 연습해 귀로 그 차이를 분명히 확인해야 합니다.

전체 폼을 두 손, 코드 심벌과 함께 악보로 옮기면 다음과 같습니다. 오른손은 근음을 뺀 보이싱만, 왼손은 각 마디의 근음만 온음표로 연주합니다.

솔로는 매 마디 첫박을 코드톤에 정확히 맞춰, 화성이 바뀌어도 라인이 흔들리지 않도록 만들었습니다. 마지막 마디는 근음 C로 길게 끝내 곡을 정리합니다.

곡 전체를 이어 연주할 때는 음량도 함께 계획합니다. 1~8마디는 보통 세기(메조포르테)로 진행을 소개하고, 9~16마디는 코드 성질이 바뀌는 지점(Fmaj7-Fm7)에서 살짝 힘을 주어 변화를 강조합니다. 솔로 8마디는 반주보다 한 단계 여리게 시작해, 마지막 마디에서 다시 원래 세기로 돌아오며 곡을 마무리합니다. 이런 음량 계획은 정해진 규칙이 아니라 하나의 예시이므로, 스스로 다른 계획을 세워 봐도 좋습니다.

## 자주 하는 실수

여러 기법을 한 곡에 합칠 때는 각 기법을 따로 연습할 때는 없던 문제가 새로 생깁니다. 대부분 두 요소를 잇는 지점(마디와 마디 사이, 반주와 솔로 사이)에서 발생합니다.

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 부속 도미넌트에서 다음 코드로 넘어갈 때 손이 늦음 | A7(b9)를 독립된 코드로만 연습하고 Dm7과 묶어서 연습하지 않음 | 항상 두 마디를 한 단위로 묶어 연습한다 |
| 9–12마디에서 진행이 헷갈림 | Fmaj7과 Fm7의 근음이 같아 코드 성질 전환을 놓침 | 3rd(A와 Ab)만 따로 짚어 소리 차이를 먼저 확인한다 |
| 솔로로 넘어가는 지점에서 박자가 흔들림 | 16마디 반주와 8마디 솔로를 따로만 연습해 이어붙인 적이 없음 | 5번 연습 과제(24마디 연결)를 매일 포함한다 |
| G7(b13)에서 소리가 어색함 | b13(Eb)과 5th(D)를 같이 눌러 충돌음이 남 | b13을 쓸 때는 5th을 완전히 빼고 3-b7-b13만 남긴다 |
| 12키 이동 시 코드를 하나씩 다시 찾음 | 코드 이름이 아니라 손 모양 자체를 외움 | 로마 숫자 기능(ii-V-I 등)으로 기억해 조성이 바뀌어도 같은 순서로 옮긴다 |
