## 개념 (짧게)

지금까지는 진행, 보이싱, 텐션, 워킹 베이스, 컴핑, 솔로를 각각 따로 연습했습니다. 실제 곡에서는 이 요소들이 동시에 겹쳐서 나옵니다.

"오리지널 진행"은 저작권이 있는 스탠다드 대신, 배운 화성 어휘(ii-V-I, 부속 도미넌트, 텐션)로 직접 만든 16마디 진행입니다. 코드 진행만 정해져 있고 멜로디는 없으므로, 오른손은 보이싱 또는 솔로 라인을 자유롭게 채웁니다.

이 곡의 형식은 AABA가 아니라 16마디를 처음부터 끝까지 한 번에 흘러가는 "스루(through) 형식"입니다. AABA는 8마디 단위가 반복·대비되면서 구조를 알아채기 쉽지만, 스루 형식은 반복 구간이 없어서 화성이 계속 앞으로 나아가는 느낌을 줍니다.

이 곡에서 쓰는 기법을 구간별로 정리하면 다음과 같습니다.

| 구간 | 사용 기법 | 이어지는 편 |
|------|-----------|-------------|
| 1–4마디 | ii-V-I 기본형 + 부속 도미넌트(V7/ii) | 03, 05, 06 |
| 5–8마디 | iii-V7/ii-ii-V 순환(부속 도미넌트 반복) | 03, 07 |
| 9–12마디 | IV-iv(마이너 서브도미넌트 차용)-I-V7/ii(#9) | 04, 08 |
| 13–16마디 | ii-V(b13)-I 종지 | 08, 06 |
| 솔로 8마디 | 9–16마디 진행 재사용 + 코드톤 중심 가이드톤 라인 | 13, 14 |

## 건반과 악보로 보기

2마디의 A7(b9)는 3마디 Dm7으로 가는 부속 도미넌트입니다. 부속 도미넌트에서 텐션을 얹을 때는 보통 5th 자리를 빼고 그 자리에 텐션을 넣습니다. 아래 악보는 A7(b9)의 B form(7th이 최저음)이 Dm7의 A form(3rd이 최저음)으로 부드럽게 이어지는 모습입니다.

<AbcScore
title="A7(b9) → Dm7 부속 도미넌트 연결(swing)" abc={`X:1 T:A7(b9) to Dm7 M:4/4 L:1/8 Q:1/4=100 K:C V:1 clef=treble "A7(b9)"[G_B^c]8 | "Dm7"[FAc]8 |] V:2 clef=bass A,8 | D,8 |] `} />

A7(b9)의 오른손 구성음은 b7(G), b9(Bb), 3rd(C#)이며, 5th은 생략합니다. 건반에서 이 세 음의 위치는 다음과 같습니다.

```
      C#      F#  G#  A#
C  D  E  F  G  A  B
```

| 사용 음 | 코드 내 역할 |
|---------|--------------|
| C# | 3rd |
| G | b7(근음에서 볼 때 딸림7도) |
| Bb | b9(텐션) |

Dm7으로 넘어갈 때 C#은 반음 아래 C로, Bb는 A로 내려가며 정리됩니다. 왼손은 A에서 D로 4도 아래로 움직여 진행의 방향을 잡아 줍니다.

이 두 코드처럼, 이 곡 전체는 왼손이 근음만 온음표로 짚고 오른손이 근음을 뺀 보이싱을 담당하는 역할 분담을 그대로 따릅니다. 역할을 나누면 왼손의 4도·5도 진행이 선명하게 들리고, 오른손은 손을 적게 움직이고도 코드가 바뀌는 것을 표현할 수 있습니다.

| 손 | 담당 | 이유 |
|-----|------|------|
| 왼손 | 근음(온음표) | 진행의 뼈대를 저음에서 분명히 들려줌 |
| 오른손 | 3rd·5th·7th·텐션(근음 제외) | 코드 성질과 색을 담당, 손 이동을 최소화 |

## 자주 하는 실수

여러 기법을 한 곡에 합칠 때는 각 기법을 따로 연습할 때는 없던 문제가 새로 생깁니다. 대부분 두 요소를 잇는 지점(마디와 마디 사이, 반주와 솔로 사이)에서 발생합니다.

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 부속 도미넌트에서 다음 코드로 넘어갈 때 손이 늦음 | A7(b9)를 독립된 코드로만 연습하고 Dm7과 묶어서 연습하지 않음 | 항상 두 마디를 한 단위로 묶어 연습한다 |
| 9–12마디에서 진행이 헷갈림 | Fmaj7과 Fm7의 근음이 같아 코드 성질 전환을 놓침 | 3rd(A와 Ab)만 따로 짚어 소리 차이를 먼저 확인한다 |
| 솔로로 넘어가는 지점에서 박자가 흔들림 | 16마디 반주와 8마디 솔로를 따로만 연습해 이어붙인 적이 없음 | 5번 연습 과제(24마디 연결)를 매일 포함한다 |
