  **이번 편의 목표:** 12마디 마이너 블루스를 스스로 설계하고, 마이너 2-5-1과 얼터드 텐션을 적용한 뒤 블루스 스케일 솔로로 곡을 마무리합니다. · **연습 시간 목안:** 하루 20~30분 × 5일

## 개념 (짧게)

마이너 블루스는 21편의 메이저 진행과 뼈대는 같은 12마디지만, 시작 코드가 마이너7이고 후반부에 마이너 2-5-1(iiø-V7alt-i)이 들어간다는 점이 다릅니다. 04편에서 배운 마이너 2-5-1과 08편의 얼터드 도미넌트 텐션이 이 곡에서 실제로 어디에 쓰이는지 확인하는 것이 이번 편의 목적입니다.

이 곡은 순수한 다이어토닉 마이너만 쓰지 않습니다. 8마디에서 잠깐 상대 메이저(같은 조표를 쓰는 메이저 키) 쪽으로 색을 바꾸는 코드를 넣어, 어둡기만 한 진행에 대비를 줍니다. 마이너 블루스가 메이저 블루스보다 화성적으로 더 다양하게 느껴지는 이유가 여기에 있습니다.

12마디 구조 자체는 09~10편에서 연습한 메이저 블루스와 같은 길이지만, 내부 화성은 다릅니다. 메이저 블루스가 1-4-1-5 중심의 단순한 도미넌트 순환이라면, 이 마이너 블루스는 후반부(9~12마디)에 완전한 마이너 2-5-1과 턴어라운드가 들어가 훨씬 더 화성적인 목적지를 향해 움직입니다. 같은 12마디라는 틀 안에서도 화성 밀도가 다를 수 있다는 것을 이 곡으로 확인합니다.

이 곡에서 쓰는 기법을 구간별로 정리하면 다음과 같습니다.

| 구간 | 사용 기법 | 이어지는 편 |
|------|-----------|-------------|
| 1–4마디 | Cm7 중심 토닉 구간 | 04 |
| 5–7마디 | Fm7 서브도미넌트 구간 | 04, 09 |
| 8마디 | Ebmaj7(상대 메이저 차용) | 04 |
| 9–11마디 | 마이너 2-5-1(Dm7(b5)-G7alt-Cm7) | 04, 08 |
| 12마디 | 턴어라운드(Dm7(b5)-G7alt 반복) | 04, 08 |
| 마무리 솔로 | 12마디 전체에 블루스 스케일 솔로 | 13, 14 |

## 건반과 악보로 보기

9~10마디의 Dm7(b5) → G7(alt)는 마이너 키에서 가장 중요한 캐던스입니다. Dm7(b5)는 b3·b5·b7로 이루어져 불안정한 소리를 내고, G7(alt)는 자연스러운 5th 대신 얼터드 텐션(b9)을 넣어 그 불안정함을 더 키운 뒤 Cm7으로 해결합니다.

각 코드의 오른손 구성음을 건반 위치로 정리하면 다음과 같습니다.

```
      C#  D#     F#  G#  A#
C  D  E   F  G  A  B
```

| 코드 | 구성음(근음 제외) | 건반 위치 |
|------|-------------------|-----------|
| Dm7(b5) | F(b3), Ab(b5), C(b7) | F–Ab(검은건반)–C |
| G7(b9) | B(3), F(b7), Ab(b9) | B–F–Ab(검은건반) |
| Cm7 | Eb(b3), G(5), Bb(b7) | Eb(검은건반)–G–Bb(검은건반) |

Dm7(b5)의 Ab와 G7(b9)의 Ab는 같은 건반이지만 코드 안에서 역할이 다릅니다(b5 다음 b9). 같은 음이 코드마다 다른 이름과 역할을 가질 수 있다는 것을 확인하는 좋은 예시입니다.

21편과 마찬가지로 이 곡도 왼손과 오른손의 역할을 나눕니다. 왼손이 근음을 담당해야 마이너 2-5-1처럼 화성이 빠르게 움직이는 구간에서도 진행의 방향이 저음에서 분명히 들립니다.

| 손 | 담당 | 이유 |
|-----|------|------|
| 왼손 | 근음(온음표, 12마디는 절반씩) | 화성이 빠르게 바뀌는 구간에서 진행의 뼈대를 분명히 들려줌 |
| 오른손 | b3·5·b7·텐션(근음 제외) | 마이너 코드 특유의 어두운 색과 얼터드 텐션을 표현 |

## 연습 과제

<Steps>

### 1. 마이너 2-5-1(9~11마디)만 반복

Dm7(b5)-G7(b9)-Cm7 세 코드만 따로 떼어 BPM 70으로 8회 반복합니다. 오른손 3-1-3 손가락으로 세 코드를 짚습니다.

### 2. 왼손 근음 12마디

악보 없이 아래 코드표만 보고 왼손 5번 손가락으로 12마디의 근음을 순서대로 짚습니다. BPM 70입니다.

### 3. 양손 합치기(4마디씩)

1~4마디, 5~8마디, 9~12마디를 각각 따로 양손으로 합칩니다. 8마디의 Ebmaj7에서 손 모양이 갑자기 밝아지는 느낌을 확인합니다.

### 4. 블루스 스케일 솔로 오른손 단독 연습

C 마이너 블루스 스케일(C, Eb, F, F#, G, Bb)로 만든 12마디 솔로를 오른손만으로 BPM 70에 연습합니다. 9~10마디는 스케일 대신 코드톤(F, Ab, B, Ab)을 우선합니다.

### 5. 전체 24마디(반주+솔로) 연결

12마디 반주를 먼저 연주하고 같은 진행에 12마디 솔로를 이어 붙입니다. BPM 90, 스윙 리듬으로 4회 반복합니다.

### 6. 12키 이동 연습

같은 진행을 G키(Gm7 시작)로 옮겨 한 번 더 연주합니다. 예를 들어 9~11마디 Dm7(b5)-G7(alt)-Cm7은 G키에서 Am7(b5)-D7(alt)-Gm7이 되며, 마이너 2-5-1의 손 모양이 조성과 무관하게 똑같이 유지되는지 확인합니다.

</Steps>

반주에서는 10마디와 12마디의 G7(alt) 모두 3-b7-#9 구성을 그대로 유지해, 같은 얼터드 색이 곡 전체에서 반복되도록 했습니다.

반주 12마디를 연주할 때는 8마디 Ebmaj7에서 음량을 살짝 올려 상대 메이저로 넘어가는 순간을 밝게 강조하고, 9마디부터는 다시 어두운 색으로 돌아가며 마이너 2-5-1의 긴장을 쌓습니다. 이런 음량 계획도 정해진 규칙이 아니라 예시이므로, 직접 다르게 설계해 봐도 좋습니다.

곡을 마무리하는 블루스 스케일 솔로는 12마디 전체에 걸쳐 있습니다. 왼손은 반주와 같은 근음을 유지하고, 오른손은 C 마이너 블루스 스케일과 각 코드의 코드톤을 섞어 라인을 만듭니다.

6마디는 앞 마디보다 한 옥타브 높은 자리에서 시작해 내려오는 모양으로, 같은 코드가 반복될 때 라인에 변화를 주는 방법을 보여 줍니다. 솔로의 10마디와 12마디는 반주와 달리 #9 대신 b9(Ab)을 골라, 같은 얼터드 도미넌트도 반주와 솔로에서 다른 텐션으로 표현할 수 있다는 것을 보여 줍니다. 12마디는 코드가 절반씩 바뀌는 지점에 맞춰 스케일 음도 함께 바뀝니다.

## 자주 하는 실수

곡을 처음부터 직접 설계할 때는 코드를 각각 따로 검증할 때는 안 보이던 문제가 생깁니다. 진행 전체를 이어서 연주해 봐야 드러나는 문제들입니다.

| 증상 | 원인 | 고치는 법 |
|------|------|-----------|
| 8마디 Ebmaj7에서 손이 멈칫함 | 마이너 코드만 계속 나오다가 갑자기 메이저 코드가 나와 순간적으로 코드 성질을 착각함 | Ebmaj7만 따로 5회 연속 짚어 손 모양을 먼저 몸에 익힌다 |
| 9마디 Dm7(b5)와 평소 Dm7이 헷갈림 | 5th을 완전5도로 짚는 습관이 남아 있음 | b5(Ab)를 먼저 짚고 나머지 음을 채우는 순서로 연습한다 |
| 10마디 G7(alt)에서 다음 코드로 늦게 이동함 | 얼터드 텐션 자체에 집중하느라 해결음(Cm7)을 준비하지 않음 | #9(A#)이 다음에 어디로 가는지(B로 반음 위) 미리 손가락으로 확인한다 |
| 솔로에서 F#(블루노트)을 안 씀 | 다이어토닉 스케일 습관이 남아 반음 변화음을 피함 | 6마디처럼 짧게 지나가는 음으로 먼저 시도한다 |
| 12마디 턴어라운드에서 박자가 무너짐 | 한 마디에 코드 두 개가 들어가는 것에 익숙하지 않음 | 12마디만 따로 떼어 절반씩(2박+2박) 세며 연습한다 |
