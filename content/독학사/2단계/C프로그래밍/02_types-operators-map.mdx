## 왜 용어를 영문까지 함께 익혀야 하는가

독학사 C프로그래밍 시험 지문은 한글로 되어 있지만, 정작 코드 안의 키워드·연산자·표준 라이브러리 함수 이름은 전부 영어입니다. `sizeof`, `unsigned`, `static`처럼 영어 단어 자체의 뜻을 알면 암기하지 않아도 의미가 짐작되는 키워드가 많은데도, 많은 입문자가 이 단어들을 "그냥 외워야 하는 암호"처럼 다룹니다. 이 편에서는 자료형·연산자·키워드를 영문 뜻과 함께 정리해서, 뒤에 나올 07~09편(자료형·연산자·제어문)을 읽을 때 "왜 이런 이름을 붙였는지" 바로 이해되도록 준비합니다.

> **쉽게 말하면:** 이 편은 영어 단어장이 아니라, "코드에 적힌 영어 단어 하나하나가 무슨 의도로 붙여진 이름인지" 알아 두는 지도입니다.

## 1. 기본 자료형 이름 지도

C의 기본 자료형(basic data type)은 크게 정수(integer)를 다루는 것과 실수(floating-point number)를 다루는 것, 문자(character)를 다루는 것으로 나뉩니다.

| 키워드 | 영문 풀이 | 뜻 | 시험에서 자주 확인하는 점 |
|--------|-----------|-----|----------------------------|
| `int` | integer(정수) | 정수를 저장하는 자료형 | 시스템(컴파일 환경)에 따라 크기가 다를 수 있으므로 특정 바이트 수를 절대적으로 단정하지 않음 |
| `char` | character(문자) | 문자 하나(정확히는 1바이트 정수)를 저장 | 문자 하나이지만 내부적으로는 정수로 취급되어 산술 연산이 가능함 |
| `float` | floating-point(부동소수점) | 소수점이 있는 실수를 저장(단정도) | `double`보다 정밀도가 낮음 |
| `double` | double precision(배정도) | `float`보다 더 정밀한 실수를 저장 | 이름 그대로 `float`의 두 배 정밀도라는 뜻에서 유래 |
| `void` | void(비어 있음, 없음) | 값이 없음을 나타냄 | 반환값이 없는 함수, 매개변수가 없음을 명시할 때 사용 |

여기에 자료형 앞에 붙는 **한정자**(qualifier, 자료형의 성질을 조정하는 키워드)도 함께 정리해 둡니다.

| 키워드 | 영문 풀이 | 뜻 |
|--------|-----------|-----|
| `unsigned` | un(부정 접두사) + signed(부호가 있는) | 부호(양수·음수 구분)를 쓰지 않고 0과 양수만 표현하는 자료형. 같은 비트 수로 더 큰 양수를 표현할 수 있다 |
| `signed` | signed(부호가 있는) | 양수와 음수를 모두 표현하는 자료형(정수형의 기본값) |
| `short` | short(짧은) | 기본 `int`보다 작거나 같은 크기의 정수 |
| `long` | long(긴) | 기본 `int`보다 크거나 같은 크기의 정수 |
| `const` | constant(상수의) | 선언 이후 값이 바뀌지 않아야 함을 컴파일러에게 알리는 키워드 |

**자주 틀리는 점**: "`int`는 항상 4바이트다"처럼 크기를 절대적으로 암기하면 위험합니다. C 표준은 각 자료형의 **최소 크기**만 보장하고, 정확한 바이트 수는 컴파일 환경(시스템)에 따라 달라질 수 있습니다. 정확한 크기를 알아내는 방법(`sizeof` 연산자)은 07편에서 실제 코드와 함께 다룹니다.

## 2. 주요 연산자 기호와 용어

연산자(operator)는 값을 계산하거나 비교하는 기호입니다. 크게 산술, 비교, 논리, 대입 네 갈래로 나눠서 정리합니다.

### 산술 연산자(arithmetic operator)

| 기호 | 영문 용어 | 뜻 |
|------|-----------|-----|
| `+` | addition | 덧셈 |
| `-` | subtraction | 뺄셈 |
| `*` | multiplication | 곱셈 |
| `/` | division | 나눗셈(정수끼리 나누면 몫만 남는 정수 나눗셈이 됨) |
| `%` | modulo(모듈로, 나머지 연산) | 나눗셈의 나머지 |

### 비교 연산자(relational operator, comparison operator)

시험 지문이나 코드 설명에서 부등호 기호를 문장 안에 그대로 쓰면 읽기 헷갈리므로, 아래에서는 기호를 코드 스팬으로 표기합니다.

| 기호 | 영문 용어 | 뜻 |
|------|-----------|-----|
| `==` | equal to | 두 값이 같은지 비교 |
| `!=` | not equal to | 두 값이 다른지 비교 |
| `>` | greater than | 왼쪽이 더 큰지 비교 |
| `<` | less than | 왼쪽이 더 작은지 비교 |
| `>=` | greater than or equal to | 왼쪽이 크거나 같은지 비교 |
| `<=` | less than or equal to | 왼쪽이 작거나 같은지 비교 |

**자주 틀리는 점**: 대입 연산자 `=`(assignment)와 비교 연산자 `==`(equal to)를 혼동하는 것은 C 문법 문제에서 가장 자주 나오는 함정입니다. `if (a = 5)`처럼 비교하려던 자리에 실수로 대입 연산자 하나만 쓰면, 이 식은 "`a`와 5가 같은지 비교"하는 것이 아니라 "`a`에 5를 대입하고, 그 결과값 5(참으로 취급됨)를 조건으로 사용"하게 되어 항상 참이 되는 논리 오류가 발생합니다. 이 함정은 08~09편에서 실제 코드와 함께 다시 확인합니다.

### 논리 연산자(logical operator)

| 기호 | 영문 용어 | 뜻 |
|------|-----------|-----|
| `&&` | logical AND | 양쪽 조건이 모두 참일 때만 참 |
| `\|\|` | logical OR | 양쪽 조건 중 하나라도 참이면 참 |
| `!` | logical NOT | 참과 거짓을 뒤집음 |

### 대입 연산자(assignment operator)

| 기호 | 영문 용어 | 뜻 |
|------|-----------|-----|
| `=` | assignment | 오른쪽 값을 왼쪽 변수에 저장 |
| `+=` | compound assignment(복합 대입) | 왼쪽 변수에 오른쪽 값을 더한 결과를 다시 저장(`a = a + b`와 같음) |
| `-=`, `*=`, `/=`, `%=` | compound assignment | 각각 뺄셈·곱셈·나눗셈·나머지 연산 후 다시 저장 |

> **쉽게 말하면:** 대입 연산자는 "오른쪽 결과를 왼쪽 상자에 담아라"는 뜻이고, 비교 연산자는 "왼쪽과 오른쪽이 같은 값인지 검사만 해라"는 뜻입니다. 상자에 무언가를 담는 것과, 두 값을 나란히 놓고 비교만 하는 것은 완전히 다른 동작입니다.

## 3. 증감 연산자 — 전위와 후위

증감 연산자(increment/decrement operator)는 변수의 값을 1만큼 늘리거나 줄이는 연산자로, 기호를 변수 앞에 쓰는지 뒤에 쓰는지에 따라 동작 순서가 달라집니다.

| 기호 | 영문 용어 | 뜻 |
|------|-----------|-----|
| `++` | increment(증가) | 변수의 값을 1 증가시킴 |
| `--` | decrement(감소) | 변수의 값을 1 감소시킴 |

```c
int a = 5;
int b = a++;
int c = ++a;
printf("a = %d, b = %d, c = %d\n", a, b, c);
```

```text
a = 7, b = 5, c = 7
```

이 코드에서 `a++`(후위 증가, post-increment)는 "먼저 현재 값을 결과로 사용하고 나중에 1을 더한다"는 뜻이라 `b`에는 증가 전 값인 5가 들어갑니다. 반면 `++a`(전위 증가, pre-increment)는 "먼저 1을 더한 뒤 그 결과를 사용한다"는 뜻이라 `c`에는 증가 후 값인 7이 들어갑니다. 이 전위·후위 차이는 08편에서 표현식 평가 순서와 함께 더 깊게 다룹니다.

## 4. 핵심 키워드 영문·한글 대응

아래 표는 09편 이후 자주 나올 제어문·함수 관련 키워드를 미리 영문 뜻과 함께 정리한 것입니다.

| 키워드 | 영문 풀이 | 뜻 | 자세히 다루는 편 |
|--------|-----------|-----|-------------------|
| `if` | if(만약) | 조건이 참일 때만 실행 | 09편 |
| `else` | else(그렇지 않으면) | `if` 조건이 거짓일 때 실행 | 09편 |
| `switch` | switch(전환하다) | 여러 경우 중 하나를 선택해 실행 | 09편 |
| `case` | case(경우) | `switch` 안에서 각각의 조건값 | 09편 |
| `while` | while(하는 동안) | 조건이 참인 동안 반복 | 09편 |
| `for` | for(동안·위해) | 초기화·조건·증감을 한 줄에 묶어 반복 | 09편 |
| `do` | do(실행하다) | `do while` 형태로 최소 한 번은 실행 후 조건 검사 | 09편 |
| `break` | break(끊다) | 반복문이나 `switch`를 즉시 빠져나옴 | 09편 |
| `continue` | continue(계속하다) | 반복문의 남은 부분을 건너뛰고 다음 반복으로 | 09편 |
| `return` | return(돌아가다) | 함수를 종료하고 값을 호출한 곳으로 돌려줌 | 10편 |
| `sizeof` | size + of(크기의) | 자료형이나 변수가 차지하는 바이트 크기를 계산 | 07편 |
| `static` | static(정적인, 고정된) | 함수 종료 후에도 값이 유지되거나, 파일 내부로 접근을 제한 | 10편 |
| `struct` | structure(구조) | 여러 자료형을 묶은 사용자 정의 자료형 | 14편 |

`sizeof`는 이름 그대로 "무언가의 크기"를 구하는 연산자입니다. 함수처럼 괄호를 쓰지만 실제로는 연산자이며, 실행 중이 아니라 컴파일 시점에 크기가 정해진다는 점이 특징입니다. 이 성질은 07편에서 자료형 크기를 확인할 때 실제 코드로 확인합니다.

> **쉽게 말하면:** 키워드 이름은 대부분 그 동작을 그대로 설명하는 평범한 영어 단어입니다. `while`은 정말로 "~하는 동안"이라는 뜻이고, `break`는 정말로 "끊는다"는 뜻입니다. 뜻을 모른 채 외우기보다 이 원래 뜻을 붙잡고 있으면 코드를 처음 봐도 동작을 짐작할 수 있습니다.

**자주 틀리는 점**: 예약어(키워드)는 대소문자를 구분하므로 `If`, `While`처럼 첫 글자를 대문자로 쓰면 컴파일러가 예약어로 인식하지 못하고 정의되지 않은 식별자로 취급해 오류를 냅니다. 02편에서 확인한 "C는 대소문자를 구분한다"는 규칙이 키워드에도 그대로 적용된다는 점을 놓치지 않아야 합니다.

## 핵심 정리

- 기본 자료형 키워드(`int`, `char`, `float`, `double`, `void`)는 영문 뜻 그대로 정수·문자·실수·비어 있음을 나타내며, 정확한 바이트 크기는 시스템에 따라 달라질 수 있다.
- 연산자는 산술·비교·논리·대입으로 나뉘며, 대입 연산자 `=`와 비교 연산자 `==`를 혼동하는 것이 가장 흔한 함정이다.
- 증감 연산자는 전위(`++a`)와 후위(`a++`)의 실행 순서가 다르며, 이 차이가 결과값에 직접 영향을 준다.
- 제어문 키워드(`if`, `while`, `for`, `switch` 등)는 영어 원래 뜻을 그대로 담고 있어, 뜻을 알면 동작을 짐작하기 쉽다.
- 키워드도 식별자처럼 대소문자를 구분하므로 철자와 대소문자를 정확히 지켜야 한다.
