## 기본 자료형·형 변환·sizeof (4–6, 16)

### 문제 4

이 문제집의 계산 문제는 특별한 언급이 없는 한 `int`는 4바이트, `char`는 1바이트, `double`은 8바이트인 환경을 기준으로 한다.

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", (int)(sizeof(int) + sizeof(char)));
    return 0;
}
```



### 문제 5

```c
#include <stdio.h>

int main(void) {
    int a = 7, b = 2;
    double result = a / b;
    printf("%.1f\n", result);
    return 0;
}
```

## 조건문·반복문 제어 구조 (9–13, 19–20)

### 문제 9

```c
#include <stdio.h>

int main(void) {
    int x = 5;
    if (x > 0)
        if (x > 10)
            printf("A");
        else
            printf("B");
    return 0;
}
```



### 문제 10

```c
#include <stdio.h>

int main(void) {
    int n = 2;
    switch (n) {
        case 1:
            printf("one ");
        case 2:
            printf("two ");
        case 3:
            printf("three ");
            break;
        default:
            printf("other");
    }
    return 0;
}
```



### 문제 11

```c
#include <stdio.h>

int main(void) {
    int i = 5;
    while (i < 5) {
        printf("A");
        i++;
    }
    printf("end");
    return 0;
}
```



### 문제 12

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 2; j++) {
            sum += i * j;
        }
    }
    printf("%d\n", sum);
    return 0;
}
```



### 문제 13

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 5; i++) {
        if (i == 3) continue;
        if (i == 5) break;
        sum += i;
    }
    printf("%d\n", sum);
    return 0;
}
```
