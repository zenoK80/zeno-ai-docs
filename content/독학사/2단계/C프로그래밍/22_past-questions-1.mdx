## 기본 자료형·형 변환·sizeof (4–6, 16)

### 문제 4

이 문제집의 계산 문제는 특별한 언급이 없는 한 `int`는 4바이트, `char`는 1바이트, `double`은 8바이트인 환경을 기준으로 한다.

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", (int)(sizeof(int) + sizeof(char)));
    return 0;
}
```

### 문제 14

```c
#include <stdio.h>

int main(void) {
    int a = 0;
    int b = 5;
    if (a != 0 && (b = 10) > 0) {
        printf("A");
    }
    printf("%d\n", b);
    return 0;
}
```

  correctAnswer={1}
  explanation={"논리 AND 연산자는 왼쪽 조건이 거짓이면 오른쪽 조건을 평가하지 않는 단락 평가(short-circuit evaluation)를 한다. a가 0이므로 a != 0은 거짓이고, 이 시점에서 오른쪽의 (b = 10)은 실행되지 않아 b는 원래 값 5 그대로 남는다. if문 전체도 거짓이므로 A는 출력되지 않는다."}

## 조건문·반복문 제어 구조 (9–13, 19–20)

### 문제 9

```c
#include <stdio.h>

int main(void) {
    int x = 5;
    if (x > 0)
        if (x > 10)
            printf("A");
        else
            printf("B");
    return 0;
}
```

  correctAnswer={1}
  explanation={"else는 중괄호로 짝이 명확히 표시되지 않은 경우 문법상 가장 가까운 if에 연결된다. 이 코드에서 else는 x &gt; 10 조건의 if에 연결되며, x가 5이므로 x &gt; 10은 거짓이라 else 블록인 B가 출력된다."}

### 문제 10

```c
#include <stdio.h>

int main(void) {
    int n = 2;
    switch (n) {
        case 1:
            printf("one ");
        case 2:
            printf("two ");
        case 3:
            printf("three ");
            break;
        default:
            printf("other");
    }
    return 0;
}
```

  options={["two three ","two ","two three other","one two three "]}
  correctAnswer={1}
  explanation={"n이 2이므로 case 2로 진입한다. case 2에는 break가 없으므로 그 다음 case 3의 코드까지 이어서 실행되는 폴스루(fall-through)가 일어나고, case 3의 break에서 멈춘다. 따라서 two 와 three 가 순서대로 출력된다."}

### 문제 12

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 2; j++) {
            sum += i * j;
        }
    }
    printf("%d\n", sum);
    return 0;
}
```

<Quiz
  questionNumber={16}
  question={"위 코드를 실행했을 때 출력되는 sum의 값은?"}
  options={["18","12","9","6"]}
  correctAnswer={1}
  explanation={"바깥 반복은 i가 1부터 3까지, 안쪽 반복은 j가 1부터 2까지 돌며 i 곱하기 j를 sum에 누적한다. i가 1일 때 1과 2를 더해 3, i가 2일 때 2와 4를 더해 6(누적 9), i가 3일 때 3과 6을 더해 9(누적 18)가 되어 최종 sum은 18이다."}
/>

### 문제 13

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 5; i++) {
        if (i == 3) continue;
        if (i == 5) break;
        sum += i;
    }
    printf("%d\n", sum);
    return 0;
}
```

  explanation={"i가 1일 때 sum은 1, i가 2일 때 sum은 3이 된다. i가 3일 때는 continue를 만나 sum을 더하지 않고 바로 다음 반복으로 넘어간다. i가 4일 때 sum은 7이 된다. i가 5일 때는 sum에 더하기 전에 break를 만나 반복문을 완전히 빠져나가므로 최종 sum은 7이다."}
