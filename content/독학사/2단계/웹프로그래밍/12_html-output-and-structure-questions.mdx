코드가 있는 문항은 먼저 눈으로 태그를 하나씩 짚어가며 "이 문서가 브라우저에 어떻게 그려질까"를 그려본 뒤 정답을 확인하세요. 독학사 시험은 태그를 실제로 그려보라는 실기 문제가 아니라, 태그의 **의미·계층·용도**를 정확히 짝지었는지를 묻는 문항이 대부분입니다.

## 문서 구조 판별 (1–5)

### 문제 1

```html
<!DOCTYPE html>
<html>
  <head>
    <title>연습 문서</title>
  </head>
  <body>
    <p>안녕하세요</p>
  </body>
</html>
```

### 문제 3

```html
<!DOCTYPE html>
<html>
  <body>
    <head>
      <title>순서 실험</title>
    </head>
    <p>본문</p>
  </body>
</html>
```

<Quiz
  questionNumber={3}
  question={"위 문서처럼 head를 body 안쪽에 넣으면 어떤 일이 벌어지는가?"}

  correctAnswer={1}
  explanation={"html 요소 아래에는 head와 body가 형제 관계로, head가 먼저 오는 것이 표준 구조다. 브라우저는 오류 복구력이 강해 이런 문서도 최대한 보정해서 그려주지만, 이는 표준을 어긴 잘못된 마크업이며 시험에서는 옳은 구조로 인정되지 않는다."}
