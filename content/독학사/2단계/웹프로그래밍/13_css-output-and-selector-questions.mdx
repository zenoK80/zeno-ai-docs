## 선택자 적용 결과 (1–6)

### 문제 1

```html
<p class="notice">안내</p>
<p>일반 문단</p>
```

```css
.notice {
  color: red;
}
```

### 문제 2

```html
<div id="header">머리말</div>
<div id="footer">꼬리말</div>
```

```css
#header {
  font-weight: bold;
}
```

<Quiz
  questionNumber={2}
  question={"위 코드에서 굵게 표시되는 요소는 무엇인가?"}
  options={["id 속성 값이 header인 div 하나만 굵게 표시된다.","두 div 모두 굵게 표시된다.","아무 요소도 굵게 표시되지 않는다.","id 속성 값이 footer인 div만 굵게 표시된다."]}
  correctAnswer={1}
  explanation={"샵 기호로 시작하는 선택자는 아이디 선택자로, 문서 안에서 유일해야 하는 id 값을 정확히 지정한 요소 하나에만 적용된다. header라는 id를 가진 div에만 규칙이 적용된다."}
/>

### 문제 3

```html
<ul>
  <li>사과</li>
  <li>바나나</li>
</ul>
```

```css
ul li {
  list-style: none;
}
```

/>

### 문제 4

```html
<div>
  <p>첫 문단</p>
  <p>둘째 문단</p>
</div>
```

```css
div > p {
  margin: 0;
}
```



### 문제 5

```html
<input type="text" />
<input type="checkbox" />
```

```css
input[type='checkbox'] {
  width: 20px;
}
```



### 문제 6

```html
<h2>제목</h2>
<h2>다른 제목</h2>
```

```css
h2::first-line {
  font-weight: bold;
}
```



## 우선순위 비교 (7–11)

### 문제 7

```html
<p class="text" style="color: blue;">문단</p>
```

```css
.text {
  color: red;
}
```



### 문제 8

```css
p {
  color: green;
}
.text {
  color: red;
}
#main {
  color: blue;
}
```



### 문제 9

```css
div p {
  color: purple;
}
p.highlight {
  color: orange;
}
```



### 문제 10

```css
p {
  color: black;
}
p {
  color: gray;
}
```



### 문제 11

```css
p {
  color: navy !important;
}
#title {
  color: red;
}
```
