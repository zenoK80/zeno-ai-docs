## 문제 2

```java
abstract class Shape {
    abstract double area();
}

public class Main {
    public static void main(String[] args) {
        Shape s = new Shape();
    }
}
```

<Quiz
  questionNumber={2}
  question={"위 코드를 컴파일했을 때 결과로 옳은 것은?"}
  options={["① 추상 클래스는 인스턴스를 직접 생성할 수 없어 컴파일 오류가 발생한다","② 정상적으로 객체가 생성되고 area는 0을 반환한다","③ 런타임에만 오류가 발생한다","④ Shape 클래스가 자동으로 구체 클래스로 변환되어 정상 실행된다"]}
  correctAnswer={1}
  explanation={"abstract로 선언된 클래스는 몸체가 없는 추상 메서드를 포함할 수 있기 때문에, 완전하지 않은 설계도로 취급되어 new로 직접 인스턴스를 만들 수 없다. Shape는 area라는 추상 메서드를 가진 추상 클래스이므로 new Shape()는 컴파일 시점에 오류로 처리된다."}

## 문제 4

```java
class Parent {
    Parent() {
        show();
    }

    void show() {
        System.out.println("Parent show");
    }
}

class Child extends Parent {
    int value = 10;

    @Override
    void show() {
        System.out.println("Child show, value = " + value);
    }

    public static void main(String[] args) {
        new Child();
    }
}
```

class Animal {}
class Dog extends Animal {}

class AnimalShelter {
    Animal getAnimal() {
        return new Animal();
    }
}

    @Override
    Dog getAnimal() {
        return new Dog();
    }
}

        Animal a = shelter.getAnimal();
        System.out.println(a.getClass().getSimpleName());
