## 영역 1: CNN 연산·크기 계산 (1–5)

가로세로 32, 채널 3(즉 32×32×3)인 컬러 이미지에 5×5 필터 16개를 스트라이드(stride) 1, 패딩(padding) 0으로 합성곱(convolution)한다.

### 문제 1

<Quiz
  questionNumber={1}
  question={"이 합성곱을 거친 특징 맵(feature map)의 가로(세로) 크기는?"}
  options={["28","27","32","16"]}
  correctAnswer={1}
  explanation={"합성곱 출력 크기 공식은 O = floor((W - F + 2P) / S) + 1 입니다. 대입하면 O = (32 - 5 + 2*0)/1 + 1 = 27/1 + 1 = 27 + 1 = 28 입니다."}
/>

### 문제 2

<Quiz
  questionNumber={2}
  question={"이 합성곱층의 학습 파라미터(가중치+편향) 개수는?"}
  options={["1216","1200","416","76"]}
  correctAnswer={1}
  explanation={"필터 하나의 파라미터 수는 (필터 가로 × 필터 세로 × 입력 채널 수 + 편향 1개) = 5*5*3+1 = 76개입니다. 필터가 16개이므로 전체 파라미터는 76*16 = 1216개입니다."}

### 문제 3

같은 5×5 필터를 스트라이드 1, 패딩(padding) 2로 적용한다.

<Quiz
  questionNumber={3}
  question={"패딩을 2로 바꾸면 출력 특징 맵의 크기는?"}
  options={["32 (입력과 동일)","28","36","30"]}
  correctAnswer={1}
  explanation={"O = (32 - 5 + 2*2)/1 + 1 = (32-5+4)+1 = 31+1 = 32 입니다. 패딩을 (F-1)/2 = (5-1)/2 = 2로 맞추면 출력 크기가 입력과 같아지는데, 이를 세임 패딩(same padding)이라 부릅니다."}
/>
