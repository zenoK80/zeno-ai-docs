## 문제 1

```text
i = 1
while i <= 3 do:
    j = 1
    while j <= 2 do:
        만약 j == 2이면 break(안쪽 루프만 탈출)
        (i, j)를 출력한다
        j = j + 1
    i = i + 1
```

## 문제 3

```text
n = 3
switch n:
    case 1: A를 출력한다
    case 2: B를 출력한다
    case 3: C를 출력한다
    case 4: D를 출력한다
    default: E를 출력한다
(각 case 끝에 break가 없다고 가정 — fall-through 언어)
```

```text
procedure swap(a, b):
    temp = a
    a = b
    b = temp

x = 1
y = 2
call swap(x, y)   // 값 전달(pass by value) 방식
x와 y를 출력한다
```

## 문제 8

다음은 값-결과 전달(pass by value-result, copy-restore)로 호출되는 하위프로그램이다. 형식 매개변수 a는 실제 인자 x와 연결되고, 또 다른 실제 인자로 배열 원소 `arr[1]`도 함께 넘겨받으며, 이 하위프로그램 안에서 배열 `arr` 자체도 전역으로 접근 가능하다고 하자.

```text
전역 배열 arr = [10, 20]

procedure p(a):
    a = a + 1
    arr[1] = 99   // 전역 배열을 직접 변경

// 값-결과 전달로 arr[1]을 인자로 넘겨 호출
call p(arr[1])
arr[1]을 출력한다
```
