  **이 문제 세트는 실제 기출문제를 그대로 옮긴 것이 아닙니다.** 국가평생교육진흥원이 공개한 독학학위제 4단계 데이터베이스 평가영역(출제기준) 중 관계 데이터 모델·관계대수·SQL 기본 항목을 근거로, 다루는 개념·계산 유형·오답 구성 방식을 참고해 지문과 데이터를 모두 새로 구성한 예상문제입니다. 실제 회차의 문항 수·배점·시험 시간은 매 공고마다 달라질 수 있으므로 **반드시 응시 회차의 공식 공고를 확인**하시기 바랍니다. 이 편은 04~06편, 10~11편에서 다룬 관계모델·관계대수·기본 SQL을 섞은 혼합 문제 22개로 구성했습니다.
</Callout>

관계대수 결과의 튜플 개수를 세는 문항과 조인·조건절 SQL의 실행 결과를 계산하는 문항은 해설에 계산 과정을 전부 풀어 두었습니다. 정답만 확인하지 말고, 표에 있는 데이터를 직접 손으로 짚어 가며 검산하는 방식으로 복습하시기 바랍니다.
