## 이번 회차의 구성 변화

20편의 모의고사 1회와 비교했을 때 이번 2회는 다음과 같이 구성을 바꾸었다.

- 독해 지문을 업무 이메일(실용 텍스트)과 의견 제시형 글(논증 구조)로 바꾸어, 실용영어 출제기준의 "실무적 문항"과 "논리적 독해"를 함께 점검한다.
- 문법 문항에 밑줄 여러 개 중 오류를 찾는 유형을 추가해 12편에서 배운 오류 찾기 전략을 실전에서 다시 확인하도록 했다.
- 총 문항 수를 22개로 늘려 20편보다 대화문과 전환 문제 비중을 조금 더 높였다.

풀이 절차는 20편과 동일하다. 근거 문장을 표시하며 풀고, 채점 후 이 문서 마지막의 오답 분석표에 결과를 기록한다.

## 독해 지문 (새로 작성)

### 지문 1 — 업무 이메일

> Subject: Change in Thursday Team Meeting
> 
> Hi team,
> 
> I am writing to let you know that Thursday afternoon team meeting has been moved from 2 p.m. to 4 p.m., because the conference room is unavailable until then due to a client visit. The agenda remains the same: we will review the quarterly budget and discuss the new vendor contract. If you have prepared any materials for the 2 p.m. slot, please simply bring the same materials to the 4 p.m. session; nothing needs to be resubmitted. For those who cannot attend at the new time, please let me know by Wednesday noon so that we can arrange a short catch-up call afterward. Also, note that the meeting location has changed from Room 301 to Room 305 on the same floor. Thank you for your flexibility, and see you Thursday.
> 
> Best,
> Jason

### 지문 2 — 의견 제시형 글

> Many companies now allow employees to work from home several days a week, and some critics argue that this arrangement weakens teamwork because colleagues rarely meet face to face. This concern is understandable, but it overlooks an important fact: teamwork does not depend on physical presence alone, but on how clearly people communicate and how reliably they follow through on shared tasks. In fact, several teams that switched to a hybrid schedule reported fewer misunderstandings, simply because they were forced to write clearer instructions instead of relying on quick hallway conversations that not everyone overheard. Of course, remote work is not free of drawbacks; new employees, in particular, may need more structured onboarding to build the informal trust that used to form naturally in a shared office. Still, the evidence suggests that the real threat to teamwork is not distance itself, but the absence of deliberate communication habits, whether employees are sitting in the same room or in different cities.

## 채점·오답 분석 방법

> **쉽게 말하면:** 20편의 결과와 이번 21편의 결과를 나란히 놓고 비교하면, 어떤 취약점이 반복되는지 더 뚜렷하게 드러난다.

아래 표에 20편과 21편의 영역별 정답 개수를 함께 기록해 취약 영역을 비교한다.

| 영역 | 20편 문항 범위 | 20편 정답 수 | 21편 문항 범위 | 21편 정답 수 | 두 회차 모두 약한 영역인가 |
|------|------------------|----------------|------------------|----------------|------------------------------|
| 어휘 | 1–3 | | 1–4 | | |
| 문법 | 4–8 | | 5–9 | | |
| 독해 | 9–14 | | 10–16 | | |
| 대화문 | 15–17 | | 17–19 | | |
| 전환·영작 | 18–19 | | 20–21 | | |
| 생활·비즈니스 표현 | 20 | | 22 | | |

두 회차 모두에서 정답률이 낮은 영역이 있다면, 그 영역은 단순 실수가 아니라 **개념 이해 자체의 공백**일 가능성이 높다. 해당 본론 편으로 돌아가 규칙과 예문을 다시 읽고, 이후 22–23편의 기출·복원 분석에서 같은 영역의 문항을 추가로 점검하는 순서를 권장한다.
