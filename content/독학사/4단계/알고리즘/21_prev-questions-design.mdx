<Quiz
  questionNumber={2}
  question={"병합 정렬의 시간 복잡도를 점화식으로 나타내면 T(n) = 2T(n/2) + cn (배열을 반으로 나누는 데 상수, 병합에 O(n))이다. 이 점화식을 재귀 트리로 전개해 복잡도를 유도하는 과정으로 옳은 것은?"}
  options={["깊이 k에서 부분 문제 개수는 2^k개이고 각 크기는 n/2^k이므로 각 깊이의 총 병합 비용은 2^k * c(n/2^k) = cn으로 항상 동일하다. 트리의 깊이는 log2(n)이므로 전체 비용은 cn * log2(n), 즉 O(n log n)이다","깊이가 늘어날수록 각 깊이의 총 병합 비용이 절반씩 줄어들어 전체 합이 등비수열이 되므로 총 비용은 O(n)이다","부분 문제 개수가 매 깊이 두 배로 늘어나기만 하고 크기는 줄어들지 않는다고 가정하면 총 비용은 O(2^n)이다","병합 비용은 부분 문제 크기와 무관하게 항상 상수이므로 총 비용은 트리의 깊이에만 비례해 O(log n)이다"]}
  correctAnswer={1}
  explanation={"재귀 트리의 각 깊이 k(0부터 시작)에는 부분 문제가 2^k개 있고, 각 부분 문제의 크기는 n/2^k이다. 각 부분 문제를 병합하는 데 그 크기에 비례하는 비용 c * (n/2^k)이 들므로, 깊이 k 전체의 병합 비용 합은 2^k개 * c(n/2^k) = cn이 된다. 즉 어느 깊이에서든 그 층의 총 병합 비용은 항상 cn으로 동일하다. 트리는 부분 문제 크기가 1이 될 때까지, 즉 n/2^k = 1이 될 때(k = log2(n))까지 내려가므로 깊이는 log2(n) + 1개 층이다. 각 층의 비용이 cn으로 동일하므로 전체 비용은 cn * log2(n)이 되고, 상수를 무시하면 O(n log n)이다. 이것이 병합 정렬이 O(n log n)인 이유를 점화식에서 유도하는 표준적인 방법이다."}

  correctAnswer={1}
  explanation={"마스터 정리는 T(n) = aT(n/b) + f(n) 형태의 점화식에서 f(n)을 n^(log_b a)와 비교해 세 가지 경우로 나눈다. f(n)이 n^(log_b a)보다 다항식 차수만큼 작으면(첫 번째 경우) T(n) = Θ(n^(log_b a))이고, 두 값이 같은 차수이면(두 번째 경우) T(n) = Θ(n^(log_b a) * log n)이며, f(n)이 다항식 차수만큼 크면서 정칙 조건을 만족하면(세 번째 경우) T(n) = Θ(f(n))이다. 이 문제에서는 n^(log_2 4) = n^2이고 f(n) = n = n^1이므로 f(n)의 차수(1)가 n^2의 차수(2)보다 작다. 즉 첫 번째 경우에 해당하며, 결론은 T(n) = Θ(n^2)이다."}
