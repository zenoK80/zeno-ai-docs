  question={"이진 탐색의 점화식 T(n) = T(n/2) + O(1)을 반복 대입법으로 전개해 시간 복잡도를 유도하는 과정으로 옳은 것은?"}
  options={["T(n) = T(n/2) + c = T(n/4) + 2c = T(n/8) + 3c = ... = T(n/2^k) + kc이며, n/2^k = 1이 되는 k = log2(n)에서 재귀가 끝나므로 T(n) = T(1) + c*log2(n) = O(log n)이다","T(n) = T(n/2) + c를 그대로 두면 매 단계 크기가 절반씩 줄면서 비교 횟수도 절반씩 줄어들어 총합이 O(n)이 된다","재귀가 한 번 호출될 때마다 부분 문제가 2개씩 생긴다고 가정해야 하므로 T(n) = O(2^n)이다","T(n) = T(n/2) + c는 매번 상수 시간이 두 배씩 늘어나는 것으로 해석해야 하므로 O(n)이다"]}
  correctAnswer={1}
  explanation={"이진 탐색은 매 단계에서 비교 한 번(상수 시간 c)을 하고 탐색 범위를 절반으로 줄인다. 이를 점화식으로 쓰면 T(n) = T(n/2) + c이다. 이 점화식을 반복해서 대입하면 T(n) = T(n/2) + c = (T(n/4) + c) + c = T(n/4) + 2c = T(n/8) + 3c = ... 이런 식으로 k번 대입하면 T(n) = T(n/2^k) + kc가 된다. 재귀는 부분 문제 크기가 1이 될 때, 즉 n/2^k = 1일 때 끝나며, 이는 k = log2(n)일 때다. 이 값을 대입하면 T(n) = T(1) + c*log2(n)이 되고, T(1)은 상수이므로 지배항은 log2(n)에 비례하는 항이다. 따라서 T(n) = O(log n)이며, 이것이 정렬된 배열 n개에서 이진 탐색이 O(log n)인 이유를 점화식에서 직접 유도한 결과다."}
