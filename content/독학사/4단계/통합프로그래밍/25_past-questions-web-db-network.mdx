## SQL 기본·조인 (1–3)

### 문제 1

다음은 EMP(사원) 테이블과 DEPT(부서) 테이블이다.

| EMPNO | ENAME | DEPTNO |
| --- | --- | --- |
| 100 | KIM | 10 |
| 101 | LEE | 20 |
| 102 | PARK | 10 |

| DEPTNO | DNAME |
| --- | --- |
| 10 | SALES |
| 20 | DEV |

```sql
SELECT e.ename, d.dname
FROM emp e
JOIN dept d ON e.deptno = d.deptno
WHERE d.dname = 'SALES';
```

### 문제 2

```sql
SELECT deptno, COUNT(*) AS cnt
FROM emp
GROUP BY deptno
HAVING COUNT(*) >= 2;
```

  question={"문제 1의 EMP 테이블 데이터를 기준으로 위 GROUP BY와 HAVING을 사용한 집계 조회의 결과로 가장 적절한 것은?"}
  options={['DEPTNO가 10이고 CNT가 2인 행 하나만 조회된다', 'DEPTNO 10과 20이 모두 조회된다', '조회 결과가 없다', '모든 사원이 한 행씩 그대로 조회된다']}
  correctAnswer={1}
  explanation={"GROUP BY deptno는 같은 부서 번호를 가진 행끼리 하나의 그룹으로 묶고, COUNT(*)는 각 그룹에 속한 행의 개수를 센다. DEPTNO가 10인 그룹에는 KIM, PARK 두 명이 속해 개수가 2이고, DEPTNO가 20인 그룹에는 LEE 한 명만 속해 개수가 1이다."}
/>

### 문제 3

```sql
SELECT ename,
       CASE
           WHEN deptno = 10 THEN 'A'
           ELSE 'B'
       END AS grp
FROM emp
ORDER BY ename;
```

## JDBC 연동 코드 구조 (4–7)

### 문제 4

```java
import java.sql.*;

public class JdbcExample {
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");
        Connection conn = DriverManager.getConnection(
            "jdbc:oracle:thin:@localhost:1521:xe", "scott", "tiger");
        Statement stmt = conn.createStatement();
        ResultSet rs = stmt.executeQuery("SELECT ename FROM emp");
        while (rs.next()) {
            System.out.println(rs.getString("ename"));
        }
        rs.close();
        stmt.close();
        conn.close();
    }
}
```
