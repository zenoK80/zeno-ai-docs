## C 구조체 (8–10)

### 문제 8

```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point p1 = {3, 4};

    p2.x = 10;
    printf("%d %d\n", p1.x, p2.x);
    return 0;
}
```
