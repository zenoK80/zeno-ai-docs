## 저장장치는 "연결"과 "인식"이 다른 문제다

저장장치 작업에는 단계가 세 개 있습니다. 이 셋을 구분하지 못하면 진단이 엉킵니다.

```mermaid
graph LR
  A[① 물리 연결 — 케이블·슬롯] --> B[② 펌웨어 인식 — BIOS가 장치를 봄]
  B --> C[③ OS 사용 준비 — 파티션·포맷·드라이브 문자]
```

- ①이 안 되면 BIOS에도 안 보입니다.
- ②까지는 되는데 ③이 안 되면, **내 컴퓨터에는 안 보이지만 디스크 관리에는 보입니다.**
- ③까지 끝나야 드라이브 문자가 붙고 파일을 저장할 수 있습니다.

실기에서 "새 하드디스크를 연결했는데 내 컴퓨터에 보이지 않습니다"라는 문제의 정답은 대부분 ③입니다. 부품 교체가 아니라 **디스크 관리에서 초기화하고 볼륨을 만드는 것**이 답입니다.

## 1. 물리 연결 — 인터페이스별 절차

### SATA 저장장치 (HDD·SATA SSD)

케이블이 **두 개** 필요합니다.

| 케이블 | 출처 | 꽂는 곳 | 특징 |
|--------|------|---------|------|
| SATA 데이터 | 메인보드 SATA 포트 | 드라이브 데이터 단자 | 좁은 L자, 7핀 |
| SATA 전원 | 파워 서플라이 | 드라이브 전원 단자 | 넓은 L자, 15핀 |

### M.2 NVMe SSD

케이블이 **하나도** 필요 없습니다. 슬롯이 데이터와 전원을 함께 공급합니다.

<Callout type="warning">
  **M.2 슬롯의 함정:** 많은 메인보드에서 M.2 슬롯을 사용하면 특정 SATA 포트가 자동으로 비활성화됩니다. 대역폭(레인)을 공유하기 때문입니다. "SSD를 추가했더니 기존 HDD가 사라졌다"는 증상의 정답이 바로 이것이며, 해결책은 **다른 SATA 포트로 옮기는 것**입니다. 메인보드 매뉴얼의 공유 표를 확인해야 합니다.
</Callout>

## 2. BIOS에서 인식 확인과 부팅 순서 설정

### 인식 확인

BIOS/UEFI에 들어가 다음 위치에서 장치 목록을 봅니다.

| 인터페이스 | 확인 위치 | 표시 형태 |
|------------|-----------|-----------|
| 구형 BIOS | Standard CMOS Features | IDE/SATA Channel별 모델명 |
| UEFI | 메인 화면 또는 Boot 메뉴 | 저장장치 아이콘·모델명 목록 |

여기에 이름이 뜨지 않으면 ① 물리 연결 문제입니다. 케이블 양쪽, 전원, 포트를 순서대로 바꿔 봅니다.

### 부팅 순서 지정

**부팅 순서**(Boot Order, Boot Sequence)는 BIOS가 운영체제를 찾을 때 어떤 장치를 먼저 뒤질지 정한 목록입니다.

부팅 순서를 영구히 바꾸지 않고 한 번만 다른 장치로 부팅하려면 부팅 중 `F11` 또는 `F12` 로 열리는 **부팅 메뉴**(Boot Menu)를 씁니다. 설치 작업에서는 이 방법이 더 안전합니다 — 설정을 되돌릴 필요가 없기 때문입니다.

## 3. 디스크 관리 — 실기 파티션 문항의 무대

### 파티션과 볼륨이라는 단어부터

**파티션**(partition, 칸막이)은 하나의 물리 디스크를 논리적으로 나눈 구획입니다. 한 채의 집을 벽으로 나눠 여러 방으로 쓰는 것과 같습니다.

**볼륨**(volume)은 파일 시스템으로 포맷되어 실제로 쓸 수 있게 된 저장 공간입니다. 방에 바닥을 깔고 이름표를 붙여 사용 가능해진 상태입니다.

**비할당 공간**(Unallocated)은 아직 어떤 파티션에도 속하지 않은 빈 영역입니다. 검은색 막대로 표시되며, 여기에 볼륨을 만들어야 사용할 수 있습니다.

### 디스크 관리 열기

실행 창(`Win` + `R`)에 `diskmgmt.msc` 를 입력합니다. 또는 시작 버튼을 우클릭해 디스크 관리를 선택합니다.

### 문항 예시로 절차 익히기

다음은 단위 조건을 명시한 자체 연습 과제입니다. 개인 가상 머신의 빈 가상 디스크에서만 수행합니다.

> 디스크 0의 750GiB 비할당 공간을 두 개의 파티션으로 분할하시오.
> 파티션 1 — 크기 500GiB, 파일 시스템 NTFS, 드라이브 문자 D, 볼륨 레이블 IT 기술부
> 파티션 2 — 크기 250GiB, 파일 시스템 exFAT, 드라이브 문자 E, 볼륨 레이블 기술영업부

<Callout type="warning">
  **채점 항목으로 쪼개 보기:** 파티션 하나당 ① 크기 ② 드라이브 문자 ③ 파일 시스템 ④ 볼륨 레이블 네 개가 채점점입니다. 두 파티션이면 여덟 개입니다. 볼륨 레이블의 **띄어쓰기까지 문제 그대로** 입력해야 하며, 완료 후 디스크 관리 화면에서 막대에 표시된 레이블과 문자를 눈으로 확인하는 것이 마지막 절차입니다.
</Callout>

### 자주 하는 실수

- **단위 착각** — 입력란은 MB입니다. `500` 을 넣으면 500MB짜리 볼륨이 생깁니다.
- **드라이브 문자 미변경** — 마법사가 제안한 문자를 그대로 두면 오답입니다.
- **파일 시스템 미변경** — 기본값이 NTFS이므로 exFAT 지정 문항에서 특히 주의합니다.
- **볼륨 레이블 오타·공백 누락** — `IT 기술부` 와 `IT기술부` 는 다릅니다.
- **디스크 번호 혼동** — 디스크 0과 디스크 1을 반드시 구분합니다.

### 파일 시스템 선택의 근거

문제가 왜 굳이 exFAT을 지정하는지도 알아 두면 서술형에 대응할 수 있습니다.

| 파일 시스템 | 단일 파일 최대 | 특징 | 주 용도 |
|-------------|----------------|------|---------|
| FAT32 | 4GB | 호환성 최고, 대용량 제약 | 구형 USB, 일부 장비 |
| exFAT | 사실상 제한 없음 | FAT의 확장판, 권한·저널링 없음 | 대용량 USB·외장 SSD, 이종 OS 교환 |
| NTFS | 사실상 제한 없음 | 권한·압축·저널링 지원 | Windows 시스템 드라이브 |

**저널링**(journaling)은 파일을 바꾸기 전에 "무엇을 바꿀 것인지"를 먼저 기록해 두는 기능입니다. 작업 도중 전원이 꺼져도 기록을 보고 복구할 수 있어 손상에 강합니다. NTFS는 이 기능이 있고 exFAT은 없습니다. 대신 exFAT은 구조가 단순해 여러 운영체제에서 잘 읽힙니다.

**exFAT**은 Extended File Allocation Table의 줄임말로, "확장된 파일 할당 표"라는 뜻입니다. FAT32의 4GB 파일 크기 한계를 없애면서도 가벼움을 유지한 규격입니다.

### 볼륨 축소·확장·삭제

문항이 "기존 볼륨을 줄여 새 파티션을 만드시오"로 나올 수도 있습니다.

| 작업 | 우클릭 메뉴 | 주의 |
|------|-------------|------|
| 축소 | 볼륨 축소 | 축소 가능 크기는 데이터 배치에 따라 제한됨 |
| 확장 | 볼륨 확장 | **바로 오른쪽에 인접한** 비할당 공간만 흡수 가능 |
| 삭제 | 볼륨 삭제 | 데이터가 사라짐, 되돌릴 수 없음 |
| 문자 변경 | 드라이브 문자 및 경로 변경 | 사용 중인 프로그램 경로가 깨질 수 있음 |

볼륨 확장이 회색으로 비활성인 경우, 원인은 대부분 **비할당 공간이 그 볼륨의 오른쪽에 인접해 있지 않아서**입니다. 이 원리를 모르면 "확장이 안 됩니다"라는 문제 앞에서 헤맵니다.

## 4. 새 디스크를 처음 붙였을 때 — 초기화 절차

완전히 새 디스크는 디스크 관리에서 **초기화되지 않음**으로 표시됩니다.

## 5. 저장장치 진단 표

| 증상 | 어디까지 보이는가 | 원인 | 조치 |
|------|-------------------|------|------|
| BIOS에도 안 보임 | 없음 | 케이블·전원·포트 불량 | 케이블 교체, 포트 변경 |
| BIOS에 보이는데 탐색기에 없음 | BIOS만 | 볼륨 미생성 또는 문자 미할당 | 디스크 관리에서 볼륨 생성 |
| 디스크 관리에 오프라인 표시 | 디스크 관리 | 디스크가 오프라인 상태 | 우클릭 → 온라인 |
| M.2 추가 후 기존 SATA가 사라짐 | 일부 | 레인 공유로 SATA 포트 비활성 | 다른 SATA 포트로 이동 |
| 부팅 시 운영체제 없음 메시지 | – | 부팅 순서가 데이터 디스크로 지정 | 부팅 순서에서 OS 디스크를 1순위로 |
| 딸깍거리는 소리와 인식 실패 | 간헐 | HDD 헤드 물리 손상 | 즉시 전원 차단, 데이터 백업 우선 |

마지막 항목은 특히 중요합니다. HDD에서 규칙적인 딸깍 소리가 나면 **계속 켜 두는 것이 데이터를 더 망칩니다.** 실기 서술형에서 "가장 먼저 취할 조치"를 묻는다면 "전원을 끄고 데이터 백업을 우선한다"가 정답입니다.

## 핵심 정리

- 저장장치는 물리 연결 → BIOS 인식 → 볼륨 생성 세 단계이며, 탐색기에 안 보이는 문제의 대부분은 세 번째 단계 누락입니다.
- M.2 슬롯 사용 시 특정 SATA 포트가 비활성화될 수 있으므로, 기존 드라이브가 사라지면 포트를 옮깁니다.
- 부팅 순서에서 `UEFI:` 접두어가 붙은 항목과 아닌 항목은 서로 다른 부팅 모드이며, 이 선택이 파티션 방식을 결정합니다.
- 새 단순 볼륨 마법사는 **크기(MB) → 드라이브 문자 → 파일 시스템 → 볼륨 레이블** 순이며 네 값 모두가 채점 항목입니다.
- 볼륨 확장은 오른쪽에 인접한 비할당 공간만 흡수할 수 있습니다.
