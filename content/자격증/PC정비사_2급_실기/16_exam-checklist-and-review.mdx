<Callout type="info">
  **이번 문서의 목표:** 이 파일은 시험 전날과 당일 아침에 한 번씩 훑기 위한 문서입니다. 다 읽으면 준비물과 입실 절차를 빠짐없이 챙기고, 자주 나오는 과제의 정답값과 화면 경로를 한 번에 되짚고, 스스로 저지르기 쉬운 실수를 미리 차단할 수 있습니다.
</Callout>

## 이 문서 사용법

새로운 내용을 배우는 문서가 아닙니다. **이미 아는 것을 잃지 않기 위한 문서**입니다.

| 시점 | 볼 부분 |
|------|---------|
| 시험 3일 전 | 정답값 요약표 전체를 소리 내어 읽으며 빈칸을 찾음 |
| 시험 전날 | 준비물 점검, 금지 실수 목록 |
| 당일 아침 | 정답값 요약표를 눈으로 훑기, 배선 순서만 손으로 한 번 써 보기 |
| 시험장 대기 중 | 금지 실수 목록만 |

## 1. 시험장 체크리스트

### 준비물

| 구분 | 항목 | 확인 |
|------|------|------|
| 필수 | 신분증(공공기관 발행, 사진·생년월일 확인 가능) | 유효기간 확인 |
| 필수 | 수험표 | 시험 시간·장소·수험번호 확인 |
| 작업형 | LAN 압착 공구(크림퍼) | 날 상태, RJ-45 8핀용인지 |
| 작업형 | UTP 케이블 | 여유분 포함 |
| 작업형 | RJ-45 커넥터 | 여유분 필수. 실패를 전제로 챙김 |
| 작업형 | 케이블 스트리퍼 또는 커터 | 크림퍼에 내장된 경우도 있음 |
| 작업형 | 케이블 테스터 | 지참 요구 여부는 공지 확인 |
| 권장 | 십자 드라이버 | 자석형이면 나사 다루기가 쉬움 |
| 권장 | 정전기 방지 손목띠 | – |
| 권장 | 여분 필기구 | – |

  **지참 준비물과 시행처 제공 물품의 구분은 회차마다 다릅니다.** 이 표는 일반적인 목록이며, 반드시 **본인 회차의 시행처 공지**를 확인해 지참 목록을 대조하세요. 특히 공구와 소모품은 제공되지 않는 경우가 많습니다.
</Callout>

### 운영 정보 확인 항목

| 항목 | 확인할 것 |
|------|-----------|
| 시험 시간 | 실기 시험 시간(안내상 80분) |
| 문항 수 | 안내상 18문항, 작업·서술·선택형 혼합 |
| 입실 완료 시각 | 시작 시각이 아니라 **입실 완료 시각** 기준 |
| 고사장 위치 | 건물과 강의실 번호까지, 이동 시간 여유 |
| 신분증 규정 | 인정되는 신분증 종류 |

**입실 완료 시각을 시험 시작 시각으로 착각하는 것**이 가장 아까운 사고입니다. 시험 시작보다 이른 시각까지 들어가야 하며, 그 시각을 넘기면 응시 자체가 불가능합니다.

### 시험 직전 마음가짐

<Steps>

### 배선 순서를 한 번 써 본다

종이에 T568B 여덟 색을 순서대로 적어 봅니다. 손으로 한 번 쓰면 압착 순간의 망설임이 사라집니다.

### 저장 조작을 되뇐다

BIOS는 `F10` 후 `Y`, 창 설정은 적용 후 확인. 이 두 문장만 머릿속에 넣고 들어갑니다.

### 모르는 문항을 버릴 각오를 한다

한 문항에 5분 이상 쓰지 않겠다고 미리 정합니다. 그 결정을 시험장에서 하려 하면 못 합니다.

### 손을 데우고 시작한다

작업형은 손이 굳으면 실수가 늘어납니다.

</Steps>

## 2. 과제별 정답값 요약표

### 배선 — T568B

| 핀 | 색 |
|----|-----|
| 1 | 흰색–주황 |
| 2 | 주황 |
| 3 | 흰색–초록 |
| 4 | 파랑 |
| 5 | 흰색–파랑 |
| 6 | 초록 |
| 7 | 흰색–갈색 |
| 8 | 갈색 |

| 항목 | 값 |
|------|-----|
| T568A와의 차이 | 주황 페어와 초록 페어의 자리가 서로 바뀜 |
| 다이렉트 케이블 | 양쪽 모두 같은 규격(예: T568B – T568B) |
| 크로스 케이블 | 한쪽 T568A, 반대쪽 T568B |
| PC와 공유기 LAN 포트 | 다이렉트 |
| PC와 PC | 크로스 |
| 1번 핀 위치 | 걸쇠를 아래로 두었을 때 왼쪽 |
| 꼬임 푸는 길이 | 최대한 짧게 |

## 3. 절대 하지 말아야 할 실수

### 반영·저장 관련 (가장 흔한 실점)

| 금지 | 대신 할 것 |
|------|------------|
| BIOS 값을 바꾸고 `Esc` 로 나가기 | `F10` 후 `Y` 로 저장 |
| 가상 메모리 값 입력 후 바로 확인 | **설정** 버튼을 먼저 클릭 |
| 서비스 속성에서 값만 바꾸고 닫기 | 적용 후 확인 |
| 폴더 옵션 창을 열어 둔 채 다음 문항으로 | 확인을 눌러 창을 닫기 |
| 새 단순 볼륨 마법사를 도중에 취소 | 마침까지 진행 |
| 레지스트리 값 편집 창을 확인 없이 닫기 | 확인 클릭 |

### 위치·대상 관련

| 금지 | 대신 할 것 |
|------|------------|
| 지시된 것과 다른 디스크 번호에 파티션 작업 | 디스크 번호를 먼저 대조 |
| CPU 쿨러 팬을 `SYS_FAN` 에 연결 | `CPU_FAN` 확인 |
| 정책 값을 `HKEY_CURRENT_USER` 에 생성 | `HKEY_LOCAL_MACHINE` 확인 |
| `Policies` 를 빼고 경로 생성 | 경로 전체를 주소 표시줄에 붙여 넣기 |
| 연결 표시줄을 로컬 리소스 탭에서 찾기 | 디스플레이 탭 |
| 프린터·클립보드를 디스플레이 탭에서 찾기 | 로컬 리소스 탭 |
| 잠금 임계값을 암호 정책에서 찾기 | 계정 잠금 정책 |
| 외장 그래픽이 있는데 보드 단자에 모니터 연결 | 그래픽카드 단자에 연결 |

### 값·형식 관련

| 금지 | 대신 할 것 |
|------|------------|
| 500GB를 `500000` MB로 입력 | `512000` MB |
| 정책 값을 문자열이나 QWORD로 생성 | DWORD 32비트 |
| 볼륨 레이블을 비워 둠 | 지정된 이름을 직접 입력 |
| 확장명 표시를 위해 항목을 체크 | 체크를 **해제** |
| 계정 잠금 임계값에 `0` 입력 | 지정된 횟수 입력 |
| 시각 효과에서 최적 성능 선택 | 사용자 지정 후 해당 항목만 체크 |
| 잠금 임계값 지정 시 제안값을 그대로 확정 | 확인 후 각 항목을 지정값으로 재수정 |

### 작업형 관련

| 금지 | 대신 할 것 |
|------|------------|
| 압착 전 색 순서를 확인하지 않음 | 커넥터 앞쪽 투명부로 8색 대조 |
| 꼬임을 길게 풀어 정렬 | 최소한으로 풀기 |
| 심선 길이를 맞추지 않고 삽입 | 한 번에 직각으로 자르기 |
| 겉피복을 압착 턱 밖에 둠 | 겉피복까지 커넥터 안으로 |
| 쿨러 나사를 한쪽부터 끝까지 조임 | 대각선으로 번갈아 조금씩 |
| 케이스 안에 나사·공구 방치 | 마무리 전 내부 전수 확인 |
| 케이블이 팬에 닿은 채 마감 | 팬 반경 손으로 훑기 |
| 전면 패널 케이블 미연결 | 전원·USB·오디오 헤더 확인 |

### 시간 관리 관련

| 금지 | 대신 할 것 |
|------|------------|
| 어려운 문항을 끝까지 붙잡기 | 5분 넘기면 표시하고 넘어가기 |
| 작업형을 여러 번 끊어서 하기 | 연속 시간 확보 |
| 검토 시간 없이 끝까지 새 문항 풀기 | 마지막 5분은 반영 여부 확인 |
| 아는 문항을 뒤로 미루기 | 짧게 끝나는 문항부터 확보 |

## 4. 제출 전 최종 루틴

<Steps>

### 에뮬레이터 문항 되짚기

문항을 순서대로 다시 열어 설정값이 남아 있는지 확인합니다. 이것이 검토의 90퍼센트입니다.

### 숫자와 이름 대조

IP 주소, 사용자 이름, 볼륨 이름, 크기 값을 문제 문장과 한 글자씩 대조합니다.

### 조립물 외관 확인

케이블 정리, 나사 체결, 팬 접촉 여부, 내부 잔여물을 봅니다.

### 케이블 결과물 확인

배선 순서를 커넥터 투명부로 다시 보고, 테스터로 순서대로 점등되는지 확인합니다.

### 빈칸 확인

답을 쓰지 않은 문항이 있는지 봅니다. 모르는 문항도 가능한 범위에서 채웁니다.

### 자리 정돈

공구와 잔여 자재를 정리합니다. 마감 상태도 평가 대상일 수 있습니다.

</Steps>

## 핵심 정리

- 준비물과 입실 완료 시각은 반드시 본인 회차 공지로 확인하며, 입실 시각을 시작 시각과 혼동하지 않습니다.
- T568B 순서, 실행 명령어, 설정 항목의 화면 위치는 요약표로 반복해 눈에 익힙니다.
- 실점의 최대 원인은 난이도가 아니라 저장·적용 누락과 오타이므로 마지막 검토는 반영 여부 확인에 씁니다.
- 위치를 헷갈리기 쉬운 항목은 연결 표시줄이 디스플레이 탭, 프린터와 클립보드가 로컬 리소스 탭, 잠금 임계값이 계정 잠금 정책이라는 세 쌍입니다.
- 압착한 LAN 커넥터만 되돌릴 수 없으므로 압착 직전 색 순서 확인을 습관으로 만듭니다.
