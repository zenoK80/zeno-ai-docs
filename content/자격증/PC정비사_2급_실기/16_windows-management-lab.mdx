## 1. 요구 조건을 네 항목으로 분해하기

| 구분 | 확인할 질문 | 예 |
|---|---|---|
| 도구 | 어느 관리 도구인가? | 레지스트리 편집기, 서비스, 디스크 관리 |
| 대상 | 어느 객체인가? | 현재 사용자, 지정 서비스, 디스크 1 |
| 값 | 무엇을 어떻게 바꾸는가? | 자료형, 숫자, 경로, 시작 유형 |
| 확인 | 반영된 상태를 어디서 보는가? | 다시 연 속성 창, 조회 결과 |

레지스트리의 키 이름과 값 이름, 서비스 표시 이름과 내부 이름, 디스크 번호와 드라이브 문자를 구분해야 다른 대상을 변경하는 실수를 막을 수 있습니다.

## 2. 레지스트리: 경로·이름·자료형·진법

### 값을 읽는 법

`HKEY_CURRENT_USER`는 현재 사용자, `HKEY_LOCAL_MACHINE`은 컴퓨터 범위의 설정을 담는 대표 루트입니다. 어느 위치에 적을지는 문제의 경로를 따릅니다. 관리자 권한이 있다고 모든 값을 HKLM에 넣는 것은 아닙니다.

| 자료형 | 저장하는 내용 |
|---|---|
| `REG_SZ` | 문자열 |
| `REG_EXPAND_SZ` | 환경변수 참조를 포함할 수 있는 문자열 |
| `REG_DWORD` | 32비트 정수 |
| `REG_QWORD` | 64비트 정수 |

**REG_DWORD라고 해서 항상 0은 끄기, 1은 켜기를 뜻하지 않습니다.** 자료형은 저장 형식일 뿐이고 의미는 개별 설정 정의가 정합니다. 예를 들어 “금지”를 뜻하는 정책 값이 1이면 기능이 차단될 수도 있습니다. 64비트 Windows에서도 DWORD를 요구하면 DWORD를 만듭니다.

## 3. 서비스: 이름·상태·시작 유형

연습 조건은 “Print Spooler의 현재 상태를 중지됨, 시작 유형을 사용 안 함으로 변경”입니다. 이 서비스의 내부 이름은 `Spooler`입니다.

1. `services.msc`를 열고 대상 서비스의 속성을 확인합니다.
2. 원래 실행 상태와 시작 유형을 기록합니다.
3. 실행 중이면 중지하고, 시작 유형을 사용 안 함으로 변경해 적용합니다.
4. 속성을 다시 열어 **두 상태를 각각** 확인합니다.
5. 개인 가상 머신에서는 연습 후 원래 시작 유형과 실행 상태로 복구합니다.

“수동”은 무조건 꺼져 있다는 뜻이 아닙니다. 프로그램이나 다른 구성요소의 요청으로 시작될 수 있습니다. “사용 안 함”도 기존 실행 프로세스를 자동 종료하는 명령과 같은 뜻은 아닙니다. 서비스 중지는 인쇄 등 의존 기능에 영향을 줄 수 있습니다.

## 4. 디스크 관리: 대상과 단위 확인

### 연습 조건

개인 가상 머신에 빈 가상 디스크를 추가합니다. `디스크 1`이 그 빈 디스크라는 것을 용량과 상태로 확인한 뒤, 미할당 공간에 **디스크 관리 입력값 기준 10240 MB**, 드라이브 문자 `R`, 파일 시스템 `NTFS`, 레이블 `Practice`인 단순 볼륨을 만듭니다.

1. `diskmgmt.msc`에서 대상 디스크를 확인합니다. 부팅·시스템·복구 파티션이 있는 디스크를 선택하지 않습니다.
2. 새 디스크라 초기화가 필요한 경우 GPT/MBR 중 과제에서 지정한 방식을 사용합니다. 이미 데이터가 있는 디스크에 초기화를 반복하지 않습니다.
3. 미할당 공간에서 새 단순 볼륨을 만들고 크기·문자·파일 시스템·레이블을 각각 입력합니다.
4. 완료 후 볼륨 목록에서 지정값을 확인합니다. `R`이 이미 사용 중이라면 다른 드라이브를 임의 변경하지 말고 연습 환경을 먼저 정리합니다.

**GB와 GiB는 같지 않습니다.** 1 GB는 10억 바이트, 1 GiB는 1,073,741,824바이트입니다. Windows 도구가 이진 단위를 MB·GB로 표시하는 경우에도, 제품 표기 용량에 무조건 1024를 곱해 실제 전체 용량이라고 판단하면 안 됩니다.

GPT를 “무제한”이라고 외우지 않습니다. Windows의 GPT 구현은 일반적으로 최대 128개 파티션을 지원합니다. MBR의 약 2 TiB 주소 한계는 논리 섹터 512바이트 기준이며, 섹터 크기를 생략한 채 모든 장치에 똑같이 적용하면 부정확합니다.

## 5. 원격 데스크톱: 클라이언트 옵션과 서버 허용

연습 조건은 “접속 대상 `192.168.50.20`, 사용자 `labuser`, 로컬 클립보드 사용, 로컬 프린터 전달 안 함”입니다.

- `mstsc`의 일반 탭에 대상 주소와 사용자 이름을 넣습니다.
- 옵션 표시 후 로컬 리소스 탭에서 클립보드를 선택하고 프린터 선택은 해제합니다.
- 접속 파일 저장을 요구한 연습이라면 지정 위치의 `.rdp` 파일에 저장한 뒤 다시 열어 확인합니다.

이것은 **접속하는 쪽의 옵션 설정**입니다. 상대 PC의 원격 데스크톱 허용, 사용자 접속 권한, 방화벽 규칙까지 자동으로 바뀌지 않습니다.

## 6. BIOS·UEFI와 하드웨어 식별의 경계

에뮬레이터에서 지정한 BIOS 항목을 찾는 연습과 실제 장비에서 안전한 설정을 고르는 일은 구분합니다. `Video BIOS Cacheable`처럼 오래된 메뉴는 현대 UEFI에 없을 수 있으며 모든 PC에 활성화해야 할 성능 옵션도 아닙니다. 저장 단축키도 제조사·펌웨어마다 다르므로 화면 안내를 확인합니다.

USB 포트의 색만으로 버전·속도·충전 기능을 단정하지 않습니다. 색은 제조사 관례일 수 있으므로 포트 표기·커넥터 형상·기기 사양을 함께 확인합니다. USB Type-C는 커넥터 형상이고, 그 모양만으로 USB4·Thunderbolt·영상 출력 지원을 보장하지 않습니다.

## 핵심 정리

- 레지스트리는 루트·경로·값 이름·자료형·진법을 모두 맞춥니다.
- 0과 1의 기능적 의미는 개별 설정에 따라 다릅니다.
- 서비스의 현재 상태와 시작 유형을 따로 확인합니다.
- 디스크 번호·데이터 유무·입력 단위를 확인한 뒤 작업합니다.
- 원격 데스크톱 클라이언트 옵션은 상대 PC의 연결 허용 설정과 다릅니다.
- 에뮬레이터의 오래된 화면을 현대 하드웨어의 보편적 사용법으로 일반화하지 않습니다.
