  **이 모의고사는 실제 기출 문제가 아니라, 최근 회차(56~60회) 기출·복원 문제의 출제 유형과 함정 구성 방식을 분석해 새 테이블·데이터·상황으로 재구성한 연습 문제입니다.** 문항 배치와 개념 비중은 공식 출제기준을 따랐지만 지문·선택지는 전부 새로 작성했습니다. 권장 풀이 시간은 **90분**입니다(실제 시험도 90분, 2과목 50문항). 시간을 재고 한 번에 풀어본 뒤 채점하세요.
</Callout>

## 이 회차의 배점표

SQLD는 2과목(데이터 모델링의 이해 / SQL 기본 및 활용) 50문항, 과목당 100점 만점으로 총점 60점 이상 합격, 과목별 40점(즉 40퍼센트) 미만이면 과락으로 전체가 불합격 처리됩니다. 이 모의고사도 같은 비율로 배분했습니다.

| 영역 | 문항 번호 | 문항 수 | 배점(1문항) |
|------|-----------|---------|-------------|
| 1과목 – 데이터 모델링의 이해 | 1–10 | 10문항 | 10점 |
| 2과목 – SQL 기본 및 활용 | 11–50 | 40문항 | 2.5점 |

표준 난이도 구성이라 개념별 비중을 고르게 배분했습니다. 조인·서브쿼리·집합연산자를 더 깊게 훈련하고 싶다면 다음 편(27. 예상 모의고사 2회)을 이어서 푸세요.

## 채점 후 복습 동선

50문항 중 틀린 문항이 몰린 영역으로 돌아가 해당 편을 다시 읽으세요. 데이터 모델링과 SQL 기본및활용은 각각 40점 미만이면 과락으로 전체 불합격 처리되므로, 두 과목 모두 최소 40점(각 4문항 이상 정답) 이상을 반드시 확보해야 합니다.

| 틀린 문항 번호대 | 취약 영역 | 돌아갈 편 |

| 1–2 | 스키마, 엔터티 분류 | 01편, 03편 |
| 3–4 | 속성, 식별자 특성 | 03편, 04편 |
| 5–6 | 식별자 관계, ERD 표기 | 04편, 05편 |
| 7–9 | 정규화, 반정규화 | 06편, 07편 |
