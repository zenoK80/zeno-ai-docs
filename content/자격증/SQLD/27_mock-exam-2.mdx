수강 테이블에서 학점이 2.0 이상인 학생만 대상으로 학과별 평균 학점을 큰 순서로 정렬하려 한다.

**수강 테이블**

| 학번 | 학과 | 학점 |
|------|------|------|
| S1 | 컴공 | 3.5 |
| S2 | 컴공 | 1.5 |
| S3 | 전자 | 4.0 |
| S4 | 전자 | 2.5 |
| S5 | 국문 | 3.0 |

```sql
SELECT 학과, AVG(학점)     -- (가)
FROM 수강                  -- (나)
WHERE 학점 >= 2.0          -- (다)
GROUP BY 학과              -- (라)
HAVING AVG(학점) >= 2.0    -- (마)
ORDER BY AVG(학점);
```
