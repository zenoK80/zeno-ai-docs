<Callout type="warning">
  **이 모의고사는 실제 기출문제를 그대로 옮긴 것이 아닙니다.** 공개된 회차의 출제 범위·문항 형식·오답 구성 방식을 분석해, 테이블·컬럼명·숫자를 모두 새로 바꿔 재구성한 문항입니다. **권장 풀이 시간은 90분**입니다(실제 SQLD 시험 시간과 동일하게 맞췄습니다). 이 회차는 특히 **윈도우 함수, GROUPING SETS/ROLLUP/CUBE, 계층형 질의(CONNECT BY)** 비중을 실제 시험보다 높여, 이 세 주제에서 확실히 점수를 확보할 수 있는지 점검하는 데 목적을 둡니다.
</Callout>

실제 SQLD는 1과목 데이터 모델링 10문항(20점), 2과목 SQL 기본 및 활용 40문항(80점), 총 100점 만점이며 과목별 40퍼센트(40%) 미만이면 과락으로 처리되어 총점과 무관하게 불합격합니다. 이 회차도 같은 배점 구조를 그대로 따릅니다.

## 문항 배분

| 영역 | 문항 수 | 문항 번호 | 배점 |
| --- | --- | --- | --- |
| 데이터 모델링(엔터티·식별자·정규화·ERD) | 10 | 1–10 | 20점 |
| SQL 기본(DDL·제약조건·DML·TCL·WHERE·함수) | 10 | 11–20 | 20점 |
| 그룹 함수·HAVING·조인 | 5 | 21–25 | 10점 |
| 서브쿼리·집합 연산자 | 5 | 26–30 | 10점 |
| 윈도우 함수(RANK 계열·프레임·LAG/LEAD) | 10 | 31–40 | 20점 |
| GROUPING SETS·ROLLUP·CUBE | 5 | 41–45 | 10점 |
| 계층형 질의(CONNECT BY) | 5 | 46–50 | 10점 |
| 합계 | 50 | 1–50 | 100점 |

[도서] 테이블은 도서ID 1, 2, 3, 4가 있다. [주문상세] 테이블에는 도서ID 2, 4에 대한 주문 기록만 있다.

```sql
SELECT 도서ID
FROM 도서 A
WHERE NOT EXISTS (
  SELECT 1 FROM 주문상세 B WHERE B.도서ID = A.도서ID
);
```



[A] 테이블의 수량 컬럼에는 10, 20, 30이 있다. [B] 테이블의 수량 컬럼에는 20, 20, 40이 있다.

```sql
SELECT 수량 FROM A
UNION
SELECT 수량 FROM B;
```
