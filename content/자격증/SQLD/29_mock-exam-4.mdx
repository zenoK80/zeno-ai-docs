<Callout type="warning">
  **이 모의고사는 실제 기출문제를 그대로 옮긴 것이 아닙니다.** 공개된 회차의 출제 범위·문항 형식·오답 구성 방식을 분석해, 테이블·컬럼명·숫자를 모두 새로 바꿔 재구성한 문항입니다. **권장 풀이 시간은 90분**입니다(실제 SQLD 시험 시간과 동일하게 맞췄습니다). 이 회차는 **SQL 실행 결과 예측형** 문항 비중을 높였고, 특히 **NULL이 섞인 집계, NOT IN, OUTER JOIN의 행 수, RANK와 DENSE_RANK의 혼동, ROWNUM 필터, UNION과 UNION ALL의 행 수 차이, HAVING과 WHERE의 혼동**이라는 여섯 가지 함정 패턴을 오답 선택지에 의도적으로 재현했습니다. 각 오답이 어떤 착각의 결과인지 해설에서 반드시 확인하십시오.
</Callout>

실제 SQLD는 1과목 데이터 모델링 10문항(20점), 2과목 SQL 기본 및 활용 40문항(80점), 총 100점 만점이며 과목별 40퍼센트(40%) 미만이면 과락으로 총점과 무관하게 불합격합니다. 표와 SQL을 직접 손으로 따라가며 결과를 먼저 예측한 뒤 보기를 확인하십시오.

## 문항 배분

| 영역 | 문항 수 | 문항 번호 | 배점 |
| --- | --- | --- | --- |
| 데이터 모델링(엔터티·식별자·정규화·NULL·DCL) | 10 | 1–10 | 20점 |
| SQL 기본과 HAVING·WHERE 함정 | 10 | 11–20 | 20점 |
| 조인과 NULL 관련 함정(NOT IN·OUTER JOIN) | 10 | 21–30 | 20점 |
| 집합연산자·윈도우 함수·ROWNUM·GROUPING SETS·계층형 질의·DCL | 10 | 31–40 | 20점 |
| DBMS 차이와 복합 실행 결과 예측 | 10 | 41–50 | 20점 |
| 합계 | 50 | 1–50 | 100점 |

## 데이터 모델링 (1–10번)

```sql
INSERT INTO 상품 (상품ID, 상품명) VALUES (1, '텀블러');
```

[상품] 테이블에는 상품ID 1, 2, 3, 4가 이 순서로 저장되어 있다.

```sql
SELECT * FROM 상품 WHERE ROWNUM > 1;
```

## DBMS 차이와 복합 실행 결과 예측 (41–50번)

[주문] 테이블에는 주문ID 1(상태코드 P), 2(상태코드 C), 3(상태코드 X)가 있다.

```sql
SELECT 주문ID,
       CASE 상태코드
         WHEN 'P' THEN '준비중'
         WHEN 'C' THEN '완료'
         ELSE '기타'
       END AS 상태명
FROM 주문;
```

```sql
SELECT 고객ID, 이름 FROM 고객
UNION
SELECT 상품ID FROM 상품;
```

[고객] 테이블은 고객ID 1(이름 김), 2(이름 이)로 구성된다. [주문] 테이블에는 고객ID 1인 주문이 3건 있고, 고객ID 2인 주문은 없다.

```sql
SELECT 고객ID, 이름,
       (SELECT COUNT(*) FROM 주문 O WHERE O.고객ID = C.고객ID) AS 주문건수
FROM 고객 C;
```

[주문] 테이블에는 주문ID 1(고객ID 1, 금액 1000), 2(고객ID 1, 금액 NULL), 3(고객ID 2, 금액 2000)이 있다.

```sql
SELECT 고객ID, COUNT(*) AS 건수, SUM(금액) AS 합계
FROM 주문
GROUP BY 고객ID
HAVING SUM(금액) > 500;
```

## 채점 후 복습 동선

50문항을 모두 푼 뒤 아래 표로 틀린 문항 번호대를 확인하고, 해당 범위에서 5문항 이상 틀렸다면 지정된 편으로 돌아가 개념부터 다시 확인하십시오.

| 틀린 문항 범위 | 다루는 개념 | 복습할 편 |
| --- | --- | --- |
| 1–10 | 엔터티·속성·정규화·NULL·DCL 개념 | 03–09편 |
| 11–20 | DDL·DML·TCL·WHERE·함수·NULL 집계·HAVING과 WHERE 차이 | 09–15편 |
| 21–30 | 조인 종류별 행 수·NOT IN과 NOT EXISTS·집합 연산자 | 16–18편 |
| 31–40 | RANK 계열·ROWNUM·GROUPING SETS·계층형 질의·DCL | 19–24편 |
| 41–50 | 절차형 SQL 개요·DBMS 문법 차이·PIVOT·CASE WHEN | 23–25편 |
