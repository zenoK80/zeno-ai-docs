</Callout>

실제 SQLD는 1과목 데이터 모델링 10문항(20점), 2과목 SQL 기본 및 활용 40문항(80점), 총 100점 만점이며 과목별 40퍼센트(40%) 미만이면 과락으로 총점과 무관하게 불합격합니다. 이 회차는 영화관 예매 시스템(영화·상영관·좌석·회원·예매·결제)을 소재로 삼아 전 단원을 고르게 담았습니다.

| 합계 | 50 | 1–50 | 100점 |

## 데이터 모델링 (1–10번)

[회원] 테이블에는 회원ID 1(등급 일반), 2(등급 VIP)가 있다.

```sql
UPDATE 예매 E
SET 할인율 = 0.1
WHERE E.회원ID IN (SELECT 회원ID FROM 회원 WHERE 등급 = 'VIP');
```

```sql
SELECT TO_NUMBER('1,250', '9,999') + 100 AS 결과 FROM DUAL;
```

[예매] 테이블은 예매ID 1(수량 1), 2(수량 5), 3(수량 10)으로 구성된다.

```sql
SELECT 예매ID,
       CASE WHEN 수량 >= 10 THEN '대량'
            WHEN 수량 >= 5 THEN '보통'
            ELSE '소량'
       END AS 구분
FROM 예매;
```

[예매] 테이블은 예매ID 1(회원ID 1), 2(회원ID 9, 회원 테이블에 없는 값)로 구성된다. [회원] 테이블에는 회원ID 1, 2가 있다.

```sql
SELECT E.예매ID, M.회원ID
FROM 예매 E, 회원 M
WHERE E.회원ID = M.회원ID;
```

[회원] 테이블은 회원ID 1(가입일 2024년 1월 10일), 2(가입일 2024년 6월 15일)로 구성된다.

```sql
SELECT 회원ID, EXTRACT(MONTH FROM 가입일) AS 가입월
FROM 회원
WHERE EXTRACT(MONTH FROM 가입일) <= 3;
```

[A] 테이블의 값 컬럼에는 1, NULL, 3이 있다. [B] 테이블의 값 컬럼에는 3, 4가 있다.

```sql
SELECT 값 FROM A
MINUS
SELECT 값 FROM B;
```

[매출4] 테이블은 영화1(매출 1000), 영화2(매출 3000), 영화3(매출 2000)으로 구성된다.

```sql
SELECT * FROM (
  SELECT 영화ID, 매출, RANK() OVER (ORDER BY 매출 DESC) AS 순위
  FROM 매출4
) WHERE 순위 <= 2;
```

## 채점 후 복습 동선

50문항을 모두 푼 뒤 아래 표로 틀린 문항 번호대를 확인하고, 해당 범위에서 5문항 이상 틀렸다면 지정된 편으로 돌아가 개념부터 다시 확인하십시오.

| 틀린 문항 범위 | 다루는 개념 | 복습할 편 |
| --- | --- | --- |
| 1–10 | 엔터티·속성·식별자·정규화·트랜잭션·DCL | 03–09편 |
| 11–20 | DDL·DML·TCL·WHERE·함수·HAVING과 WHERE 차이 | 10–15편 |
| 21–30 | 조인 종류·서브쿼리·집합연산자 | 16–18편 |
| 31–40 | 윈도우 함수·GROUPING SETS·ROLLUP·CUBE·계층형 질의 | 19–22편 |
| 41–50 | PIVOT·CASE WHEN·정규표현식·절차형 SQL·DBMS 문법 차이 | 23–25편 |
