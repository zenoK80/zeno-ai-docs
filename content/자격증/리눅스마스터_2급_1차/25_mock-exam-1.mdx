## 과목별 문항 배분표

리눅스마스터 2급 1차 검정은 리눅스 일반·리눅스 운영 및 관리·리눅스 활용 3과목으로 구성된다. 이 시리즈의 목차(01–24편)를 기준으로 세부 항목 수에 비례해 문항을 배분하면 다음과 같다.

| 과목 | 다루는 세부 항목 | 이 회차 문항 수 | 문항 번호 |
|------|-------------------|------------------|-----------|
| 1과목 리눅스 일반 | 리눅스의 이해, 설치, 기본 명령어 | 14문항 | 1–14 |
| 2과목 리눅스 운영 및 관리 | 파일 시스템 명령어, 셸, 프로세스 관리, 에디터, 소프트웨어 설치, 장치 설정 | 27문항 | 15–41 |
| 3과목 리눅스 활용 | X 윈도, 인터넷 활용, 응용분야 | 9문항 | 42–50 |

실제 회차별 과목별 정확한 문항 배분(예: 각 과목 최소 출제 수, 과락 기준 존재 여부)은 KAIT의 회차 공고에서 최종 확인해야 한다. 이 표는 세부 항목 수 비례로 추정한 학습용 배분이다.

## 채점 후 복습 동선표

50문항 중 정답 개수를 세어 60점(30문항) 이상이면 합격선이다. 틀린 문항이 몰린 영역을 아래에서 찾아 해당 편으로 돌아가 복습한다.

| 틀린 문항 번호대 | 다루는 영역 | 돌아갈 편 |
|-------------------|-------------|-----------|
| 1–4 | 라이선스, 배포판과 패키지 형식 | 01, 02편 |
| 5–8 | 설치·파티션·부팅·런레벨 | 03, 04편 |
| 9–14 | 로그인·셸 기본, 기본 명령어 | 05, 06, 07편 |
| 15–18 | 파일시스템 구조, 마운트 명령어 | 08, 09편 |
| 19–21 | 권한 계산, 특수 권한 | 10편 |
| 22–23 | 사용자·그룹, su와 sudo | 11편 |
| 24–28 | 프로세스 개념, 명령어와 시그널 | 12, 13편 |
| 29–31 | vi 및 그 외 에디터 | 14, 15편 |
| 32–34 | 소프트웨어 설치, 장치 설정 | 16, 17편 |
| 35–38 | 셸 환경변수, 재지정·파이프 | 18, 19편 |
| 39–41 | cron과 at | 20편 |
| 42–44 | X 윈도 | 21편 |
| 45–49 | 네트워크 기초·명령어·서비스 | 22, 23편 |
| 50 | 응용분야 | 24편 |
