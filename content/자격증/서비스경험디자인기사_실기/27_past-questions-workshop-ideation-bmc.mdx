## 이 편을 이렇게 쓰세요

이 편은 "동네 도서관의 무인 대출·반납 서비스 개선" 프로젝트를 공통 배경으로 삼는다. 리서치 자료 종합(어피니티 다이어그램) → 아이디어 워크숍 기획 → 아이디어를 서비스 구조로 옮기는 터치포인트 매트릭스 → 비즈니스 모델 검토 → 완료보고서 작성 순서로 이어진다.

## 서술형 문제

### 문제 1. 어피니티 다이어그램 작성

**문제 상황**: 도서관 이용자 인터뷰에서 다음과 같은 메모가 나왔다: "반납함이 어디 있는지 안내가 없다", "대출 기기 사용법을 몰라 직원에게 매번 물어본다", "야간에는 반납이 안 된다고 생각해 늦게까지 가지고 있는다", "회원증을 안 가져오면 대출을 못 해 헛걸음한다". 이 메모를 어피니티 다이어그램(친화도 맵)으로 그룹핑하고 각 그룹의 이름을 붙이시오.

**모범 답안**

| 그룹명 | 포함된 메모 |
|---|---|
| 안내·정보 부족 | 반납함 위치 안내 없음, 야간 반납 가능 여부를 모름 |
| 기기 사용성 부족 | 대출 기기 사용법을 몰라 직원에게 의존 |
| 인증 절차 불편 | 회원증 미소지 시 대출 불가로 헛걸음 발생 |

**채점 포인트**

- 메모 4개가 누락 없이 어느 한 그룹에는 포함되어 있는지
- 그룹명이 개별 메모를 단순 요약한 것이 아니라, 공통된 문제 유형(안내 부족, 사용성 부족, 절차 불편)을 추상화해 이름 붙였는지
- 서로 다른 원인을 가진 메모를 억지로 한 그룹에 몰아넣지 않았는지

### 문제 2. 아이디어 워크숍 기획

**문제 상황**: 문제 1의 그룹핑 결과를 바탕으로 이해관계자(도서관 직원, 이용자 대표, 서비스 디자이너)가 함께 참여하는 아이디어 워크숍을 기획하시오. 목적, 참가자 구성, 진행 순서(아젠다), 산출물을 포함하시오.

**모범 답안**

| 항목 | 내용 |
|---|---|
| 목적 | 안내 부족, 기기 사용성, 인증 절차 세 가지 문제 유형에 대한 개선 아이디어를 다양한 이해관계자 관점에서 도출 |
| 참가자 구성 | 도서관 직원 2명, 이용자 대표 3명, 서비스 디자이너(퍼실리테이터) 1명 |
| 진행 순서 | 문제 그룹 리뷰(10분) → 개인별 아이디어 스케치(15분) → 소그룹 공유·발전(20분) → 전체 공유·우선순위 투표(15분) |
| 산출물 | 그룹별 아이디어 스케치 원본, 우선순위 투표 결과표, 상위 3개 아이디어 요약 |

**채점 포인트**

- 참가자 구성이 서로 다른 이해관계자(직원, 이용자, 디자이너)를 고르게 포함했는지
- 진행 순서가 개인 작업에서 그룹 공유로, 다시 전체 합의로 확장되는 흐름(퍼실리테이션의 기본 구조)을 갖췄는지
- 산출물이 워크숍 종료 시점에 실제로 손에 남는 결과물(스케치, 투표 결과표)로 구체화되어 있는지

### 문제 3. 퍼실리테이션 진행 서술

**문제 상황**: 문제 2의 워크숍에서 도서관 직원이 자신의 업무 부담을 이유로 이용자 대표의 아이디어에 계속 부정적인 반응을 보인다. 퍼실리테이터(진행자)로서 어떻게 대응할지 서술하시오.

**모범 답안**

우선 부정적 반응 자체를 억누르지 않고, "그 아이디어를 실행했을 때 업무 부담이 어떻게 늘어날 것 같은지" 구체적으로 말해 달라고 요청해 우려를 명확한 정보로 전환한다. 이어서 그 우려를 워크숍 결과물(아이디어 스케치)에 실행 시 고려사항으로 함께 기록해, 아이디어 자체를 폐기하지 않으면서도 직원의 우려를 반영한다. 마지막으로 이용자 대표에게도 발언 기회를 동등하게 배분해, 한쪽의 반복된 부정적 반응이 전체 논의를 위축시키지 않도록 조율한다.

**채점 포인트**

- 부정적 반응을 무시하거나 참가자를 배제하지 않고, 우려를 구체적 정보로 전환하는 방식으로 다뤘는지
- 우려를 기록해 아이디어에 반영하되, 아이디어 자체를 성급히 폐기하지 않았는지
- 발언 기회의 균형(퍼실리테이션의 기본 원칙 중 하나)을 언급했는지

### 문제 4. 터치포인트 매트릭스 작성

**문제 상황**: 문제 2에서 도출된 상위 아이디어(반납함 위치 안내 강화, 기기 사용법 영상 안내, QR코드 기반 무인증 대출)를 서비스 단계별 터치포인트 매트릭스로 정리하시오.

**모범 답안**

| 서비스 단계 | 접점(터치포인트) | 사용 매체 | 반영된 아이디어 |
|---|---|---|---|
| 도서관 진입 | 입구 안내판 | 실물 표지판, 바닥 화살표 스티커 | 반납함 위치 안내 강화 |
| 대출 시도 | 대출 기기 화면 | 기기 화면 내 영상 안내, QR 인증 | 기기 사용법 영상 안내, QR코드 기반 무인증 대출 |
| 반납 | 반납함 | 반납함 옆 안내판, 야간 조명 | 반납함 위치 안내 강화 |

**채점 포인트**

- 서비스 단계(진입-대출-반납)가 실제 서비스 흐름 순서와 일치하는지
- 각 단계의 접점과 매체가 구체적으로 명시되어 있는지(추상적으로 "안내를 강화한다"라고만 쓰면 감점)
- 문제 2에서 도출한 아이디어가 하나도 누락되지 않고 매트릭스의 해당 단계에 배치되었는지

### 문제 5. 서비스 구조화 서술

**문제 상황**: 문제 4의 매트릭스를 근거로, QR코드 기반 무인증 대출 아이디어가 기존 서비스 구조(회원증 기반 인증)를 어떻게 바꾸는지 서술하시오.

**모범 답안**

기존 구조는 이용자가 물리적 회원증을 소지해야만 대출 기기에서 인증이 가능했으나, QR코드 기반 무인증 대출 구조에서는 이용자가 앱에 표시된 개인 QR코드를 기기에 스캔하는 방식으로 인증 수단이 대체된다. 이에 따라 회원증을 잊고 왔을 때 발생하던 헛걸음(문제 1의 인증 절차 불편 그룹)이 해소되며, 대출 기기 쪽에는 QR코드 스캐너 설치라는 새로운 지원 프로세스가 추가되어야 한다.

**채점 포인트**

- 기존 구조와 변경된 구조를 대비해서 서술했는지
- 변경이 문제 1에서 도출한 인사이트(인증 절차 불편)와 직접 연결되는지
- 구조 변경에 따라 새로 필요해지는 지원 요소(스캐너 설치 등)까지 언급했는지

### 문제 6. 비즈니스 모델 캔버스 채우기

**문제 상황**: 개선된 도서관 무인 대출·반납 서비스의 비즈니스 모델 캔버스(Business Model Canvas) 중 핵심 파트너, 핵심 활동, 가치 제안, 고객 관계 4개 블록을 채우시오.

**모범 답안**

| 블록 | 내용 |
|---|---|
| 핵심 파트너 | 지역 도서관 운영 기관, QR 인증 시스템 개발 업체 |
| 핵심 활동 | 무인 대출·반납 기기 운영과 유지보수, 이용자 안내 콘텐츠 제작 |
| 가치 제안 | 회원증 없이도, 직원 도움 없이도 대출과 반납을 완료할 수 있는 간편함 |
| 고객 관계 | 기기 옆 실시간 안내 영상과 앱 내 챗봇 문의로 셀프서비스 지원 |

**채점 포인트**

- 가치 제안이 문제 1~5에서 도출한 실제 문제(안내 부족, 사용성 부족, 인증 절차 불편)의 해결과 연결되는지
- 핵심 활동이 가치 제안을 실현하는 데 실제로 필요한 활동으로 구체화되어 있는지
- 4개 블록 각각이 서로 다른 내용으로 채워져 중복되지 않는지(같은 문장을 여러 블록에 반복하면 감점)

### 문제 7. 가치 제안 서술

**문제 상황**: 문제 6에서 도출한 가치 제안이 기존 서비스(직원 상주 대출 창구) 대비 어떤 점에서 사용자에게 더 나은 가치를 제공하는지 서술하시오.

**모범 답안**

기존 서비스는 직원이 상주하는 시간에만 대출·반납이 가능해 야간이나 직원 부재 시 이용이 제한되었다. 개선된 서비스는 QR코드 기반 무인증과 기기 내 영상 안내로 직원 부재 시에도 이용자가 스스로 대출·반납을 완료할 수 있어, 이용 가능 시간이 늘어나고 문제 1에서 확인된 야간 반납 불안(반납이 안 되는 줄 알고 늦게까지 보관하는 문제)도 함께 해소된다.

**채점 포인트**

- 기존 서비스와 개선 서비스를 대비해서 가치의 차이를 설명했는지
- 가치 제안이 문제 1의 리서치 인사이트(야간 반납 불안)와 직접 연결되는지
- 추상적 구호("더 편리해진다")가 아니라 구체적으로 무엇이 어떻게 나아지는지 서술했는지

### 문제 8. 완료보고서와 디자인 자료화

**문제 상황**: 문제 1~7의 프로젝트를 마무리하는 완료보고서를 작성하려 한다. 프로세스 단계별 결과 요약, 최종 산출물 목록, 데이터베이스화·보존 방안, 사후관리 계획을 정리하시오.

**모범 답안**

| 항목 | 내용 |
|---|---|
| 프로세스 단계별 결과 요약 | 리서치(인터뷰 메모 4건 수집)→종합(어피니티 다이어그램 3개 그룹)→아이디에이션(워크숍에서 상위 3개 아이디어 도출)→구조화(터치포인트 매트릭스 완성)→비즈니스 모델 검토 완료 |
| 최종 산출물 목록 | 어피니티 다이어그램 원본, 워크숍 아이디어 스케치, 터치포인트 매트릭스, 비즈니스 모델 캔버스 |
| 데이터베이스화·보존 방안 | 산출물을 프로젝트 폴더에 단계별로 분류해 저장하고, 도서관 운영 기관과 클라우드로 공유 |
| 사후관리 계획 | 서비스 도입 후 3개월 시점에 이용자 만족도를 재조사해 개선 아이디어의 실제 효과를 점검 |

**채점 포인트**

- 프로세스 단계별 요약이 앞선 문제 1~6의 흐름을 빠짐없이 반영하고 있는지
- 최종 산출물 목록이 실제로 작성된 산출물(어피니티 다이어그램, 워크숍 결과 등)과 정확히 대응하는지
- 데이터베이스화·보존 방안에 분류 기준과 공유 대상이 구체적으로 명시되어 있는지
- 사후관리 계획이 일회성으로 끝나지 않고, 도입 이후 효과를 재점검하는 절차까지 포함하는지

## 핵심 정리

- 어피니티 다이어그램은 개별 메모를 공통된 문제 유형으로 추상화해 그룹명을 붙이는 것이 핵심이며, 억지로 묶으면 감점된다.
- 아이디어 워크숍 기획은 참가자 구성의 다양성과 개인-소그룹-전체로 확장되는 진행 순서, 손에 남는 산출물을 모두 갖춰야 한다.
