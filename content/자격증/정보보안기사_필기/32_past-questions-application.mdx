## 웹 서버 운영과 OWASP 주요 공격 (1–5)

> **출제 포인트:** 로그인 폼 우회 문장을 보고 어떤 공격 기법인지 즉시 이름을 붙일 수 있는지를 확인합니다. `admin'--` 같은 패턴은 SQL 질의문의 나머지를 주석 처리해 비밀번호 검사 조건 자체를 무력화하는 SQL 인젝션의 전형적인 형태입니다.
